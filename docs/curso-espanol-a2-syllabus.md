# Syllabus — Spanish A2 (English-speaking learners)

60 units. Category `curso-espanol-a2`. Folder `src/content/blog/curso-espanol-a2/`.  
**Focus:** irregular present, full *gustar* system, **indefinido vs imperfecto**, future, basic commands, *estar* + gerund, *por/para* expansion. DELE A2 in U54–60.
