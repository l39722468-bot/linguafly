# Syllabus — Spanish A2 (PCIC / NRE / DELE A2)

60 units. Category `curso-espanol-a2`. Folder `src/content/blog/curso-espanol-a2/`.  
**Norma:** columna **A2** de los inventarios PCIC. Mapa: [curso-espanol-cobertura-pcic.md](./curso-espanol-cobertura-pcic.md).

Este nivel **recibe** el material que el PCIC sitúa en A2 (y que no debe enseñarse como productivo en A1): presente irregular y vocálico, perífrasis *ir a / tener que / hay que / poder / estar + gerundio*, pretéritos **perfecto, indefinido e imperfecto**, imperativo, clíticos OD/OI, comparativos, *encantar/doler*, indefinidos negativos.

**No** paradigma de futuro/condicional (PCIC Gram. 9.1.4–9.1.5 vacíos en A1–A2). Planes = *ir a* + presente con valor de futuro. Cortesía = fórmula *me gustaría*.
