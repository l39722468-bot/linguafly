# Cloudflare D1 Bulk Import Guide\n\n## Format\n\nCreate a JSONL (JSON Lines) file with one article per line:\n\n```jsonl\n{\"slug\":\"article-1\",\"title\":\"Title\",\"description\":\"Desc\",\"content\":\"Content...\",\"category\":\"cat\",\"level\":\"A1\",\"tags\":[\"t1\",\"t2\"]}\n{\"slug\":\"article-2\",\"title\":\"Title\",\"description\":\"Desc\",\"content\":\"Content...\",\"category\":\"cat\",\"level\":\"B1\",\"tags\":[\"t3\"]}\n```\n\n## Required Fields\n\n- **slug** (string): Unique URL-friendly identifier (lowercase, hyphens only)\n- **title** (string): Article title (max 255 chars recommended)\n- **content** (string): Full article content\n- **category** (string): Article category (business, travel, exams, etc.)\n\n## Optional Fields\n\n- **description** (string): Short description for lists\n- **level** (string): Language level (A1, A2, B1, B2, C1, C2)\n- **tags** (array): Array of tag strings\n\n## Example: 1M Articles\n\n### Data Structure\n```\narticles.jsonl (4GB+ file)\n├─ 1,000,000 articles\n├─ ~4KB average per article\n└─ Organized by category and level\n```\n\n### Import Process\n```bash\n# 1. Prepare your JSONL file\nls -lh articles.jsonl  # Should be ~4GB\n\n# 2. Set API key\nexport ARTICLES_API_KEY=\"your-secure-key\"\n\n# 3. Start import (will process ~1000 articles/batch)\nnpx tsx scripts/bulk-import-articles.ts articles.jsonl\n\n# 4. Monitor progress\ncurl https://linguafly.dev/api/articles/count\n\n# 5. Check logs\nwrangler d1 execute linguafly_db --command=\"\\\n  SELECT batch_number, status, imported_count, completed_at \\\n  FROM import_logs \\\n  ORDER BY batch_number DESC \\\n  LIMIT 10;\"\n```\n\n## Performance\n\n| Metric | Value |\n|--------|-------|\n| Batch size | 1,000 articles |\n| Time per batch | ~10-30 seconds |\n| Batches needed | 1,000 |\n| Total time | ~100-300 minutes (~2-5 hours) |\n| Throughput | ~3,500-10,000 articles/minute |\n\n## Categories & Levels\n\n### Categories\n- business\n- travel\n- exams (IELTS, TOEFL, CAE, etc.)\n- pronunciation\n- vocabulary\n- grammar\n- culture\n- conversation\n- listening\n- reading\n- writing\n- idioms\n\n### Levels\n- A1 (Beginner)\n- A2 (Elementary)\n- B1 (Intermediate)\n- B2 (Upper Intermediate)\n- C1 (Advanced)\n- C2 (Proficiency)\n\n## Validation\n\n### Before Import\n```bash\n# Check JSONL syntax\njq -s 'length' articles.jsonl  # Should output: 1000000\n\n# Sample first 5 lines\nhead -5 articles.jsonl | jq .\n\n# Check for invalid JSON\njq . articles.jsonl > /dev/null && echo \"✅ Valid JSON\"\n```\n\n### During Import\n```bash\n# Monitor in real-time\nwatch 'curl https://linguafly.dev/api/articles/count'\n\n# Check database size\nwrangler d1 execute linguafly_db --command=\"\\\n  SELECT COUNT(*) as total, \\\n         COUNT(CASE WHEN is_published = 1 THEN 1 END) as published \\\n  FROM articles;\"\n```\n\n### After Import\n```bash\n# Verify all articles\nwrangler d1 execute linguafly_db --command=\"\\\n  SELECT \\\n    COUNT(*) as total,\\\n    COUNT(DISTINCT category) as categories,\\\n    COUNT(DISTINCT level) as levels,\\\n    MIN(created_at) as first_imported,\\\n    MAX(created_at) as last_imported\\\n  FROM articles;\"\n\n# Check for duplicates\nwrangler d1 execute linguafly_db --command=\"\\\n  SELECT slug, COUNT(*) as count\\\n  FROM articles\\\n  GROUP BY slug\\\n  HAVING count > 1;\"\n```\n\n## Troubleshooting\n\n### Import Too Slow\n- Reduce batch size if timeouts occur\n- Check network connectivity to Cloudflare\n- Monitor Cloudflare dashboard for rate limits\n\n### Import Failures\n- Check `import_logs` table for error details\n- Validate JSON format with `jq`\n- Retry failed batches individually\n- Check required fields (slug, title, content, category)\n\n### Duplicate Slugs\n- JSONL must have unique slugs\n- Pre-process with: `sort -u articles.jsonl > articles-unique.jsonl`\n- Or use database constraint to reject duplicates\n\n### Memory Issues\n- Process JSONL in smaller files\n- Split 1M articles into 10 x 100K files\n- Import sequentially\n\n## Advanced: Parallel Import\n\n```bash\n# Split into 10 files\nsplit -l 100000 articles.jsonl article-part-\n\n# Import in parallel (requires multiple API keys per worker)\nfor file in article-part-*; do\n  npx tsx scripts/bulk-import-articles.ts $file &\ndone\nwait\n\necho \"✅ All files imported\"\n```\n\n## Rollback\n\n```bash\n# Delete all articles\nwrangler d1 execute linguafly_db --command=\"DELETE FROM articles;\" --remote\n\n# Or delete specific batch range\nwrangler d1 execute linguafly_db --command=\"\\\n  DELETE FROM articles \\\n  WHERE id IN (\\\n    SELECT article_id FROM article_analytics \\\n    WHERE DATE(date) = '2026-09-07'\\\n  );\" --remote\n```\n\n## See Also\n\n- [README.CLOUDFLARE.md](../README.CLOUDFLARE.md)
