## Lección 1 — Gramática

**Objetivo:** PET/B1 exam strategies + mixed grammar in exam context

### Ejercicios 1–5 — Completa

1. If you ___ hard, you will pass. → *study / studied / had studied*
2. You ___ read the instructions. → *should / must / might*
3. I ___ been practising for three months. → *have / has / had*
4. If I ___ had more time, I would have checked. → *had / have / would*
5. The exam ___ taken every year. → *is / was / has been*

<details>
<summary>Ver solución</summary>

1. **study** · 2. **should** · 3. **have** · 4. **had** · 5. **is**

</details>

### Ejercicios 6–10 — Elige / completa

1. If + present → will = ___ → *first / second / third*
2. should ≈ ___ → *advice / deduction / passive*
3. have been + -ing = ___ → *PP continuous / past perfect / passive*
4. had had → would have = ___ → *third / first / reported*
5. is taken = ___ → *passive present / active / modal*

<details>
<summary>Ver solución</summary>

1. **first** · 2. **advice** · 3. **PP continuous** · 4. **third** · 5. **passive present**

</details>

### Ejercicios 11–15 — Corrige

1. *If you will study hard…*
2. *You must to read the instructions.*
3. *I have been practise for three months.*
4. *If I would have had more time…*
5. *The exam was taken every year.* (habit)

<details>
<summary>Ver solución</summary>

1. If you **study** hard…
2. You **should read** the instructions.
3. I **have been practising** for three months.
4. If I **had had** more time…
5. The exam **is taken** every year.

</details>
