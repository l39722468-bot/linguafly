## Lección 1 — Gramática

**Objetivo:** practicar defining relative clauses (who/which/that).

### Ejercicios 1–5 — Completa

Elige la opción correcta. Solo una es válida.

1. The woman ___ lives next door is a vet. → *who / which / where*
2. The book ___ I bought is interesting. → *which / who / whose*
3. Animals ___ live in the wild are free. → *that / who / where*
4. The landscape ___ we visited was breathtaking. → *that / who / whose*
5. The bird ___ I saw was an eagle. → *which / who / where*

<details>
<summary>Ver solución</summary>

1. **who** · 2. **which** · 3. **that** · 4. **that** · 5. **which**

</details>

### Ejercicios 6–10 — Elige / completa

Completa cada frase con la forma correcta.

1. Anyone ___ loves wildlife should visit. → *who / which / where*
2. The river ___ flows through the valley is clean. → *which / who / whose*
3. The man ___ saw the bear reported it. → *who / which / where*
4. The plants ___ grow here need water. → *that / who / where*
5. Omit object: The book ___ I bought… → *that/which / who / where*

<details>
<summary>Ver solución</summary>

1. **who** · 2. **which** · 3. **who** · 4. **that** · 5. **that/which**

</details>

### Ejercicios 11–15 — Corrige el error

Cada frase tiene **un** error. Reescribe la frase correcta.

1. *The woman which lives next door…*
2. *Animals who live in the wild…*
3. *The book who I bought…*
4. *Anyone which loves wildlife…*
5. *The bird who I saw…*

<details>
<summary>Ver solución</summary>

1. The woman **who/that** lives…
2. Animals **that/which** live…
3. The book **which/that** I bought…
4. Anyone **who/that** loves…
5. The bird **which/that** I saw…

</details>

3. eagle → *águila · pollution · cafe*
4. forest → *bosque · appointment · worried*
5. bear → *oso · plastic · exciting*

<details>
<summary>Ver solución</summary>

</details>

### Ejercicios 6–10 — Completa / significado

Elige la opción que completa o explica mejor cada ítem.

1. who → ___ → *people / things only / commas*
2. which/that → ___ → *things/animals / people only / tags*
3. wild ≈ ___ → *salvaje / banco / aburrido*
4. vet ≈ ___ → *veterinario / clima / tag*
5. park ≈ ___ → *parque / bored / which*

<details>
<summary>Ver solución</summary>

1. **people** · 2. **things/animals** · 3. **salvaje** · 4. **veterinario** · 5. **parque**

</details>
