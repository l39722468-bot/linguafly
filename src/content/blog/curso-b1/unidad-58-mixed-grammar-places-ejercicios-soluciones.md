## Lección 1 — Gramática

**Objetivo:** passive, would rather, there are, relative where, PP continuous

### Ejercicios 1–5 — Completa

1. The bridge ___ built last year. → *was / is / has been*
2. I'd ___ live in the countryside. → *rather / better / prefer*
3. ___ are many shops in the centre. → *There / It / They*
4. The village ___ I grew up is small. → *where / which / who*
5. I ___ been living here since 2015. → *have / has / had*

<details>
<summary>Ver solución</summary>

1. **was** · 2. **rather** · 3. **There** · 4. **where** · 5. **have**

</details>

### Ejercicios 6–10 — Elige / completa

1. was built → ___ → *passive past / active / present*
2. would rather ≈ ___ → *preference / obligation / deduction*
3. There are + ___ → *plural noun / singular / infinitive*
4. where for places = ___ → *relative / passive / modal*
5. since 2015 → ___ → *PP continuous / past simple / future*

<details>
<summary>Ver solución</summary>

1. **passive past** · 2. **preference** · 3. **plural noun** · 4. **relative** · 5. **PP continuous**

</details>

### Ejercicios 11–15 — Corrige

1. *The bridge is built last year.*
2. *I'd rather to live…*
3. *It are many shops…*
4. *The village which I grew up…*
5. *I have living here since 2015.*

<details>
<summary>Ver solución</summary>

1. The bridge **was built** last year.
2. I'd **rather live**…
3. **There are** many shops…
4. The village **where** I grew up…
5. I **have been living** here since 2015.

</details>

## Lección 2 — Vocabulario

**Objetivo:** town & countryside

### Ejercicios 1–5 — Empareja / elige

1. countryside → *campo · city · street*
2. town centre → *centro / periferia / valle*
3. valley → *valle · montaña · río*
4. bridge → *puente · túnel · sendero*
5. suburb → *periferia · centro · campo*

<details>
<summary>Ver solución</summary>

1. **campo** · 2. **centro** · 3. **valle** · 4. **puente** · 5. **periferia**

</details>

### Ejercicios 6–10 — Completa

1. village ≈ ___ → *pueblo pequeño / gran ciudad / bosque*
2. There are ≈ ___ → *existen (plural) / existe (singular) / tienen*
3. where for places ≈ ___ → *relativa de lugar / persona / cosa*
4. forest ≈ ___ → *bosque / lago / plaza*
5. museum ≈ ___ → *museo / estación / hospital*

<details>
<summary>Ver solución</summary>

1. **pueblo pequeño** · 2. **existen (plural)** · 3. **relativa de lugar** · 4. **bosque** · 5. **museo**

</details>

## Lección 5 — Writing

**Objetivo:** producir frases con el foco de la unidad.

1. Escribe passive + would rather + there are + where.
2. Completa: The bridge ___ built last year.
3. Completa: I'd ___ live in the countryside.
4. Completa: ___ are many shops.
5. Completa: The village ___ I grew up.
6. Completa: I ___ been living since 2015.
7. Corrige: *It are many shops…*
8. Corrige: *The village which I grew up…*
9. Usa countryside y bridge en 2 frases.
10. Mini-historia (4 frases) ciudad vs campo.
11. Traduce: Hay muchas tiendas en el centro.
12. Traduce: El pueblo donde crecí es pequeño.
13. Explica there is vs there are.
14. Escribe 1× second conditional (places).
15. Autochequeo: where for places.

<details>
<summary>Ver solución</summary>

1. Open four.
2. **was**
3. **rather**
4. **There**
5. **where**
6. **have**
7. **There are** many shops.
8. The village **where** I grew up…
9. Open.
10. Open.
11. There are many shops in the town centre.
12. The village where I grew up is very small.
13. There is + singular; there are + plural.
14. OK.
15. Self-check.

</details>
