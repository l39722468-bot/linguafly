## Lección 1 — Gramática

**Objetivo:** practicar reflexive pronouns (myself, yourself, himself…).

### Ejercicios 1–5 — Completa

Elige la opción correcta. Solo una es válida.

1. I hurt ___ when I fell. → *myself / yourself / himself*
2. She taught ___ to play the guitar. → *herself / himself / itself*
3. They enjoyed ___ at the party. → *themselves / ourselves / yourselves*
4. We organised the trip ___. → *by ourselves / by themselves / by yourself*
5. We need to believe in ___. → *ourselves / themselves / yourself*

<details>
<summary>Ver solución</summary>

1. **myself** · 2. **herself** · 3. **themselves** · 4. **by ourselves** · 5. **ourselves**

</details>

### Ejercicios 6–10 — Elige / completa

Completa cada frase con la forma correcta.

1. He taught ___ Spanish. → *himself / herself / itself*
2. Help ___ to some food. → *yourself / myself / himself*
3. The children dressed ___. → *themselves / ourselves / yourselves*
4. Be proud of ___. → *yourself / myself / himself*
5. I made ___ a sandwich. → *myself / yourself / themselves*

<details>
<summary>Ver solución</summary>

1. **himself** · 2. **yourself** · 3. **themselves** · 4. **yourself** · 5. **myself**

</details>

### Ejercicios 11–15 — Corrige el error

Cada frase tiene **un** error. Reescribe la frase correcta.

1. *I hurt me when I fell.*
2. *She taught herself to him.*
3. *They enjoyed theirselves.*
4. *We organised it by ourselves.*
5. *Believe in we.*

<details>
<summary>Ver solución</summary>

1. I hurt **myself** when I fell.
2. She taught **herself**…
3. They enjoyed **themselves**.
4. OK / by **ourselves**.
5. Believe in **ourselves**.

</details>

4. memory → *recuerdo · salad · bank*
5. coincidence → *coincidencia · salt · library*

<details>
<summary>Ver solución</summary>

</details>

### Ejercicios 6–10 — Completa / significado

Elige la opción que completa o explica mejor cada ítem.

1. myself = ___ → *yo mismo / tú / ellos*
2. themselves = ___ → *ellos mismos / nosotros / ella*

4. look back ≈ ___ → *mirar atrás / cocinar / elegir*
5. get over ≈ ___ → *superar / preferir / visitar*

<details>
<summary>Ver solución</summary>

1. **yo mismo** · 2. **ellos mismos** · 3. **sin ayuda** · 4. **mirar atrás** · 5. **superar**

</details>
