## Lección 1 — Gramática

**Objetivo:** practicar so/such/so much/so many + intensifiers.

### Ejercicios 1–5 — Completa

Elige la opción correcta. Solo una es válida.

1. I'm ___ tired. → *so / such / such a*
2. It was ___ nice day. → *such a / so / such*
3. There is ___ work. → *so much / so many / so*
4. There are ___ people. → *so many / so much / so*
5. This hotel is ___ expensive. → *so / such / such a*

<details>
<summary>Ver solución</summary>

1. **so** · 2. **such a** · 3. **so much** · 4. **so many** · 5. **so**

</details>

### Ejercicios 6–10 — Elige / completa

Completa cada frase con la forma correcta.

1. so + ___ → *adjective / noun / verb*
2. such (+ a/an) + ___ → *adj + noun / only adj / verb*
3. so much + ___ → *uncountable / countable / plural*
4. so many + ___ → *countable plural / uncountable / adj*
5. extremely ≈ ___ → *very strong / weak / noun*

<details>
<summary>Ver solución</summary>

1. **adjective** · 2. **adj + noun** · 3. **uncountable** · 4. **countable plural** · 5. **very strong**

</details>

### Ejercicios 11–15 — Corrige el error

Cada frase tiene **un** error. Reescribe la frase correcta.

1. *I'm such tired.*
2. *It was so nice day.*
3. *There is so many work.*
4. *There are so much people.*
5. *such expensive hotel* (no noun)

<details>
<summary>Ver solución</summary>

1. I'm **so** tired.
2. It was **such a** nice day.
3. There is **so much** work.
4. There are **so many** people.
5. **such an** expensive hotel / **so** expensive

</details>

## Lección 2 — Vocabulario

**Objetivo:** intensifiers.

### Ejercicios 1–5 — Empareja / elige

Elige la **traducción o significado correcto** (ignora las distracciones).

1. extremely → *extremadamente · fairly · delay*
2. incredibly → *increíblemente · passport · although*
3. quite → *bastante · luggage · despite*
4. absolutely → *totalmente · scenic · so that*
5. really → *realmente · booking · compound*

<details>
<summary>Ver solución</summary>

1. **extremadamente** · 2. **increíblemente** · 3. **bastante** · 4. **totalmente** · 5. **realmente**

</details>

### Ejercicios 6–10 — Completa / significado

Elige la opción que completa o explica mejor cada ítem.

1. very ≈ ___ → *muy / causa / guion*
2. intensifier → ___ → *strength / noun / hyphen*
3. so + ___ → *adj / noun / verb*
4. such + ___ → *noun phrase / only adj / verb*
5. fairly ≈ ___ → *bastante / total / retraso*

<details>
<summary>Ver solución</summary>

1. **muy** · 2. **strength** · 3. **adj** · 4. **noun phrase** · 5. **bastante**

</details>

### Ejercicios 11–15 — En contexto

Completa con una de estas palabras: *extremely* · *incredibly* · *quite* · *absolutely* · *really*

12. Write a short sentence with **incredibly**.  
13. Write a short sentence with **quite**.  
14. Choose the best word for this idea: «totalmente» → **absolutely** / other. Confirm in the [guía teórica](/blog/curso-b1/unidad-36-so-such-intensifiers).  
15. Practise aloud, then continue in the [Unidad 36 del curso](/curso-b1/unit-36).

<details>
<summary>Ver solución</summary>

11. Modelo: usa **extremely** en una frase natural con *so/such/so much/so many + intensifiers*.  
12. Modelo: usa **incredibly** en una frase corta.  
13. Modelo: usa **quite** en una frase corta.  
14. **absolutely** (comprueba la tabla de vocabulario en la teoría).  
15. Continúa en **/curso-b1/unit-36**.

</details>
