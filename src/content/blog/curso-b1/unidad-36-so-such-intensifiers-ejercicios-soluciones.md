## Lección 1 — Gramática

**Objetivo:** so/such/so much/so many + intensifiers

### Ejercicios 1–5 — Completa

1. I'm ___ tired. → *so / such / such a*
2. It was ___ nice day. → *such a / so / such*
3. There is ___ work. → *so much / so many / so*
4. There are ___ people. → *so many / so much / so*
5. This hotel is ___ expensive. → *so / such / such a*

<details>
<summary>Ver solución</summary>

1. **so** · 2. **such a** · 3. **so much** · 4. **so many** · 5. **so**

</details>

### Ejercicios 6–10 — Elige / completa

1. so + ___ → *adjective / noun / verb*
2. such (+ a/an) + ___ → *adj + noun / only adj / verb*
3. so much + ___ → *uncountable / countable / plural*
4. so many + ___ → *countable plural / uncountable / adj*
5. extremely ≈ ___ → *very strong / weak / noun*

<details>
<summary>Ver solución</summary>

1. **adjective** · 2. **adj + noun** · 3. **uncountable** · 4. **countable plural** · 5. **very strong**

</details>

### Ejercicios 11–15 — Corrige

1. *I'm such tired.*
2. *It was so nice day.*
3. *There is so many work.*
4. *There are so much people.*
5. *such expensive hotel* (no noun)

<details>
<summary>Ver solución</summary>

1. I'm **so** tired.
2. It was **such a** nice day.
3. There is **so much** work.
4. There are **so many** people.
5. **such an** expensive hotel / **so** expensive

</details>

**Objetivo:** intensifiers

### Ejercicios 1–5 — Empareja / elige

1. extremely → *extremadamente · fairly · delay*
2. incredibly → *increíblemente · passport · although*
3. quite → *bastante · luggage · despite*
4. absolutely → *totalmente · scenic · so that*
5. really → *realmente · booking · compound*

<details>
<summary>Ver solución</summary>

</details>

## Lección 5 — Writing

**Objetivo:** producir frases con el foco de la unidad.

1. Escribe 2× so + adj + 2× such a + noun.
2. Completa: I'm ___ tired.
3. Completa: It was ___ nice day.
4. Completa: There is ___ work.
5. Completa: There are ___ people.
6. Corrige: *I'm such tired.*
7. Corrige: *so many work.*
8. Usa extremely y really en 2 frases con so/such.
9. Escribe: This hotel is so expensive.
10. Mini-diálogo (3 frases) con so/such.
11. Traduce: Estoy tan cansado.
12. Traduce: Fue un día tan bonito.
13. Explica so vs such en 1 frase.
14. Escribe 1× so many + countable.
15. Autochequeo: adj→so; noun→such.

<details>
<summary>Ver solución</summary>

1. Open 2+2.
2. **so**
3. **such a**
4. **so much**
5. **so many**
6. **so** tired
7. **so much** work
8. Open.
9. OK.
10. Open.
11. I'm so tired.
12. It was such a nice day.
13. so+adj; such+noun.
14. OK.
15. Self-check.

</details>
