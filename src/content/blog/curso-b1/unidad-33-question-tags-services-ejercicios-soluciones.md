## Lección 1 — Gramática

**Objetivo:** practicar question tags (isn't it?, don't you?…).

### Ejercicios 1–5 — Completa

Elige la opción correcta. Solo una es válida.

1. It's a nice day, ___? → *isn't it / is it / doesn't it*
2. You like this restaurant, ___? → *don't you / do you / doesn't you*
3. She works at the bank, ___? → *doesn't she / does she / isn't she*
4. They haven't finished, ___? → *have they / haven't they / did they*
5. You're free tomorrow, ___? → *aren't you / are you / don't you*

<details>
<summary>Ver solución</summary>

1. **isn't it** · 2. **don't you** · 3. **doesn't she** · 4. **have they** · 5. **aren't you**

</details>

### Ejercicios 6–10 — Elige / completa

Completa cada frase con la forma correcta.

1. He is a doctor, ___? → *isn't he / is he / doesn't he*
2. We need an appointment, ___? → *don't we / do we / aren't we*
3. The cafe isn't open, ___? → *is it / isn't it / does it*
4. You went to the pharmacy, ___? → *didn't you / did you / don't you*
5. Positive → tag is ___ → *negative / positive / zero*

<details>
<summary>Ver solución</summary>

1. **isn't he** · 2. **don't we** · 3. **is it** · 4. **didn't you** · 5. **negative**

</details>

### Ejercicios 11–15 — Corrige el error

Cada frase tiene **un** error. Reescribe la frase correcta.

1. *It's nice, is it?*
2. *You like it, do you?* (confirm)
3. *She works here, isn't she?*
4. *They haven't finished, haven't they?*
5. *You're free, don't you?*

<details>
<summary>Ver solución</summary>

1. It's nice, **isn't it?**
2. You like it, **don't you?**
3. She works here, **doesn't she?**
4. They haven't finished, **have they?**
5. You're free, **aren't you?**

</details>

2. appointment → *cita · pollution · forest*
3. pharmacy → *farmacia · climate · who*
4. restaurant → *restaurante · waste · which*
5. doctor → *médico · protect · that*

<details>
<summary>Ver solución</summary>

1. **banco** · 2. **cita** · 3. **farmacia** · 4. **restaurante** · 5. **médico**

</details>

### Ejercicios 6–10 — Completa / significado

Elige la opción que completa o explica mejor cada ítem.

1. + statement → ___ tag → *negative / positive / zero*
2. − statement → ___ tag → *positive / negative / zero*
3. cafe ≈ ___ → *cafetería / eagle / bored*
4. taxi ≈ ___ → *taxi / forest / which*
5. hotel ≈ ___ → *hotel / recycle / who*

<details>
<summary>Ver solución</summary>

1. **negative** · 2. **positive** · 3. **cafetería** · 4. **taxi** · 5. **hotel**

</details>
