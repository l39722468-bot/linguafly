## Lección 1 — Gramática

**Objetivo:** to/so that/because of + explaining

### Ejercicios 1–5 — Completa

1. I study English ___ travel more. → *to / so that / because of*
2. We left early ___ avoid traffic. → *in order to / because of / so that*
3. I called ___ you wouldn't worry. → *so that / to / because of*
4. We stayed inside ___ the storm. → *because of / because / to*
5. The delay was ___ the weather. → *due to / so that / although*

<details>
<summary>Ver solución</summary>

1. **to** · 2. **in order to** · 3. **so that** · 4. **because of** · 5. **due to**

</details>

### Ejercicios 6–10 — Elige / completa

1. to / in order to + ___ → *infinitive / clause / noun*
2. so that + ___ → *clause (subject+verb) / infinitive / noun*
3. because + ___ → *clause / noun / infinitive*
4. because of + ___ → *noun / clause / verb*
5. due to ≈ ___ → *because of / because / so that*

<details>
<summary>Ver solución</summary>

1. **infinitive** · 2. **clause (subject+verb)** · 3. **clause** · 4. **noun** · 5. **because of**

</details>

### Ejercicios 11–15 — Corrige

1. *I study to that I travel.*
2. *We left early to we avoid traffic.*
3. *I called to you wouldn't worry.*
4. *We stayed because the storm.*
5. *due to it was raining* (clause)

<details>
<summary>Ver solución</summary>

1. I study **to** travel / **so that** I can travel.
2. We left early **in order to** avoid… / **so that** we could avoid…
3. I called **so that** you wouldn't worry.
4. We stayed **because of** the storm / **because** it was stormy.
5. **due to the rain** / **because** it was raining

</details>

## Lección 2 — Vocabulario

**Objetivo:** explaining

### Ejercicios 1–5 — Empareja / elige

1. purpose → *propósito · agree · so*
2. cause → *causa · disagree · such*
3. explain → *explicar · opinion · two-day*
4. goal → *objetivo · convincing · although*
5. therefore → *por lo tanto · fair · however*

<details>
<summary>Ver solución</summary>

1. **propósito** · 2. **causa** · 3. **explicar** · 4. **objetivo** · 5. **por lo tanto**

</details>

### Ejercicios 6–10 — Completa

1. reason ≈ ___ → *razón / retraso / guion*
2. result ≈ ___ → *resultado / equipaje / intensidad*
3. so (result) ≈ ___ → *así que / destino / compound*
4. in order to ≈ ___ → *para / pasaporte / contraste*
5. due to ≈ ___ → *debido a / scenic / so many*

<details>
<summary>Ver solución</summary>

1. **razón** · 2. **resultado** · 3. **así que** · 4. **para** · 5. **debido a**

</details>

## Lección 5 — Writing

**Objetivo:** producir frases con el foco de la unidad.

1. Escribe 2× to + 1× so that + 1× because of.
2. Completa: I study English ___ travel.
3. Completa: We left early ___ avoid traffic.
4. Completa: I called ___ you wouldn't worry.
5. Completa: We stayed inside ___ the storm.
6. Corrige: *I called to you wouldn't worry.*
7. Corrige: *because the storm* (noun only)
8. Usa purpose y cause en 2 frases.
9. Escribe: The delay was due to the weather.
10. Mini-explicación (4 frases) why/how.
11. Traduce: Estudio inglés para viajar.
12. Traduce: Por la tormenta.
13. Explica to vs so that en 1 frase.
14. Escribe 1× in order to.
15. Autochequeo: clause→because/so that; noun→because of.

<details>
<summary>Ver solución</summary>

1. Open four.
2. **to**
3. **in order to / to**
4. **so that**
5. **because of / due to**
6. **so that**
7. **because of** the storm
8. Open.
9. OK.
10. Open.
11. I study English to travel.
12. because of the storm.
13. to+inf; so that+clause.
14. OK.
15. Self-check.

</details>
