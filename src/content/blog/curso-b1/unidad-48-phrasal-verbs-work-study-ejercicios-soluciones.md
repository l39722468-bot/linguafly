## Lección 1 — Gramática

**Objetivo:** practicar work out, look forward to, run out of, take care of, carry out, deal with.

### Ejercicios 1–5 — Completa

Elige la opción correcta. Solo una es válida.

1. I ___ out at the gym every morning. → *work / works / working*
2. I'm looking forward ___ my holiday. → *to / for / at*
3. We ran ___ of milk. → *out / off / away*
4. She takes care ___ her children. → *of / for / about*
5. They carried ___ the research. → *out / on / off*

<details>
<summary>Ver solución</summary>

1. **work** · 2. **to** · 3. **out** · 4. **of** · 5. **out**

</details>

### Ejercicios 6–10 — Elige / completa

Completa cada frase con la forma correcta.

1. look forward to + ___ → *-ing or noun / infinitive / past*
2. run out of + ___ → *object / no object / clause*
3. take care of ≈ ___ → *look after / look for / look at*
4. carry out = ___ → *perform / continue / stop*
5. deal with = ___ → *handle / ignore / create*

<details>
<summary>Ver solución</summary>

1. **-ing or noun** · 2. **object** · 3. **look after** · 4. **perform** · 5. **handle**

</details>

### Ejercicios 11–15 — Corrige el error

Cada frase tiene **un** error. Reescribe la frase correcta.

1. *I'm looking forward to go.*
2. *We ran out milk.*
3. *She takes care her children.*
4. *They carried on the research.* (perform)
5. *I don't know how to deal this problem.*

<details>
<summary>Ver solución</summary>

1. I'm looking forward to **going**.
2. We ran **out of** milk.
3. She takes care **of** her children.
4. They **carried out** the research.
5. deal **with** this problem

</details>

## Lección 2 — Vocabulario

**Objetivo:** work & study.

### Ejercicios 1–5 — Empareja / elige

Elige la **traducción o significado correcto** (ignora las distracciones).

1. work out → *entrenar · look forward · run out*
2. look forward to → *esperar con ilusión · take care · carry out*
3. run out of → *quedarse sin · deal with · work out*
4. take care of → *cuidar de · carry out · deal with*
5. carry out → *llevar a cabo · deal with · work out*

<details>
<summary>Ver solución</summary>

1. **entrenar** · 2. **esperar con ilusión** · 3. **quedarse sin** · 4. **cuidar de** · 5. **llevar a cabo**

</details>

### Ejercicios 6–10 — Completa / significado

Elige la opción que completa o explica mejor cada ítem.

1. work out ≈ ___ → *entrenar/resolver / esperar / quedarse sin*
2. look forward to + ___ → *-ing o noun / infinitivo / pasado*
3. run out of ≈ ___ → *quedarse sin / cuidar de / lidiar con*
4. take care of ≈ ___ → *cuidar de / buscar / mirar*
5. deal with ≈ ___ → *lidiar con / llevar a cabo / entrenar*

<details>
<summary>Ver solución</summary>

1. **entrenar/resolver** · 2. **-ing o noun** · 3. **quedarse sin** · 4. **cuidar de** · 5. **lidiar con**

</details>
