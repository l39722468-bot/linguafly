## Lección 1 — Gramática

**Objetivo:** had better / it's time + advice vocabulary

### Ejercicios 1–5 — Completa

1. You ___ better see a doctor. → *had / have / would*
2. It's time ___ go home. → *to / for / that*
3. It's time you ___ (start) studying. → *started / start / to start*
4. You had better ___ tell him yet. → *not / no / don't*
5. It's high time we ___ (make) a decision. → *made / make / to make*

<details>
<summary>Ver solución</summary>

1. **had** · 2. **to** · 3. **started** · 4. **not** · 5. **made**

</details>

### Ejercicios 6–10 — Elige / completa

1. had better + ___ → *bare infinitive / to infinitive / -ing*
2. it's time to + ___ → *infinitive / past / -ing*
3. it's time (that) + ___ → *past / infinitive / to*
4. it's time for + ___ → *noun / clause / duration*
5. had better ≈ ___ → *strong advice / preference / past habit*

<details>
<summary>Ver solución</summary>

1. **bare infinitive** · 2. **infinitive** · 3. **past** · 4. **noun** · 5. **strong advice**

</details>

### Ejercicios 11–15 — Corrige

1. *You had better to leave.*
2. *It's time you start.* (that-clause)
3. *It's time for go.*
4. *You better see a doctor.* (incomplete)
5. *It's high time we make.*

<details>
<summary>Ver solución</summary>

1. You had better **leave**.
2. It's time you **started**.
3. It's time **to go** / **for going**.
4. You **had** better see a doctor.
5. It's high time we **made** a decision.

</details>

## Lección 2 — Vocabulario

**Objetivo:** advice

### Ejercicios 1–5 — Empareja / elige

1. advice → *consejo · preference · phrasal*
2. advise → *aconsejar · prefer · deal*
3. warn → *advertir · urge · follow*
4. urge → *instar · suggest · disregard*
5. it's high time → *ya es hora (fuerte) · it's time · had better*

<details>
<summary>Ver solución</summary>

1. **consejo** · 2. **aconsejar** · 3. **advertir** · 4. **instar** · 5. **ya es hora (fuerte)**

</details>

### Ejercicios 6–10 — Completa

1. had better ≈ ___ → *más te vale / preferiría / no necesitas*
2. it's time to ≈ ___ → *ya es hora de / en lugar de / quedarse sin*
3. seek advice ≈ ___ → *pedir consejo / dar consejo / ignorar*
4. a piece of advice ≈ ___ → *un consejo / un advise / advices*
5. follow advice ≈ ___ → *seguir consejo / desatender / optar*

<details>
<summary>Ver solución</summary>

1. **más te vale** · 2. **ya es hora de** · 3. **pedir consejo** · 4. **un consejo** · 5. **seguir consejo**

</details>

## Lección 5 — Writing

**Objetivo:** producir frases con el foco de la unidad.

1. Escribe 3× had better / it's time.
2. Completa: You ___ better see a doctor.
3. Completa: It's time ___ go home.
4. Completa: It's time you ___ (start).
5. Completa: You had better ___ tell him.
6. Corrige: *You had better to leave.*
7. Corrige: *It's time you start.*
8. Usa it's high time y it's about time en 2 frases.
9. Escribe: You had better not tell him.
10. Mini-diálogo (4 frases) con advice.
11. Traduce: Más te vale ver a un médico.
12. Traduce: Ya es hora de ir a casa.
13. Explica had better vs it's time en 1 frase.
14. Escribe 1× it's time for + noun.
15. Autochequeo: had better sin to.

<details>
<summary>Ver solución</summary>

1. Open three.
2. **had**
3. **to**
4. **started**
5. **not**
6. had better **leave**
7. you **started**
8. Open.
9. OK.
10. Open.
11. You had better see a doctor.
12. It's time to go home.
13. had better=urgent advice; it's time=right moment.
14. OK.
15. Self-check.

</details>
