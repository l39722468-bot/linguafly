## Lección 1 — Gramática

**Objetivo:** practicar gerund/infinitive y phrasal verbs (mix U21–24).

### Ejercicios 1–5 — Completa

Elige la opción correcta. Solo una es válida.

1. I enjoy ___. → *cycling / to cycle / cycle*
2. She wants ___ a sofa. → *to buy / buying / buy*
3. Remember ___ off the lights. → *to turn / turning / turn*
4. Please fill ___ the form. → *in / out / up*
5. I found ___ the discount. → *out / up / in*

<details>
<summary>Ver solución</summary>

1. **cycling** · 2. **to buy** · 3. **to turn** · 4. **in** · 5. **out**

</details>

### Ejercicios 6–10 — Elige / completa

Completa cada frase con la forma correcta.

1. Don't give ___. → *up / out / in*
2. Turn ___ the lights. → *off / after / into*
3. We finished ___. → *painting / to paint / paint*
4. They decided ___ camping. → *to go / going / go*
5. Hand ___ the receipt. → *in / out / up*

<details>
<summary>Ver solución</summary>

1. **up** · 2. **off** · 3. **painting** · 4. **to go** · 5. **in**

</details>

### Ejercicios 11–15 — Corrige el error

Cada frase tiene **un** error. Reescribe la frase correcta.

1. *I enjoy to cycle.*
2. *She wants buying a sofa.*
3. *Remember turning off the lights.* (reminder)
4. *Find the discount.* (phrasal)
5. *Fill the form.*

<details>
<summary>Ver solución</summary>

1. I enjoy **cycling**.
2. She wants **to buy** a sofa.
3. Remember **to turn** off…
4. **Find out** the discount.
5. **Fill in** the form.

</details>

## Lección 2 — Vocabulario

**Objetivo:** hobbies, house, daily activities, shopping (mix).

### Ejercicios 1–5 — Empareja / elige

Elige la **traducción o significado correcto** (ignora las distracciones).

1. hiking → *senderismo · recibo · nevera*
2. fridge → *nevera · discount · hurry*
3. receipt → *recibo · camping · sofa*
4. look after → *cuidar · museum · refund*
5. find out → *averiguar · photography · garden*

<details>
<summary>Ver solución</summary>

1. **senderismo** · 2. **nevera** · 3. **recibo** · 4. **cuidar** · 5. **averiguar**

</details>

### Ejercicios 6–10 — Completa / significado

Elige la opción que completa o explica mejor cada ítem.

1. enjoy + ___ → *-ing / to / off*
2. want + ___ → *to / -ing / after*
3. remember (reminder) + ___ → *to / off / into*
4. turn ___ → *off/on / in / out*
5. fill ___ / hand ___ → *in / after / up*

<details>
<summary>Ver solución</summary>

1. **-ing** · 2. **to** · 3. **to** · 4. **off/on** · 5. **in**

</details>
