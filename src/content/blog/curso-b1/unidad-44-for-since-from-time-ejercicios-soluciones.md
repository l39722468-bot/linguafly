## Lección 1 — Gramática

**Objetivo:** for/since/from + time expressions

### Ejercicios 1–5 — Completa

1. I have lived here ___ 2015. → *since / for / from*
2. We have known each other ___ ten years. → *for / since / from*
3. The shop is open ___ 9am ___ 5pm. → *from … to / since … for / during … while*
4. She has been ill ___ Monday. → *since / for / from*
5. I haven't eaten ___ breakfast. → *since / for / from*

<details>
<summary>Ver solución</summary>

1. **since** · 2. **for** · 3. **from … to** · 4. **since** · 5. **since**

</details>

### Ejercicios 6–10 — Elige / completa

1. for + ___ → *duration / starting point / range end*
2. since + ___ → *starting point / duration / to*
3. from…to = ___ → *range / duration only / clause*
4. since 2015 → tense often ___ → *present perfect / past simple only / future*
5. for ten years counts ___ → *how long / when started / until when*

<details>
<summary>Ver solución</summary>

1. **duration** · 2. **starting point** · 3. **range** · 4. **present perfect** · 5. **how long**

</details>

### Ejercicios 11–15 — Corrige

1. *I have lived here for 2015.*
2. *We have known since ten years.*
3. *open since 9am to 5pm*
4. *ill for Monday* (starting point)
5. *from 2015* (duration until now, no to)

<details>
<summary>Ver solución</summary>

1. I have lived here **since** 2015.
2. We have known each other **for** ten years.
3. open **from** 9am **to** 5pm
4. ill **since** Monday
5. lived here **since** 2015 / **from** 2015 **to** now

</details>

## Lección 2 — Vocabulario

**Objetivo:** time expressions

### Ejercicios 1–5 — Empareja / elige

1. for ages → *mucho tiempo · depend · during*
2. all day → *todo el día · interested · while*
3. so far → *hasta ahora · afraid · look*
4. already → *ya · good · wait*
5. until → *hasta · proud · believe*

<details>
<summary>Ver solución</summary>

1. **mucho tiempo** · 2. **todo el día** · 3. **hasta ahora** · 4. **ya** · 5. **hasta**

</details>

### Ejercicios 6–10 — Completa

1. for ages = ___ → *long duration / starting point / noun event*
2. so far → tense ___ → *present perfect / only past / future*
3. from…to ≈ ___ → *range / duration / since*
4. by 5pm = ___ → *deadline / duration / since*
5. yet (neg/question) ≈ ___ → *todavía / durante / desde*

<details>
<summary>Ver solución</summary>

</details>

## Lección 5 — Writing

**Objetivo:** producir frases con el foco de la unidad.

1. Escribe 2× since + 2× for + 1× from…to.
2. Completa: lived here ___ 2015.
3. Completa: known each other ___ ten years.
4. Completa: open ___ 9am ___ 5pm.
5. Completa: ill ___ Monday.
6. Corrige: *lived here for 2015*
7. Corrige: *known since ten years*
8. Usa for ages y so far en 2 frases.
9. Escribe: I haven't eaten since breakfast.
10. Mini-diálogo (4 frases) con for/since/from.
11. Traduce: Vivo aquí desde 2015.
12. Traduce: La tienda abre de 9 a 5.
13. Explica for vs since en 1 frase.
14. Escribe 1× until.
15. Autochequeo: for=duration; since=point; from…to=range.

<details>
<summary>Ver solución</summary>

1. Open five.
2. **since**
3. **for**
4. **from** … **to**
5. **since**
6. **since** 2015
7. **for** ten years
8. Open.
9. OK.
10. Open.
11. I have lived here since 2015.
12. The shop is open from 9am to 5pm.
13. for=how long; since=when.
14. OK.
15. Self-check.

</details>
