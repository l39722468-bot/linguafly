## Lección 1 — Gramática

**Objetivo:** practicar third conditional (if + past perfect, would have).

### Ejercicios 1–5 — Completa

Elige la opción correcta. Solo una es válida.

1. If she ___ earlier, she would have arrived on time. → *had left / left / leaves*
2. We ___ the train if we had run. → *wouldn't have missed / wouldn't miss / won't miss*
3. If I had seen the warning, I ___. → *would have stopped / would stop / will stop*
4. They might have won if they ___ more. → *had practised / practised / practise*
5. If I ___ about the party, I would have come. → *had known / knew / know*

<details>
<summary>Ver solución</summary>

1. **had left** · 2. **wouldn't have missed** · 3. **would have stopped** · 4. **had practised** · 5. **had known**

</details>

### Ejercicios 6–10 — Elige / completa

Completa cada frase con la forma correcta.

1. If we ___ stayed up so late, we might have slept better. → *hadn't / didn't / don't*
2. If the teacher ___ us another day, we could have finished. → *had given / gave / gives*
3. He ___ have told you if he had seen you. → *would / will / can*
4. If I had taken the job, I ___ have moved to London. → *would / will / can*
5. If you had listened, you ___ have made that mistake. → *wouldn't / won't / don't*

<details>
<summary>Ver solución</summary>

1. **hadn't** · 2. **had given** · 3. **would** · 4. **would** · 5. **wouldn't**

</details>

### Ejercicios 11–15 — Corrige el error

Cada frase tiene **un** error. Reescribe la frase correcta.

1. *If I would have known…*
2. *I would passed.*
3. *If I knew about the party yesterday…* (pasado irreal)
4. *If she studied harder, she would have passed.*
5. *We would catch the train if we had left earlier.*

<details>
<summary>Ver solución</summary>

1. If I **had known**…
2. I **would have passed**.
3. If I **had known**…
4. If she **had studied** harder, she would have passed.
5. We **would have caught** the train if we had left earlier.

</details>

## Lección 2 — Vocabulario

**Objetivo:** regrets & past events.

### Ejercicios 1–5 — Empareja / elige

Elige la **traducción o significado correcto** (ignora las distracciones).

1. regret → *arrepentirse · reservar · soñar*
2. miss (a chance) → *perder (oportunidad) · ganar · empezar*
3. opportunity → *oportunidad · concierto · soleado*
4. mistake → *error · festival · streaming*
5. hindsight → *en retrospectiva · estreno · audience*

<details>
<summary>Ver solución</summary>

1. **arrepentirse** · 2. **perder (oportunidad)** · 3. **oportunidad** · 4. **error** · 5. **en retrospectiva**

</details>

### Ejercicios 6–10 — Completa / significado

Elige la opción que completa o explica mejor cada ítem.

1. I wish I had ≈ ___ → *ojalá hubiera / voy a / solía*
2. should have ≈ ___ → *debería haber / voy a / podría*
3. could have ≈ ___ → *podría haber / debe / will*
4. missed opportunity ≈ ___ → *oportunidad perdida / entrada VIP / picnic*
5. on time ≈ ___ → *a tiempo / tarde / nunca*

<details>
<summary>Ver solución</summary>

1. **ojalá hubiera** · 2. **debería haber** · 3. **podría haber** · 4. **oportunidad perdida** · 5. **a tiempo**

</details>
