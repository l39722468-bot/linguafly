## Lección 1 — Gramática

**Objetivo:** practicar verb/adj + preposition, during/for/while, for/since/from (mix U41–44).

### Ejercicios 1–5 — Completa

Elige la opción correcta. Solo una es válida.

1. I depend ___ my parents. → *on / in / for*
2. She's interested ___ art. → *in / on / at*
3. I fell asleep ___ the film. → *during / while / for*
4. I have lived here ___ 2015. → *since / for / from*
5. We waited ___ two hours. → *for / during / while*

<details>
<summary>Ver solución</summary>

1. **on** · 2. **in** · 3. **during** · 4. **since** · 5. **for**

</details>

### Ejercicios 6–10 — Elige / completa

Completa cada frase con la forma correcta.

1. depend on → ___ → *verb prep / adj prep / time*
2. interested in → ___ → *adj prep / during / since*
3. during the film → ___ → *time noun / duration / starting point*
4. since 2015 → ___ → *starting point / duration / range*
5. for two hours → ___ → *duration / point / noun event*

<details>
<summary>Ver solución</summary>

1. **verb prep** · 2. **adj prep** · 3. **time noun** · 4. **starting point** · 5. **duration**

</details>

### Ejercicios 11–15 — Corrige el error

Cada frase tiene **un** error. Reescribe la frase correcta.

1. *depend of my parents*
2. *interested on art*
3. *asleep while the film*
4. *lived here for 2015*
5. *waited during two hours*

<details>
<summary>Ver solución</summary>

1. depend **on** my parents
2. interested **in** art
3. asleep **during** the film
4. lived here **since** 2015
5. waited **for** two hours

</details>

1. depend on / listen to → *verb prep · only adj prep*
2. interested in / afraid of → *adj prep · only during*
3. during / for / while → *time trio · only since*
4. for / since / from → *time expressions · only verb prep*
5. apply / excited / moment / for ages → *vocab mix · wrong*

<details>
<summary>Ver solución</summary>

1. **verb prep** · 2. **adj prep** · 3. **time trio** · 4. **time expressions** · 5. **vocab mix**

</details>

### Ejercicios 6–10 — Completa / significado

1. depend on → ___ → *verb prep / adj prep / duration*
2. during + ___ → *noun / clause / duration*
3. since + ___ → *point / duration / to*
4. for + hours → ___ → *duration / point / noun event*
5. interested in → ___ → *adj prep / verb prep / while*

<details>
<summary>Ver solución</summary>

1. **verb prep** · 2. **noun** · 3. **point** · 4. **duration** · 5. **adj prep**

</details>
