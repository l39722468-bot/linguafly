Tras el [First conditional (U11)](/blog/curso-b1/unidad-11-first-conditional-weather), la **Unidad 12** (*Second Conditional*) te lleva a lo **imaginario**: *If I had…, I would…*

> **Practica:** [Unidad 12](/curso-b1/unit-12) · **Antes:** [U11](/blog/curso-b1/unidad-11-first-conditional-weather)

---

## Qué aprenderás

- **If + past, would + verb**
- *If I were you…* / *What if…?* / *In an ideal world…*
- Vocabulario: *imagine, wish, dream, ideal*

![Second conditional](/blog/curso-b1/unit-12/second-conditional.png)

---

## 1. Forma

| | |
| :--- | :--- |
| **If + past simple** | **would + infinitivo** |
| If I **had** a million dollars, | I **would** travel around the world. |
| If she **were** here, | she **would** help us. |
| If I **were** you, | I **would** apologize. |

## 7. Ejercicios

1. If I ___ a million dollars, I would travel. (*had*)  
2. If she ___ here, she would help. (*were*)  
3. If I were you, I ___ apologize. (*would*)  
4. *If I will have time, I would go* → If I **had** time, I **would** go.  
5. Vocab: imaginar = ___ · ojalá/desear = ___

<details><summary>Ver solución</summary>

1. **had** · 2. **were** · 3. **would** · 4. correction above · 5. **imagine** · **wish**
</details>

## Tip

Second = **no es un plan real**. Si puedes comprobarlo mañana con el tiempo, es first (U11).
