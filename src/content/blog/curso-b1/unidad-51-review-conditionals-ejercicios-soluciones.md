## Lección 1 — Gramática

**Objetivo:** first / second / third conditional + time clauses (U11–15 review)

### Ejercicios 1–5 — Completa

1. If it ___ tomorrow, we'll stay home. → *rains / will rain / rained*
2. If I ___ more time, I'd travel. → *had / have / would have*
3. If we ___ earlier, we would have caught the train. → *had left / left / would leave*
4. When I ___ work, I'll call you. → *finish / will finish / finished*
5. Unless you ___, you'll miss the bus. → *hurry / will hurry / hurried*

<details>
<summary>Ver solución</summary>

1. **rains** · 2. **had** · 3. **had left** · 4. **finish** · 5. **hurry**

</details>

### Ejercicios 6–10 — Elige / completa

1. First conditional: if + ___ → *present / past / will*
2. Second: if + ___ → would → *past / present / past perfect*
3. Third: if + past perfect → ___ → *would have + V3 / would + V / will have*
4. When/until + time clause: ___ → *present / will / past*
5. Unless ≈ ___ → *if not / if / when not*

<details>
<summary>Ver solución</summary>

1. **present** · 2. **past** · 3. **would have + V3** · 4. **present** · 5. **if not**

</details>

### Ejercicios 11–15 — Corrige

1. *If it will rain, we stay home.*
2. *If I would have time…*
3. *If we left earlier, we would catch.* (third)
4. *When I will finish work…*
5. *Unless you will hurry…*

<details>
<summary>Ver solución</summary>

1. If it **rains**, we'll stay home.
2. If I **had** time…
3. If we **had left** earlier, we **would have caught** the train.
4. When I **finish** work…
5. Unless you **hurry**…

</details>

## Lección 5 — Writing

**Objetivo:** producir frases con el foco de la unidad.

1. Escribe 1× first, second, third y time clause.
2. Completa: If it ___ tomorrow, we'll stay home.
3. Completa: If I ___ more time, I'd travel.
4. Completa: If we ___ earlier, we would have caught the train.
5. Completa: When I ___ work, I'll call you.
6. Corrige: *If it will rain, we stay home.*
7. Corrige: *If I would have time…*
8. Usa unless en 2 frases.
9. Escribe: If we had left earlier, we would have caught the train.
10. Mini-historia (4 frases) con 3 condicionales.
11. Traduce: Si llueve mañana, nos quedaremos en casa.
12. Traduce: Si hubiéramos salido antes, habríamos cogido el tren.
13. Explica first vs third en 1 frase.
14. Escribe 1× unless.
15. Autochequeo: no will en if-clause.

<details>
<summary>Ver solución</summary>

1. Open four.
2. **rains**
3. **had**
4. **had left**
5. **finish**
6. If it **rains**, we'll stay home.
7. If I **had** time…
8. Open.
9. OK.
10. Open.
11. If it rains tomorrow, we'll stay at home.
12. If we had left earlier, we would have caught the train.
13. First=probable future; third=past regret.
14. OK.
15. Self-check.

</details>
