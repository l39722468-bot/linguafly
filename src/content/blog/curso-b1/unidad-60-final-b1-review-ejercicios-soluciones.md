## Lección 1 — Gramática

**Objetivo:** full B1 grammar revision (all modules U1–60)

### Ejercicios 1–5 — Completa

1. If water ___ 100°C, it boils. → *reaches / reached / will reach*
2. The letter ___ sent yesterday. → *was / is / has been*
3. She ___ me she would come. → *told / said / asked*
4. If I ___ rich, I would travel. → *were / am / had been*
5. I ___ been living here since 2015. → *have / has / had*

<details>
<summary>Ver solución</summary>

1. **reaches** · 2. **was** · 3. **told** · 4. **were** · 5. **have**

</details>

### Ejercicios 6–10 — Elige / completa

1. If + present → present = ___ → *zero / first / second*
2. was sent → ___ → *passive / conditional / modal*
3. would come → ___ → *reported / conditional / tense*
4. If I were → ___ → *second / third / zero*
5. have been living → ___ → *PP continuous / past perfect / passive*

<details>
<summary>Ver solución</summary>

1. **zero** · 2. **passive** · 3. **reported** · 4. **second** · 5. **PP continuous**

</details>

### Ejercicios 11–15 — Corrige

1. *If water will reach 100°C…*
2. *The letter is sent yesterday.*
3. *She said me she would come.*
4. *If I was rich…*
5. *I have living here since 2015.*

<details>
<summary>Ver solución</summary>

1. If water **reaches** 100°C…
2. The letter **was sent** yesterday.
3. She **told me** she would come.
4. If I **were** rich…
5. I **have been living** here since 2015.

</details>

1. Una frase de cada área B1 (cond., passive, reported, modal, tense).

3. Completa: The letter ___ sent yesterday.
4. Completa: She ___ me she would come.
5. Completa: If I ___ rich, I would travel.
6. Completa: I ___ been living since 2015.
7. Corrige: *If I was rich…*
8. Corrige: *She said me she would come.*
9. Corrige: *I have living here since 2015.*

11. Matching: zero / passive / reported / second / PP cont.
12. Traduce: Si lo hubiera sabido antes, habría venido.

14. Escribe mensaje final: B1 complete 60/60.
