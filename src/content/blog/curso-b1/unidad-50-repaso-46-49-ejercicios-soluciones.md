## Lección 1 — Gramática

**Objetivo:** practicar had better, would rather, phrasal verbs, need/needn't (mix U46–49).

### Ejercicios 1–5 — Completa

Elige la opción correcta. Solo una es válida.

1. You ___ better see a doctor. → *had / have / would*
2. I'd ___ stay at home. → *rather / better / need*
3. We ran ___ of milk. → *out / off / away*
4. You ___ hurry. → *needn't / need / must*
5. It's time ___ go home. → *to / for / that*

<details>
<summary>Ver solución</summary>

1. **had** · 2. **rather** · 3. **out** · 4. **needn't** · 5. **to**

</details>

### Ejercicios 6–10 — Elige / completa

Completa cada frase con la forma correcta.

1. had better → ___ → *advice / preference / necessity*
2. would rather → ___ → *preference / advice / phrasal verb*
3. ran out of → ___ → *phrasal verb / modal / it's time*
4. needn't → ___ → *no necessity / preference / advice*
5. it's time to → ___ → *advice timing / preference / phrasal*

<details>
<summary>Ver solución</summary>

1. **advice** · 2. **preference** · 3. **phrasal verb** · 4. **no necessity** · 5. **advice timing**

</details>

### Ejercicios 11–15 — Corrige el error

Cada frase tiene **un** error. Reescribe la frase correcta.

1. *You had better to see a doctor.*
2. *I'd rather to stay.*
3. *We ran out milk.*
4. *You needn't to hurry.*
5. *It's time you go home.* (that-clause)

<details>
<summary>Ver solución</summary>

1. You had better **see** a doctor.
2. I'd rather **stay**.
3. We ran **out of** milk.
4. You needn't **hurry**.
5. It's time you **went** home / It's time **to go** home.

</details>

## Lección 2 — Vocabulario

**Objetivo:** advice, preferences, work & study, necessity (mix).

### Ejercicios 1–5 — Empareja / elige

2. would rather / would sooner → *preferences · needn't · had better*
3. work out / look forward to → *phrasal · advice · necessary*
4. need / needn't → *necessity · preference · carry out*
5. advice / preference / deal with / essential → *vocab mix · wrong*

</details>

</details>
