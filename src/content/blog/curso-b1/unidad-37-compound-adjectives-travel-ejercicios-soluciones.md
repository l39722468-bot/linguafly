## Lección 1 — Gramática

**Objetivo:** compound adjectives (two-day, 20-year-old…)

### Ejercicios 1–5 — Completa

1. a ___ trip (2 days) → *two-day / two-days / two day*
2. a ___ student (20 years) → *20-year-old / 20-years-old / 20 year old*
3. a ___ hotel → *well-known / well known / well-knowns*
4. a ___ flight → *long-distance / long distance / long-distances*
5. an ___ traveller → *open-minded / open minded / open-mind*

<details>
<summary>Ver solución</summary>

1. **two-day** · 2. **20-year-old** · 3. **well-known** · 4. **long-distance** · 5. **open-minded**

</details>

### Ejercicios 6–10 — Elige / completa

1. Compound before noun needs ___ → *hyphen / plural / comma*
2. a five-star hotel (not ___) → *five-stars / five-star / five star*
3. number + noun in compound → ___ form → *singular / plural / verb*
4. well-known describes ___ → *fame / feeling / purpose*
5. two-day modifies ___ → *trip / travels / travelling*

<details>
<summary>Ver solución</summary>

1. **hyphen** · 2. **five-stars** · 3. **singular** · 4. **fame** · 5. **trip**

</details>

### Ejercicios 11–15 — Corrige

1. *a two-days trip*
2. *a 20-years-old student*
3. *a well known hotel* (adj before noun)
4. *a long distance flight* (compound adj)
5. *five-stars hotel*

<details>
<summary>Ver solución</summary>

1. a **two-day** trip
2. a **20-year-old** student
3. a **well-known** hotel
4. a **long-distance** flight
5. a **five-star** hotel

</details>
