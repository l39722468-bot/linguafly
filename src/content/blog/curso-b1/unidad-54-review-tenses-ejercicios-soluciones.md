## Lección 1 — Gramática

**Objetivo:** practicar present perfect, PP continuous, past perfect, futures (U2–7 review).

### Ejercicios 1–5 — Completa

Elige la opción correcta. Solo una es válida.

1. I ___ lived here since 2015. → *have / has / am*
2. She ___ been studying all morning. → *has / have / is*
3. When I arrived, they ___ already left. → *had / have / were*
4. I ___ Paris last year. → *visited / have visited / had visited*
5. I'm ___ to visit my parents. → *going / go / will*

<details>
<summary>Ver solución</summary>

1. **have** · 2. **has** · 3. **had** · 4. **visited** · 5. **going**

</details>

### Ejercicios 6–10 — Elige / completa

Completa cada frase con la forma correcta.

1. Present perfect: have/has + ___ → *V3 / -ing / infinitive*
2. PP continuous: have/has been + ___ → *-ing / V3 / to*
3. Past perfect: had + ___ → *V3 / past / -ing*
4. since + ___ / for + duration → *point in time / duration / both*
5. Going to ≈ ___ → *plan / regret / passive*

<details>
<summary>Ver solución</summary>

1. **V3** · 2. **-ing** · 3. **V3** · 4. **point in time / duration** · 5. **plan**

</details>

### Ejercicios 11–15 — Corrige el error

Cada frase tiene **un** error. Reescribe la frase correcta.

1. *I have live here since 2015.*
2. *She has been study all morning.*
3. *When I arrived, they have left.*
4. *I have visited Paris last year.*
5. *I'm going visit my parents.*

<details>
<summary>Ver solución</summary>

1. I **have lived** here since 2015.
2. She **has been studying** all morning.
3. When I arrived, they **had** already left.
4. I **visited** Paris last year.
5. I'm **going to visit** my parents.

</details>

4. recently → *recientemente · ever · never*
5. duration → *duración · sequence · report*

<details>
