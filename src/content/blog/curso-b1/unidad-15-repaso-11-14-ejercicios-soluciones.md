## Lección 1 — Gramática

**Objetivo:** practicar first, second y third conditional + time clauses.

### Ejercicios 1–5 — Completa

Elige la opción correcta. Solo una es válida.

1. If it ___ sunny tomorrow, we'll walk. → *is / were / had been*
2. If I ___ you, I'd take an umbrella. → *were / am / had been*
3. If they ___ earlier, they would have got seats. → *had booked / booked / book*
4. We ___ out if it doesn't rain. → *will go / would go / went*
5. She ___ if she had known. → *would have called / would call / will call*

<details>
<summary>Ver solución</summary>

1. **is** · 2. **were** · 3. **had booked** · 4. **will go** · 5. **would have called**

</details>

### Ejercicios 6–10 — Elige / completa

Completa cada frase con la forma correcta.

1. If she studies, she ___ pass. (first) → *will / would / would have*
2. If she studied, she ___ pass. (second) → *would / will / would have*
3. If she had studied, she ___ passed. (third) → *would have / will / would*
4. When I ___, I will call you. → *arrive / will arrive / arrived*
5. If we ___ VIP tickets, we'd meet the band. → *had / have / had had*

<details>
<summary>Ver solución</summary>

1. **will** · 2. **would** · 3. **would have** · 4. **arrive** · 5. **had**

</details>

### Ejercicios 11–15 — Corrige el error

Cada frase tiene **un** error. Reescribe la frase correcta.

1. *If it will rain…*
2. *If I would have time…*
3. *I would passed.*
4. *If we leave now, we would catch the bus.* (plan real)
5. *If I had left earlier, I would arrive.* (pasado)

<details>
<summary>Ver solución</summary>

1. If it **rains**…
2. If I **had** time… / If I **had had** time…
3. I **would have passed**.
4. If we leave now, we **will** catch the bus.
5. If I had left earlier, I **would have arrived**.

</details>
