## Lección 1 — Gramática

**Objetivo:** need / needn't / needn't have + necessity

### Ejercicios 1–5 — Completa

1. You ___ hurry — we have time. → *needn't / need / mustn't*
2. I need ___ buy a ticket. → *to / for / -*
3. She needn't ___ bought a new one. → *have / to / -*
4. This needs ___ urgently. → *repairing / to repair / repair*
5. We needn't ___ booked the table. → *have / to / -*

<details>
<summary>Ver solución</summary>

1. **needn't** · 2. **to** · 3. **have** · 4. **repairing** · 5. **have**

</details>

### Ejercicios 6–10 — Elige / completa

1. needn't + ___ → *bare infinitive / to infinitive / -ing*
2. need (main verb) + ___ → *to infinitive / bare infinitive / -ing*
3. needn't have + ___ → *past participle / infinitive / -ing*
4. need + -ing = ___ → *passive meaning / active / future*
5. don't need to ≈ ___ → *needn't / mustn't / shouldn't*

<details>
<summary>Ver solución</summary>

1. **bare infinitive** · 2. **to infinitive** · 3. **past participle** · 4. **passive meaning** · 5. **needn't**

</details>

### Ejercicios 11–15 — Corrige

1. *You needn't to hurry.*
2. *I need buy a ticket.*
3. *She needn't bought.* (missing have)
4. *This needs to repairing.*
5. *We needn't to have booked.*

<details>
<summary>Ver solución</summary>

1. You needn't **hurry**.
2. I need **to** buy a ticket.
3. She needn't **have** bought a new one.
4. This needs **repairing**.
5. We needn't **have** booked the table.

</details>

## Lección 2 — Vocabulario

**Objetivo:** necessity

### Ejercicios 1–5 — Empareja / elige

1. necessity → *necesidad · preference · advice*
2. necessary → *necesario · unnecessary · optional*
3. unnecessary → *innecesario · essential · need*
4. essential → *esencial · optional · needn't*
5. optional → *opcional · necessary · must*

<details>
<summary>Ver solución</summary>

1. **necesidad** · 2. **necesario** · 3. **innecesario** · 4. **esencial** · 5. **opcional**

</details>

### Ejercicios 6–10 — Completa

1. needn't ≈ ___ → *no necesitas / debes / preferirías*
2. needn't have ≈ ___ → *no era necesario (pasado) / necesitas ahora / obligación*
3. need + -ing ≈ ___ → *necesita ser hecho / quiere hacer / ha hecho*
4. don't need to ≈ ___ → *needn't / mustn't / shouldn't*
5. in need of ≈ ___ → *necesitado de / preferencia por / consejo sobre*

<details>
<summary>Ver solución</summary>

1. **no necesitas** · 2. **no era necesario (pasado)** · 3. **necesita ser hecho** · 4. **needn't** · 5. **necesitado de**

</details>

## Lección 5 — Writing

**Objetivo:** producir frases con el foco de la unidad.

1. Escribe 2× needn't + 2× need to + 1× need + -ing.
2. Completa: You ___ hurry.
3. Completa: I need ___ buy a ticket.
4. Completa: She needn't ___ bought.
5. Completa: This needs ___ urgently.
6. Corrige: *You needn't to hurry.*
7. Corrige: *I need buy a ticket.*
8. Usa needn't have y unnecessary en 2 frases.
9. Escribe: We needn't have booked the table.
10. Mini-diálogo (4 frases) con need/needn't.
11. Traduce: No necesitas darte prisa.
12. Traduce: Necesito comprar un billete.
13. Explica needn't vs don't need to en 1 frase.
14. Escribe 1× essential.
15. Autochequeo: needn't sin to; need to con to.

<details>
<summary>Ver solución</summary>

1. Open five.
2. **needn't**
3. **to**
4. **have**
5. **repairing**
6. needn't **hurry**
7. need **to** buy
8. Open.
9. OK.
10. Open.
11. You needn't hurry.
12. I need to buy a ticket.
13. Similar meaning; needn't more formal/modal.
14. OK.
15. Self-check.

</details>
