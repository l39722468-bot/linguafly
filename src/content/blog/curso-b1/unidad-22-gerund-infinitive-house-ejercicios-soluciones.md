## Lección 1 — Gramática

**Objetivo:** practicar like/love/prefer; remember/forget/try (+ -ing or to).

### Ejercicios 1–5 — Completa

Elige la opción correcta. Solo una es válida.

1. Remember ___ the door. (reminder) → *to lock / locking / lock*
2. I remember ___ it. (memory) → *locking / to lock / lock*
3. I prefer ___ near a park. → *living / to live / live*
4. Try ___ the kitchen first. → *cleaning / to clean / clean*
5. I like ___ in the kitchen. → *cooking / to cook / cook*

<details>
<summary>Ver solución</summary>

1. **to lock** · 2. **locking** · 3. **living** · 4. **cleaning** · 5. **cooking**

</details>

### Ejercicios 6–10 — Elige / completa

Completa cada frase con la forma correcta.

1. She forgot ___ off the dishwasher. → *turning / to turn / turn*
2. Don't forget ___ the door. → *to lock / locking / lock*
3. We love ___ evenings in the garden. → *spending / to spend / spend*
4. Try ___ the vacuum cleaner. → *restarting / to restart / restart*
5. I prefer ___ in a quiet flat. → *living / to live / live*

<details>
<summary>Ver solución</summary>

1. **turning** · 2. **to lock** · 3. **spending** · 4. **restarting** · 5. **living**

</details>

### Ejercicios 11–15 — Corrige el error

Cada frase tiene **un** error. Reescribe la frase correcta.

1. *Remember locking the door.* (reminder)
2. *I remember to lock it yesterday.* (memory)
3. *Try to cleaning first.*
4. *She forgot to turning it off.*
5. *I prefer live near a park.*

<details>
<summary>Ver solución</summary>

1. Remember **to lock** the door.
2. I remember **locking** it.
3. Try **cleaning** / Try **to clean**…
4. She forgot **turning** / forgot **to turn**…
5. I prefer **living** / **to live**…

</details>
