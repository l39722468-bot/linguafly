## Lección 1 — Gramática

**Objetivo:** practicar passive, modal passive y reported speech (statements, questions, commands).

### Ejercicios 1–5 — Completa

Elige la opción correcta. Solo una es válida.

1. The app ___ updated every week. → *is / was / must*
2. The form ___ be completed. → *must / said / asked*
3. She said she ___ busy. → *was / is / be*
4. He asked ___ I was ready. → *if / to / was*
5. They told us ___ practise. → *to / if / not*

<details>
<summary>Ver solución</summary>

1. **is** · 2. **must** · 3. **was** · 4. **if** · 5. **to**

</details>

### Ejercicios 6–10 — Elige / completa

Completa cada frase con la forma correcta.

1. Files ___ uploaded yesterday. → *were / was / are*
2. The report ___ be sent today. → *should / said / asked*
3. Maya told me she ___ help. → *could / can / will*
4. The teacher asked if we ___ practised. → *had / have / has*
5. They told us ___ worry. → *not to / to / if*

<details>
<summary>Ver solución</summary>

1. **were** · 2. **should** · 3. **could** · 4. **had** · 5. **not to**

</details>

### Ejercicios 11–15 — Corrige el error

Cada frase tiene **un** error. Reescribe la frase correcta.

1. *She said me she was tired.*
2. *Must to be finished.*
3. *He asked where did I live.*
4. *The emails is sent.*
5. *Told us don't worry.*

<details>
<summary>Ver solución</summary>

1. She **told** me… / She **said**…
2. **Must be** finished.
3. He asked where I **lived**.
4. The emails **are** sent.
5. Told us **not to** worry.

</details>

4. attach → *adjuntar · translate · repair*
5. pronounce → *pronunciar · install · forward*

<details>
<summary>Ver solución</summary>

</details>

### Ejercicios 6–10 — Completa / significado

Elige la opción que completa o explica mejor cada ítem.

1. must be + V3 = ___ → *modal passive / first conditional / wish*

4. told to = ___ → *command / forecast / salary*
5. is/are + V3 = ___ → *present passive / second / gig*

<details>
<summary>Ver solución</summary>

1. **modal passive** · 2. **reported statement** · 3. **reported question** · 4. **command** · 5. **present passive**

</details>
