## Lección 1 — Gramática

**Objetivo:** practicar passive, would rather, relatives, comparatives, although.

### Ejercicios 1–5 — Completa

Elige la opción correcta. Solo una es válida.

1. This dress ___ made of cotton. → *is / was / makes*
2. I'd ___ wear blue. → *rather / better / prefer*
3. The shirt ___ I bought is too small. → *which / who / where*
4. This jacket is ___ expensive than that one. → *more / most / much*
5. ___ it was expensive, I bought it. → *Although / Because / Unless*

<details>
<summary>Ver solución</summary>

1. **is** · 2. **rather** · 3. **which** · 4. **more** · 5. **Although**

</details>

### Ejercicios 6–10 — Elige / completa

Completa cada frase con la forma correcta.

1. is made of = ___ → *passive present / active / past simple*
2. would rather + ___ → *bare inf / to inf / -ing*
3. which for things = ___ → *relative / passive / modal*
4. more + adj = ___ → *comparative / superlative / passive*
5. Although = ___ → *contrast / reason / condition*

<details>
<summary>Ver solución</summary>

1. **passive present** · 2. **bare inf** · 3. **relative** · 4. **comparative** · 5. **contrast**

</details>

### Ejercicios 11–15 — Corrige el error

Cada frase tiene **un** error. Reescribe la frase correcta.

1. *This dress was made of cotton.* (present fact)
2. *I'd rather to wear blue.*
3. *The shirt who I bought…*
4. *This jacket is expensiver…*
5. *Because it was expensive, I bought it.* (contrast)

<details>
<summary>Ver solución</summary>

1. This dress **is made of** cotton.
2. I'd **rather wear** blue.
3. The shirt **which** I bought…
4. This jacket is **more expensive**…
5. **Although** it was expensive, I bought it.

</details>

## Lección 2 — Vocabulario

**Objetivo:** clothes & colours.

### Ejercicios 1–5 — Empareja / elige

Elige la **traducción o significado correcto** (ignora las distracciones).

1. cotton → *algodón · leather · metal*
2. try on → *probarse · quitarse · guardar*
3. fashion → *moda · sport · food*
4. pale → *pálido · bright · dark*
5. accessories → *complementos · zapatos solo · abrigos*

<details>
<summary>Ver solución</summary>

1. **algodón** · 2. **probarse** · 3. **moda** · 4. **pálido** · 5. **complementos**

</details>

### Ejercicios 6–10 — Completa / significado

Elige la opción que completa o explica mejor cada ítem.

1. dark blue ≈ ___ → *tono profundo / tono claro / sin color*
2. match (v.) ≈ ___ → *combinar / rechazar / contrastar*
3. designer ≈ ___ → *crea ropa / vende comida / conduce*
4. leather ≈ ___ → *material animal / planta / plástico*
5. the most expensive = ___ → *superlativo / comparativo / pasiva*

<details>
<summary>Ver solución</summary>

1. **tono profundo** · 2. **combinar** · 3. **crea ropa** · 4. **material animal** · 5. **superlativo**

</details>
