## Lección 1 — Gramática

**Objetivo:** practicar although/however/despite + opinions.

### Ejercicios 1–5 — Completa

Elige la opción correcta. Solo una es válida.

1. ___ it was raining, we went out. → *Although / However / Despite*
2. I like it. ___, it's expensive. → *However / Although / Despite*
3. ___ I disagree, I respect you. → *Even though / However / Despite*
4. ___ the delay, we arrived. → *Despite / Although / However*
5. Though ≈ ___ → *Although / However / Because of*

<details>
<summary>Ver solución</summary>

1. **Although** · 2. **However** · 3. **Even though** · 4. **Despite** · 5. **Although**

</details>

### Ejercicios 6–10 — Elige / completa

Completa cada frase con la forma correcta.

1. although + ___ → *clause / noun only / comma phrase*
2. however position → *new sentence / mid-clause like although / before noun*
3. despite + ___ → *noun/-ing / full clause / verb*
4. even though ≈ ___ → *although (stronger) / however / so that*
5. In spite of ≈ ___ → *despite / although / however*

<details>
<summary>Ver solución</summary>

1. **clause** · 2. **new sentence** · 3. **noun/-ing** · 4. **although (stronger)** · 5. **despite**

</details>

### Ejercicios 11–15 — Corrige el error

Cada frase tiene **un** error. Reescribe la frase correcta.

1. *However it was raining, we went.*
2. *Although, it's expensive.* (second clause)
3. *Despite it was raining* (clause)
4. *Even though I disagree, however I respect.*
5. *Although the delay, we arrived.*

<details>
<summary>Ver solución</summary>

1. **Although** it was raining… / However, **it was raining.** (new sentence)
2. I like it. **However**, it's expensive.
3. **Despite the rain** / **Despite it raining**
4. Even though… (no however in same link)
5. **Despite the delay** / **Although there was a delay**

</details>

## Lección 2 — Vocabulario

**Objetivo:** opinions.

### Ejercicios 1–5 — Empareja / elige

Elige la **traducción o significado correcto** (ignora las distracciones).

1. agree → *estar de acuerdo · luggage · so*
2. disagree → *no estar de acuerdo · delay · such*
3. opinion → *opinión · passport · two-day*
4. convincing → *convincente · scenic · to*
5. fair → *justo · booking · because of*

<details>
<summary>Ver solución</summary>

1. **estar de acuerdo** · 2. **no estar de acuerdo** · 3. **opinión** · 4. **convincente** · 5. **justo**

</details>

### Ejercicios 6–10 — Completa / significado

Elige la opción que completa o explica mejor cada ítem.

1. point of view ≈ ___ → *punto de vista / retraso / guion*
2. support ≈ ___ → *apoyar / equipaje / intensidad*
3. doubt ≈ ___ → *duda / destino / compound*
4. unfair ≈ ___ → *injusto / vuelo / purpose*
5. in my view ≈ ___ → *en mi opinión / crowded / so much*

<details>
<summary>Ver solución</summary>

1. **punto de vista** · 2. **apoyar** · 3. **duda** · 4. **injusto** · 5. **en mi opinión**

</details>

### Ejercicios 11–15 — En contexto

Completa con una de estas palabras: *agree* · *disagree* · *opinion* · *convincing* · *fair*

13. Modelo: usa **opinion** en una frase corta.  
14. **convincing** (comprueba la tabla de vocabulario en la teoría).  
15. Continúa en **/curso-b1/unit-38**.

</details>
