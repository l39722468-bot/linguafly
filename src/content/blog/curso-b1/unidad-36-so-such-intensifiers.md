## Qué aprenderás

- **so + adj**
- **such (a/an) + noun**
- **so much / so many**
- Vocabulario: very, really, extremely…

![So such intensifiers B1](/blog/curso-b1/unit-36/so-such.png)

---

## 1. Mapa rápido

| Forma | Ejemplo |
| :--- | :--- |
| **so** + adj | I'm **so** tired. |
| **such a/an** + adj + noun | **such a** nice day |
| **so much** + uncountable | **so much** work |
| **so many** + countable | **so many** people |

## 7. Ejercicios

1. I'm ___ tired.  
2. It was ___ nice day.  
3. There is ___ work.  
4. There are ___ people.  
5. Vocab: extremadamente = ___

<details><summary>Ver solución</summary>

1. **so** · 2. **such a** · 3. **so much** · 4. **so many** · 5. **extremely**
</details>

---

## Tip del profesor

Tras *such* casi siempre hay **nombre** (*such a day*). Tras *so*, **adjetivo** (*so tired*).
