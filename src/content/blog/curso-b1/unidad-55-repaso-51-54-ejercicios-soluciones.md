## Lección 1 — Gramática

**Objetivo:** conditionals, passive/reported, modals, tenses (mix U51–54)

### Ejercicios 1–5 — Completa

1. If I ___ known, I would have told you. → *had / have / would*
2. The email ___ sent yesterday. → *was / is / has been*
3. She said she ___ call back. → *would / will / calls*
4. You ___ worry. → *needn't / need / mustn't*
5. I ___ been working here for five years. → *have / has / had*

<details>
<summary>Ver solución</summary>

1. **had** · 2. **was** · 3. **would** · 4. **needn't** · 5. **have**

</details>

### Ejercicios 6–10 — Elige / completa

1. If I had known → ___ → *third conditional / first / passive*
2. was sent → ___ → *passive / modal / conditional*
3. would call → ___ → *reported / conditional / tense*
4. needn't → ___ → *no necessity / deduction / tense*
5. have been working → ___ → *PP continuous / past perfect / passive*

<details>
<summary>Ver solución</summary>

1. **third conditional** · 2. **passive** · 3. **reported** · 4. **no necessity** · 5. **PP continuous**

</details>

### Ejercicios 11–15 — Corrige

1. *If I would have known…*
2. *The email is sent yesterday.*
3. *She said she will call.*
4. *You needn't to worry.*
5. *I have working here for five years.*

<details>
<summary>Ver solución</summary>

1. If I **had known**…
2. The email **was sent** yesterday.
3. She said she **would** call back.
4. You **needn't worry**.
5. I **have been working** here for five years.

</details>
