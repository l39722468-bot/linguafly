## Lección 1 — Gramática

**Objetivo:** practicar first vs second conditional (real vs hypothetical).

### Ejercicios 1–5 — Completa

Elige la opción correcta. Solo una es válida.

1. If we ___ time tonight, we'll watch a documentary. → *have / had / will have*
2. If I ___ a film director, I'd make a comedy. → *were / am / will be*
3. If the concert ___ at 8, we'll arrive at 7:30. → *starts / started / will start*
4. If we ___ VIP tickets, we'd be so happy. → *won / win / will win*
5. If you ___ to the party, you'll meet lots of people. → *come / came / will come*

<details>
<summary>Ver solución</summary>

1. **have** · 2. **were** · 3. **starts** · 4. **won** · 5. **come**

</details>

### Ejercicios 6–10 — Elige / completa

Completa cada frase con la forma correcta.

1. If the episode is boring, we ___ change series. → *will / would / are*
2. If I had a free evening, I ___ go to a gig. → *would / will / am*
3. If tickets are cheap, we ___ book now. → *will / would / are*
4. If I were you, I ___ avoid spoilers. → *would / will / am*
5. If concerts ___ free, everyone would go more. → *were / are / will be*

<details>
<summary>Ver solución</summary>

1. **will** · 2. **would** · 3. **will** · 4. **would** · 5. **were**

</details>

### Ejercicios 11–15 — Corrige el error

Cada frase tiene **un** error. Reescribe la frase correcta.

1. *If it will rain, we stay in.*
2. *If I would have time, I go.*
3. *If concerts are free, everyone would go.* (deseo irreal)
4. *If we leave early, we would get seats.* (plan real)
5. *If I had wings, I will fly.*

<details>
<summary>Ver solución</summary>

1. If it **rains**, we**'ll** stay in.
2. If I **had** time, I **would** go.
3. If concerts **were** free, everyone **would** go.
4. If we leave early, we **will** get seats.
5. If I had wings, I **would** fly.

</details>
