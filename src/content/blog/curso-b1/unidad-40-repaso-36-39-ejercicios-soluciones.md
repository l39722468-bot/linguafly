## Lección 1 — Gramática

**Objetivo:** practicar so/such, compounds, contrast y purpose/reason (mix U36–39).

### Ejercicios 1–5 — Completa

Elige la opción correcta. Solo una es válida.

1. It was ___ long journey. → *such a / so / such*
2. a ___ trip (2 days) → *two-day / two-days / two day*
3. ___ I was tired, I went out. → *Although / However / Despite*
4. I left early ___ catch the train. → *to / because of / although*
5. We stayed in ___ the rain. → *because of / so that / however*

<details>
<summary>Ver solución</summary>

1. **such a** · 2. **two-day** · 3. **Although** · 4. **to** · 5. **because of**

</details>

### Ejercicios 6–10 — Elige / completa

Completa cada frase con la forma correcta.

1. so/such → ___ → *intensifiers / contrast / purpose*
2. two-day → ___ → *compound adj / tag / because*
3. although → ___ → *contrast / intensifier / purpose*
4. to catch → ___ → *purpose / contrast / compound*
5. because of → ___ → *reason / intensifier / compound*

<details>
<summary>Ver solución</summary>

1. **intensifiers** · 2. **compound adj** · 3. **contrast** · 4. **purpose** · 5. **reason**

</details>

### Ejercicios 11–15 — Corrige el error

Cada frase tiene **un** error. Reescribe la frase correcta.

1. *so long journey*
2. *two-days trip*
3. *However I was tired, I went.*
4. *I left early because of catch the train.*
5. *We stayed in although the rain.*

<details>
<summary>Ver solución</summary>

1. **such a** long journey
2. **two-day** trip
3. **Although** I was tired…
4. I left early **to** catch…
5. We stayed in **because of** the rain

</details>

3. although/however/despite → *contrast · only purpose*
4. to/so that/because of → *purpose/reason · only compounds*
5. extremely / luggage / agree / purpose → *vocab mix · wrong*

<summary>Ver solución</summary>

</details>

### Ejercicios 6–10 — Completa / significado

Elige la opción que completa o explica mejor cada ítem.

1. such a → ___ → *intensifier / compound / contrast*
2. hyphen in compound? → *Yes / No / Only contrast*
3. however links clauses? → *No (new sentence) / Yes like although / Always*
4. so that + clause? → *Yes / No / Only noun*
5. because of + noun? → *Yes / No / Only infinitive*

<details>
<summary>Ver solución</summary>

1. **intensifier** · 2. **Yes** · 3. **No (new sentence)** · 4. **Yes** · 5. **Yes**

</details>
