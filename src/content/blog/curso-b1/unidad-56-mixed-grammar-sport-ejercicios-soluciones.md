## Lección 1 — Gramática

**Objetivo:** practicar mixed grammar B1 (conditionals, passive, modals, tenses, reported).

### Ejercicios 1–5 — Completa

Elige la opción correcta. Solo una es válida.

1. The match ___ cancelled due to rain. → *was / is / has been*
2. If you ___ more, you'd improve. → *practised / practice / had practised*
3. I ___ been playing since I was ten. → *have / has / had*
4. If they ___ harder, they would have won. → *had trained / trained / train*
5. She ___ me she had won. → *told / said / asked*

<details>
<summary>Ver solución</summary>

1. **was** · 2. **practised** · 3. **have** · 4. **had trained** · 5. **told**

</details>

### Ejercicios 6–10 — Elige / completa

Completa cada frase con la forma correcta.

1. was cancelled → ___ → *passive / first / modal*
2. If + past → would = ___ → *second / third / zero*
3. have been + -ing = ___ → *PP continuous / past perfect / passive*
4. had trained → would have = ___ → *third / second / reported*
5. told + person = ___ → *reported / passive / conditional*

<details>
<summary>Ver solución</summary>

1. **passive** · 2. **second** · 3. **PP continuous** · 4. **third** · 5. **reported**

</details>

### Ejercicios 11–15 — Corrige el error

Cada frase tiene **un** error. Reescribe la frase correcta.

1. *The match is cancelled due to rain.*
2. *If you will practise more…*
3. *I have playing since I was ten.*
4. *If they trained harder, they would have won.* (third)
5. *She said me she had won.*

<details>
<summary>Ver solución</summary>

1. The match **was cancelled** due to rain.
2. If you **practised** more…
3. I **have been playing** since I was ten.
4. If they **had trained** harder, they **would have won**.
5. She **told me** she had won.

</details>
