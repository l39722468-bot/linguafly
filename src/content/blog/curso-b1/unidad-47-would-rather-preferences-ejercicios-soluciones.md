## Lección 1 — Gramática

**Objetivo:** would rather / would sooner + preferences

### Ejercicios 1–5 — Completa

1. I'd rather ___ at home tonight. → *stay / to stay / staying*
2. I'd rather walk ___ take the bus. → *than / then / that*
3. I'd rather you ___ (not tell) him. → *didn't tell / don't tell / not tell*
4. I'd ___ not mention it. → *rather / sooner / prefer*
5. He'd ___ die than apologise. → *sooner / rather / prefer*

<details>
<summary>Ver solución</summary>

1. **stay** · 2. **than** · 3. **didn't tell** · 4. **rather** · 5. **sooner**

</details>

### Ejercicios 6–10 — Elige / completa

1. would rather + ___ → *bare infinitive / to infinitive / -ing*
2. would rather A ___ B → *than / then / that*
3. would rather (that) + ___ → *past / present / infinitive*
4. would sooner = ___ → *stronger preference / obligation / advice*
5. I'd rather you came ≈ ___ → *preference about another person / past fact / future plan*

<details>
<summary>Ver solución</summary>

1. **bare infinitive** · 2. **than** · 3. **past** · 4. **stronger preference** · 5. **preference about another person**

</details>

### Ejercicios 11–15 — Corrige

1. *I would rather to stay.*
2. *I'd rather walk then take the bus.*
3. *I'd rather you don't tell him.*
4. *I'd sooner to die.*
5. *I'd rather not to mention it.*

<details>
<summary>Ver solución</summary>

1. I would rather **stay**.
2. I'd rather walk **than** take the bus.
3. I'd rather you **didn't** tell him.
4. I'd sooner **die** than apologise.
5. I'd rather **not mention** it.

</details>

## Lección 2 — Vocabulario

**Objetivo:** preferences

### Ejercicios 1–5 — Empareja / elige

1. preference → *preferencia · necessity · advice*
2. prefer → *preferir · need · warn*
3. favourite → *favorito · first choice · opt for*
4. rather than → *en lugar de · than / then · instead of*
5. opt for → *optar por · choose · select*

<details>
<summary>Ver solución</summary>

1. **preferencia** · 2. **preferir** · 3. **favorito** · 4. **en lugar de** · 5. **optar por**

</details>

### Ejercicios 6–10 — Completa

1. would rather ≈ ___ → *preferiría / más te vale / necesitas*
2. would sooner ≈ ___ → *preferiría (más fuerte) / obligación / consejo*
3. I'd rather you didn't ≈ ___ → *preferiría que no / ya es hora / no necesitas*
4. first choice ≈ ___ → *primera opción / obligación / phrasal verb*
5. instead of ≈ ___ → *en lugar de / que (than) / para (for)*

<details>
<summary>Ver solución</summary>

1. **preferiría** · 2. **preferiría (más fuerte)** · 3. **preferiría que no** · 4. **primera opción** · 5. **en lugar de**

</details>

## Lección 5 — Writing

**Objetivo:** producir frases con el foco de la unidad.

1. Escribe 3× would rather / would sooner.
2. Completa: I'd rather ___ at home.
3. Completa: walk ___ take the bus.
4. Completa: I'd rather you ___ (not tell).
5. Completa: I'd ___ not mention it.
6. Corrige: *I would rather to stay.*
7. Corrige: *I'd rather you don't tell him.*
8. Usa would sooner y rather than en 2 frases.
9. Escribe: I'd rather walk than take the bus.
10. Mini-diario de preferencias (4 frases).
11. Traduce: Preferiría quedarme en casa.
12. Traduce: Preferiría que no se lo dijeras.
13. Explica would rather vs would prefer en 1 frase.
14. Escribe 1× would rather (that) + past.
15. Autochequeo: would rather sin to.

<details>
<summary>Ver solución</summary>

1. Open three.
2. **stay**
3. **than**
4. **didn't tell**
5. **rather**
6. would rather **stay**
7. you **didn't** tell him
8. Open.
9. OK.
10. Open.
11. I'd rather stay at home.
12. I'd rather you didn't tell him.
13. rather + bare inf; prefer + to.
14. OK.
15. Self-check.

</details>
