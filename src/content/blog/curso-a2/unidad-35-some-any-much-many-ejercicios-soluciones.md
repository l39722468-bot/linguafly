## Lección 1 — Gramática

**Objetivo:** some/any; much/many; a lot of; a few / a little.

### Ejercicios 1–5 — Completa

1. I bought ____ apples. *(afirmativa)* → *some / any / much*
2. We don't have ____ sugar. *(negativa)* → *any / some / many*
3. Do you have ____ questions? *(pregunta)* → *any / some / much*
4. Would you like ____ coffee? *(oferta)* → *some / any / many*
5. There isn't ____ time. *(negativa)* → *any / some / few*

<details>
<summary>Ver solución</summary>

1. **some** · 2. **any** · 3. **any** · 4. **some** · 5. **any**

</details>


### Ejercicios 6–10 — Elige

6. *Some* in normal affirmative: ____. → a) yes · b) never · c) only questions
7. *Any* in negatives/questions: ____. → a) typical · b) never with milk · c) only with -ing
8. *Many* goes with ____. → a) countable plural · b) uncountable only · c) no noun
9. *A little* + ____. → a) uncountable · b) countable plural only · c) always many
10. Unit 35 reviews ____. → a) quantities A2 · b) only phrasals · c) only Who called

<details>
<summary>Ver solución</summary>

6. **a) yes** · 7. **a) typical** · 8. **a) countable plural** · 9. **a) uncountable** · 10. **a) quantities A2**

</details>


### Ejercicios 11–15 — Corrige

11. *I have any bread.*
12. *How much apples do you want?*
13. *There is many water.*
14. *I need a few sugar.*
15. *Do you have some idea?* *(pregunta neutra)*

<details>
<summary>Ver solución</summary>

11. I have **some** bread.
12. How **many** apples do you want?
13. There is **a lot of** water. / There is **much** water.
14. I need **a little** sugar.
15. Do you have **any** idea?

</details>

## Lección 2 — Vocabulario

**Objetivo:** bread, eggs, milk, cheese, tomatoes, rice; countable vs uncountable.

### Ejercicios 1–5 — Empareja / elige

1. *bread* ≈ ____ → *uncountable · countable plural · subject Q*
2. *eggs* ≈ ____ → *countable · uncountable · phrasal*
3. *How many* ≈ ____ → *countable quantity · uncountable · polite wish*
4. *How much* ≈ ____ → *uncountable quantity · countable only · separable*
5. *a few* ≈ ____ → *small number (C) · little milk · subject only*

<details>
<summary>Ver solución</summary>

1. **uncountable** · 2. **countable** · 3. **countable quantity** · 4. **uncountable quantity** · 5. **small number (C)**

</details>


### Ejercicios 6–10 — Completa

6. How ____ eggs do we need? → *many / much / few*
7. How ____ milk is left? → *much / many / few*
8. There aren't ____ people here. → *many / much / little*
9. I don't have ____ money. → *much / many / few*
10. Can I have ____ milk in my tea? → *a little / a few / many*

<details>
<summary>Ver solución</summary>

6. **many** · 7. **much** · 8. **many** · 9. **much** · 10. **a little**

</details>


### Ejercicios 11–15 — Elige

11. *A lot of* works with ____. → a) countable & uncountable · b) only many · c) only subject Q
12. *A few tomatoes* = ____. → a) unos pocos · b) un poco de líquido · c) ninguno
13. Affirmative informal: prefer ____. → a) a lot of · b) much apples · c) any bread normal
14. *Would you like some tea?* uses ____. → a) some (offer) · b) any only · c) many
15. Unit 35 next is ____. → a) articles a/an/the · b) Module 6 only · c) skip U36

<details>
<summary>Ver solución</summary>

11. **a) countable & uncountable** · 12. **a) unos pocos** · 13. **a) a lot of** · 14. **a) some (offer)** · 15. **a) articles a/an/the**

</details>

## Lección 3 — Reading: Shopping list

**Objetivo:** comprender un texto con el foco de la unidad.

### Texto y audio

<audio controls preload="none" src="/audio/blog/curso-a2/unit-35/reading-quantifiers.mp3" title="🔊 Reading: Shopping list"></audio>

> We need some bread and some eggs. We don't have any milk. How much cheese do we need? Just a little. How many tomatoes? A few — maybe four. There's a lot of rice already, so we don't need any more.

### Ejercicios 1–5 — Comprensión

1. Need to buy? → a) Bread and eggs · b) Only rice · c) Only milk
2. Milk at home? → a) Don't have any · b) Have some · c) A lot of milk
3. Cheese needed? → a) Just a little · b) A few · c) Many people
4. Tomatoes? → a) A few — maybe four · b) A lot of rice · c) Any more
5. Rice? → a) Already a lot — no more · b) Need any more · c) None at all

<details>
<summary>Ver solución</summary>

1. **a) Bread and eggs** · 2. **a) Don't have any** · 3. **a) Just a little** · 4. **a) A few — maybe four** · 5. **a) Already a lot — no more**

</details>


### Ejercicios 6–10 — Detalles

6. *Don't have any milk* is ____. → a) negative + any · b) some affirmative · c) subject Q
7. *How much cheese* = ____. → a) uncountable Q · b) countable Q · c) Who called
8. *A few tomatoes* = ____. → a) countable small amount · b) a little milk · c) hate waiting
9. *A lot of rice* means ____. → a) much rice already · b) no rice · c) pick up bag
10. Matches unit 35: ____. → a) yes · b) no · c) only U31

<details>
<summary>Ver solución</summary>

6. **a) negative + any** · 7. **a) uncountable Q** · 8. **a) countable small amount** · 9. **a) much rice already** · 10. **a) yes**

</details>


### Ejercicios 11–15 — Forma

11. *Some* + bread (affirm.): ____. → a) natural · b) always any · c) never
12. *How many* + ____. → a) countable plural · b) water only · c) happened
13. Pair: many apples / ____. → a) much water · b) Who did you call · c) turn it off
14. Reading marks ____. → a) quantifiers · b) only phrasals · c) only -ing
15. List writing uses ____. → a) some/any/much/many · b) only did · c) only could

<details>
<summary>Ver solución</summary>

11. **a) natural** · 12. **a) countable plural** · 13. **a) much water** · 14. **a) quantifiers** · 15. **a) some/any/much/many**

</details>
