## Lección 1 — Gramática

**Objetivo:** I like (gusto) vs I'd like (pedido); Would you like…? vs Do you like…?

### Ejercicios 1–5 — Completa

1. I ____ chocolate. *(gusto general)* → *like / would like / likes*
2. ____ a tea, please. *(pedido)* → *I like / I'd like / Do you like*
3. ____ you like some cake? *(oferta)* → *Do / Would / Are*
4. She ____ reading in the evening. *(hábito)* → *likes / would like / like*
5. We'd ____ to book a table. → *like / likes / liking*

<details>
<summary>Ver solución</summary>

1. **like** · 2. **I'd like** · 3. **Would** · 4. **likes** · 5. **like**

</details>


### Ejercicios 6–10 — Elige

6. *I like* = gusto ____. → a) habitual · b) pedido ahora · c) solo oferta
7. *I'd like* suena más ____. → a) educado que I want · b) que must · c) que Who called
8. *Do you like tea?* pregunta por ____. → a) gusto general · b) oferta ahora · c) subject Q
9. Respuesta a *Would you like cake?*: ____. → a) Yes, please · b) Yes, I like · c) Yes, I do
10. Unit 37 follows ____. → a) articles U36 · b) Module 6 only · c) skip U38

<details>
<summary>Ver solución</summary>

6. **a) habitual** · 7. **a) educado que I want** · 8. **a) gusto general** · 9. **a) Yes, please** · 10. **a) articles U36**

</details>


### Ejercicios 11–15 — Corrige

11. *I like a coffee, please.*
12. *Do you like some juice?* *(oferta)*
13. *I'd like swimming now.*
14. *I would like go home.*
15. *Would you like coffee?* *(pregunta de gusto general)*

<details>
<summary>Ver solución</summary>

11. I'd like a coffee, please.
12. Would you like some juice?
13. I'd like to swim. / I like swimming.
14. I'd like to go home.
15. Do you like coffee?

</details>

## Lección 2 — Vocabulario

**Objetivo:** coffee, tea, hot chocolate, cake, cheesecake, menu, soup, pasta, water, bill.

### Ejercicios 1–5 — Empareja / elige

1. *hot chocolate* ≈ ____ → *bebida caliente · paraguas · estación*
2. *cheesecake* ≈ ____ → *postre · sopa · billete*
3. *bill* ≈ ____ → *cuenta · menú · mesa*
4. *tomato soup* ≈ ____ → *entrante · té · parque*
5. *quiet places* ≈ ____ → *lugares tranquilos · phrasal · subject Q*

<details>
<summary>Ver solución</summary>

1. **bebida caliente** · 2. **postre** · 3. **cuenta** · 4. **entrante** · 5. **lugares tranquilos**

</details>


### Ejercicios 6–10 — Completa

6. I'd like ____ cappuccino, please. → *a / an / the*
7. ____ you like some milk with that? → *Do / Would / Are*
8. Leo ____ strong coffee. *(gusto)* → *likes / would like / like*
9. Ana ____ like a hot chocolate today. → *would / likes / do*
10. Two ____, please. *(bebida)* → *waters / water / a water*

<details>
<summary>Ver solución</summary>

6. **a** · 7. **Would** · 8. **likes** · 9. **would** · 10. **waters**

</details>


### Ejercicios 11–15 — Elige

11. *Sweet desserts* — Leo doesn't like = ____. → a) gusto negativo · b) pedido · c) should
12. *Would you like a table for two?* = ____. → a) oferta camarero · b) gusto general · c) Who called
13. *I'd like to have the pasta* uses ____. → a) to + infinitivo · b) -ing only · c) did
14. *Ready to order* context: ____. → a) restaurante · b) parque · c) examen
15. Unit 37 next is ____. → a) should/ought to · b) Module 6 only · c) skip U38

<details>
<summary>Ver solución</summary>

11. **a) gusto negativo** · 12. **a) oferta camarero** · 13. **a) to + infinitivo** · 14. **a) restaurante** · 15. **a) should/ought to**

</details>

## Lección 3 — Reading: At the café

**Objetivo:** comprender un texto con el foco de la unidad.

### Texto y audio

<audio controls preload="none" src="/audio/blog/curso-a2/unit-37/reading-would-like.mp3" title="🔊 Reading: At the café"></audio>

> Ana and Leo are at a café after class.
>
> Ana likes quiet places. Today she would like a hot chocolate. Leo likes strong coffee, but today he'd like a tea because it's late. The waiter asks: "Would you like some cake?" Ana says yes — she'd like a piece of cheesecake. Leo doesn't like sweet desserts, so he says "No, thank you."

### Ejercicios 1–5 — Comprensión

1. Where are they? → a) At a café · b) At school · c) In the park
2. Ana likes ____. → a) Quiet places · b) Loud music · c) Sweet desserts
3. Ana wants today? → a) Hot chocolate · b) Strong coffee · c) Cheesecake only
4. Leo wants today? → a) Tea · b) Coffee · c) Soup
5. Who wants cake? → a) Ana — cheesecake · b) Leo · c) Neither

<details>
<summary>Ver solución</summary>

1. **a) At a café** · 2. **a) Quiet places** · 3. **a) Hot chocolate** · 4. **a) Tea** · 5. **a) Ana — cheesecake**

</details>


### Ejercicios 6–10 — Detalles

6. *Ana likes quiet places* = ____. → a) gusto habitual · b) pedido · c) should
7. *She would like a hot chocolate* = ____. → a) deseo ahora · b) gusto general · c) Who called
8. *Would you like some cake?* = ____. → a) oferta · b) Do you like · c) subject Q
9. Leo says *No, thank you* because ____. → a) doesn't like sweet desserts · b) likes cheesecake · c) wants coffee
10. Matches unit 37: ____. → a) yes · b) no · c) only U31

<details>
<summary>Ver solución</summary>

6. **a) gusto habitual** · 7. **a) deseo ahora** · 8. **a) oferta** · 9. **a) doesn't like sweet desserts** · 10. **a) yes**

</details>


### Ejercicios 11–15 — Forma

11. *He'd like* = ____. → a) he would like · b) he did like · c) he likes always
12. *I'd like a piece of cheesecake* = ____. → a) pedido concreto · b) gusto general · c) any milk
13. *Leo likes strong coffee* + *he'd like tea* shows ____. → a) contraste gusto/pedido · b) only articles · c) only phrasals
14. Reading marks ____. → a) like vs would like · b) only the · c) only much
15. Café writing uses ____. → a) I'd like / Would you like · b) only did · c) only should

<details>
<summary>Ver solución</summary>

11. **a) he would like** · 12. **a) pedido concreto** · 13. **a) contraste gusto/pedido** · 14. **a) like vs would like** · 15. **a) I'd like / Would you like**

</details>

## Lección 4 — Listening: Ordering

**Objetivo:** escuchar el foco gramatical en contexto.

### Audio y guion

<audio controls preload="none" src="/audio/blog/curso-a2/unit-37/listening-would-like.mp3" title="🔊 Listening: Ordering"></audio>

> Waiter: Good evening. Would you like a table for two?  
> Ana: Yes, please.  
> Waiter: Are you ready to order?  
> Leo: I'd like the tomato soup, please.  
> Ana: I'd like to have the pasta.  
> Waiter: Would you like something to drink?  
> Ana: Two waters, please.  
> Leo: And I'd like the bill later — not now.

### Ejercicios 1–5 — Comprensión

1. Table for? → a) Two · b) Three · c) One
2. Leo orders ____. → a) Tomato soup · b) Pasta · c) Cake
3. Ana orders ____. → a) Pasta · b) Soup · c) Coffee
4. Drinks? → a) Two waters · b) Tea · c) Hot chocolate
5. Bill? → a) Later — not now · b) Now · c) No bill

<details>
<summary>Ver solución</summary>

1. **a) Two** · 2. **a) Tomato soup** · 3. **a) Pasta** · 4. **a) Two waters** · 5. **a) Later — not now**

</details>


### Ejercicios 6–10 — Detalles

6. First line uses ____. → a) Would you like (oferta) · b) Do you like · c) Who called
7. *I'd like the tomato soup* = ____. → a) pedido educado · b) gusto · c) should
8. *I'd like to have the pasta* = ____. → a) would like + to · b) like -ing only · c) any some
9. *Would you like something to drink?* = ____. → a) oferta · b) gusto general · c) subject Q
10. Unit 37 practice: ____. → a) yes · b) no · c) only Module 6

<details>
<summary>Ver solución</summary>

6. **a) Would you like (oferta)** · 7. **a) pedido educado** · 8. **a) would like + to** · 9. **a) oferta** · 10. **a) yes**

</details>


### Ejercicios 11–15 — Forma

11. Offer: ____ you like a table? → a) Would · b) Do · c) Are
12. Order: I'd ____ the soup. → a) like · b) likes · c) liking
13. *The bill later* = I'd like ____. → a) bill (pedido) · b) like bill · c) should bill
14. Shadow and note ____. → a) like / would like · b) only a/an · c) only phrasals
15. U37 closes before ____. → a) should U38 · b) Module 6 only · c) U31 skip

<details>
<summary>Ver solución</summary>

11. **a) Would** · 12. **a) like** · 13. **a) bill (pedido)** · 14. **a) like / would like** · 15. **a) should U38**

</details>

## Lección 5 — Writing

**Objetivo:** producir frases con el foco de la unidad.

### Ejercicios 1–5 — Completa

1. I ____ tea. *(gusto)* → *like / would like / likes*
2. ____ a sandwich, please. → *I like / I'd like / Would you like*
3. ____ you like some water? *(oferta)* → *Do / Would / Are*
4. I'd like ____ (sit) near the window. → *sit / to sit / sitting*
5. She ____ spicy food. *(no gusto)* → *doesn't like / wouldn't like / don't like*

<details>
<summary>Ver solución</summary>

1. **like** · 2. **I'd like** · 3. **Would** · 4. **to sit** · 5. **doesn't like**

</details>


### Ejercicios 6–8 — Ordena

6. I'd / like / a / coffee, / please.
7. Would / you / like / some / cake?
8. Do / you / like / Italian / food?

<details>
<summary>Ver solución</summary>

6. I'd like a coffee, please.
7. Would you like some cake?
8. Do you like Italian food?

</details>


### Ejercicios 9–15 — Escribe (modelos)

9. Una frase con *I like* + sustantivo.
10. Una frase con *I'd like* + sustantivo (pedido).
11. Una pregunta *Do you like…?*
12. Una pregunta *Would you like…?* (oferta).
13. Una frase con *I'd like to* + verbo.
14. Reescribe de forma educada: *I want a coffee.*
15. Diálogo en un café (8–10 líneas) con I'd like, Would you like e I like.

<details>
<summary>Ver solución</summary>

9. I like tea. / Leo likes strong coffee.
10. I'd like a tea, please. / Today she would like a hot chocolate.
11. Do you like spicy food?
12. Would you like some cake?
13. I'd like to have the pasta. / I'd like to sit near the window.
14. I'd like a coffee, please.
15. Waiter: Would you like a table for two? Ana: Yes, please. Leo: I'd like the tomato soup, please. Ana: I'd like to have the pasta. Waiter: Would you like something to drink? Ana: Two waters, please. Leo: I like strong coffee, but today I'd like a tea.

</details>
