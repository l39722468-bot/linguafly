## Qué aprenderás en la Unidad 37 (A2)

- Usar **I like** para gustos generales.
- Usar **I'd like** / **I would like** para deseos y pedidos educados.
- Preguntar y ofrecer con **Would you like…?**
- Pedir en **restaurante, tienda e invitaciones**.
- Evitar errores típicos (*I like a coffee, please* / *Do you like some tea?*).

## 1. Idea clave: gusto vs deseo

| | *like* | *would like* (*I'd like*) |
| :--- | :--- | :--- |
| Significado | gusto / preferencia habitual | deseo o petición **ahora** (educado) |
| Pregunta típica | Do you **like**…? | **Would** you **like**…? |
| Ejemplo | I **like** tea. | I'd **like** a tea, please. |

> I **like** coffee. *(en general)*  
> I'd **like** a coffee. *(pido uno ahora)*

## 2. *I like* — gustos habituales

Usa *like* para decir qué te gusta **en general** (comida, ocio, actividades).

| Forma | Ejemplo |
| :--- | :--- |
| Affirmative | I **like** pizza. / She **likes** jazz. |
| Negative | I **don't like** waiting. |
| Question | **Do** you **like** spicy food? |

Con actividades, en A2 es muy frecuente **like + -ing**:

> I **like swimming**.  
> They **like watching** films.

(Repaso más amplio en la [Unidad 33](/blog/curso-a2/unidad-33-gerunds-infinitives).)

## 3. *I'd like* — deseo o pedido educado

*I would like* / *I'd like* suena **más educado** que *I want*. Úsalo para pedir, encargar o expresar un deseo concreto.

| Forma | Ejemplo |
| :--- | :--- |
| + sustantivo | I'd **like** a sandwich, please. |
| + **to** + verbo | I'd **like to** sit near the window. |
| Negative | I **wouldn't like** a spicy dish. |
| Question (oferta) | **Would you like** some water? |

> I'd **like to order** the soup.  
> We'd **like** the bill, please.

## 4. *Would you like…?* ≠ *Do you like…?*

| Pregunta | Función | Respuesta típica |
| :--- | :--- | :--- |
| **Do you like** tea? | ¿Te gusta el té *(en general)*? | Yes, I do. / No, I don't. |
| **Would you like** some tea? | ¿Quieres té *(ahora / oferta)*? | Yes, please. / No, thank you. |

Mezclarlas es un error muy común de hispanohablantes:

~~Do you like some tea?~~ → **Would you like some tea?**  
~~Would you like coffee?~~ *(si preguntas gusto general)* → **Do you like coffee?**

## 5. En el café, la tienda y las invitaciones

### Café / restaurante

> **Customer:** I'd **like** a cappuccino, please.  
> **Waiter:** **Would you like** some milk with that?  
> **Customer:** Yes, please. And I'd **like to** see the dessert menu.

### Tienda

> I'd **like** this shirt in medium.  
> **Would you like** a bag?

### Invitaciones

> **Would you like to** come to my party on Saturday?  
> Yes, I'd **love to**. / Sorry, I can't.

## 6. Mapa rápido

| Quieres decir… | Usa… | Ejemplo |
| :--- | :--- | :--- |
| Gusto habitual | like (+ noun / -ing) | I **like** pasta. / I **like cooking**. |
| Pedido / deseo ahora | I'd like (+ noun / to + V) | I'd **like** pasta. / I'd **like to cook** tonight. |
| Oferta / invitación | Would you like…? | **Would you like** dessert? |
| Gusto (pregunta) | Do you like…? | **Do you like** spicy food? |

## 7. Lectura y diálogo

### Lectura — At the café

Ana and Leo are at a café after class.

Ana **likes** quiet places. Today she **would like** a hot chocolate. Leo **likes** strong coffee, but today he'd **like** a tea because it's late. The waiter asks: “**Would you like** some cake?” Ana says yes — she'd **like** a piece of cheesecake. Leo **doesn't like** sweet desserts, so he says “No, thank you.”

<audio controls preload="none" src="/audio/blog/curso-a2/unit-37/reading-cafe.mp3" title="🔊 Reading: At the café"></audio>

### Diálogo — Ordering

**Waiter:** Good evening. **Would you like** a table for two?  
**Ana:** Yes, please.  
**Waiter:** Are you ready to order?  
**Leo:** I'd **like** the tomato soup, please.  
**Ana:** I'd **like to** have the pasta.  
**Waiter:** **Would you like** something to drink?  
**Ana:** Two waters, please.  
**Leo:** And I'd **like** the bill later — not now.

### Mini práctica (escucha)

Escucha y completa mentalmente:

1. I ___ coffee. *(gusto)*  
2. I'd ___ a coffee, please. *(pedido)*  
3. ___ you like some cake? *(oferta)*  
4. Do you ___ spicy food? *(gusto)*

## 8. Errores frecuentes

1. ~~I like a coffee, please.~~ → **I'd like a coffee, please.** *(pedido)*  
2. ~~Do you like some tea?~~ → **Would you like some tea?** *(oferta)*  
3. ~~I'd like swimming.~~ → **I'd like to swim.** / **I like swimming.**  
4. ~~I would like go now.~~ → **I'd like to go** now.  
5. ~~Would you like coffee?~~ *(si es gusto general)* → **Do you like coffee?**  
6. ~~Yes, I like~~ *(respuesta a Would you like…?)* → **Yes, please.** / **Yes, I'd love one.**

## 9. Ejercicios (con soluciones)

### Ejercicio 1 — Elige *like* o *would like*

1. I ___ chocolate ice cream. *(en general)*  
2. ___ a bottle of water, please.  
3. She ___ reading in the evening.  
4. We ___ to book a table for 8 pm.

<details>
<summary>Soluciones</summary>

1. like  
2. I'd like / I would like  
3. likes / like  
4. 'd like / would like  

</details>

### Ejercicio 2 — *Do you like* o *Would you like*

1. ___ football? *(gusto general)*  
2. ___ some more rice? *(oferta en la mesa)*  
3. ___ to come with us tomorrow? *(invitación)*  
4. ___ Italian food? *(preferencia)*

<details>
<summary>Soluciones</summary>

1. Do you like  
2. Would you like  
3. Would you like  
4. Do you like  

</details>

### Ejercicio 3 — Completa con la forma correcta del verbo

1. I like ___ (cook) at weekends.  
2. I'd like ___ (cook) dinner tonight.  
3. They like ___ (travel).  
4. She'd like ___ (visit) Lisbon.

<details>
<summary>Soluciones</summary>

1. cooking  
2. to cook  
3. travelling / traveling  
4. to visit  

</details>

### Ejercicio 4 — Corrige el error

1. I like a sandwich, please.  
2. Do you like some juice?  
3. I'd like going home now.  
4. Would you like coffee? *(pregunta de gusto general)*  
5. I would like buy this bag.

<details>
<summary>Soluciones</summary>

1. I'd like a sandwich, please.  
2. Would you like some juice?  
3. I'd like to go home now. / I like going home.  
4. Do you like coffee?  
5. I'd like to buy this bag.  

</details>

### Ejercicio 5 — Traduce al inglés

1. Me gusta el té.  
2. Querría un té, por favor.  
3. ¿Te gusta el té?  
4. ¿Quieres té? *(oferta)*  
5. Me gustaría sentarme aquí.

<details>
<summary>Soluciones</summary>

1. I like tea.  
2. I'd like a tea, please. / I would like a tea, please.  
3. Do you like tea?  
4. Would you like some tea? / Would you like tea?  
5. I'd like to sit here.  

</details>

### Ejercicio 6 — Diálogo del restaurante

Completa:

**A:** ___ you like to see the menu?  
**B:** Yes, please. I ___ the grilled fish.  
**A:** ___ you like a salad with that?  
**B:** No, thank you. I don't ___ salad very much.

<details>
<summary>Soluciones</summary>

Would  
'd like / would like  
Would  
like  

</details>

### Ejercicio 7 — Empareja

1. I like dancing.  
2. I'd like to dance.  
3. Do you like dancing?  
4. Would you like to dance?  

a) invitación / oferta ahora  
b) gusto habitual  
c) pregunta sobre gusto  
d) deseo de bailar (ahora / plan)

<details>
<summary>Soluciones</summary>

1 → b  
2 → d  
3 → c  
4 → a  

</details>

### Ejercicio 8 — Elige la respuesta natural

**Would you like some cake?**

a) Yes, I like.  
b) Yes, please.  
c) Yes, I do.

<details>
<summary>Soluciones</summary>

b  

</details>

### Ejercicio 9 — Reescribe de forma más educada

1. I want a coffee.  
2. Give me the menu.  
3. Do you want water? *(como camarero)*  
4. I want to pay now.

<details>
<summary>Soluciones</summary>

1. I'd like a coffee (, please).  
2. I'd like the menu (, please). / Could I have the menu, please?  
3. Would you like some water?  
4. I'd like to pay now (, please).  

</details>

### Ejercicio 10 — Tu diálogo (8–12 líneas)

Escribe un diálogo en un café entre un cliente y un camarero. Incluye:

- al menos **2** *I'd like*  
- al menos **1** *Would you like…?*  
- al menos **1** *I like* / *I don't like* (gusto)

**Modelo:** el diálogo de la sección 7.

## 10. Plan de estudio (25–30 minutos)

1. **5 min** — Tabla *like* vs *would like*.  
2. **8 min** — Ejercicios 1–6.  
3. **7 min** — Escucha lectura y diálogo; marca cada *like* / *would like*.  
4. **5–8 min** — Escribe el Ejercicio 10 en voz alta.

### Checklist

- [ ] Sé cuándo uso **I like** (gusto)  
- [ ] Sé cuándo uso **I'd like** (pedido / deseo)  
- [ ] Distingo **Do you like…?** y **Would you like…?**  
- [ ] Uso **I'd like to + verbo** correctamente  
- [ ] Respondo ofertas con *Yes, please* / *No, thank you*

## 11. Consejos y siguiente paso

1. Traduce mentalmente: ¿es **me gusta** o **querría / me gustaría pedir**?  
2. En servicios (café, tienda, hotel), prioriza **I'd like** y **Would you like**.  
3. Practica en el [cuaderno de ejercicios de la Unidad 37](/blog/curso-a2/unidad-37-would-like-vs-like-ejercicios-soluciones) y en la [Unidad 37 del curso A2](/curso-a2/unit-37).
