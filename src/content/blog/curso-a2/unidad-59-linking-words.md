faqs:
  - question: ¿Cuál es la diferencia entre but y although?
    answer: >-
      Ambos contrastan. But une dos ideas en el mismo nivel: It's cold, but
      sunny. Although introduce una idea contrastiva (a menudo al inicio):
      Although it's cold, it's sunny.
  - question: ¿Because o so?
    answer: >-
      Because = causa (por qué). So = consecuencia (resultado). I stayed home
      because it rained. / It rained, so I stayed home.
  - question: ¿However lleva coma?
    answer: >-
      Sí, suele ir con coma: However, I disagree. También al final: I disagree,
      however.
  - question: ¿Therefore es muy formal para A2?
    answer: >-
      Es un poco más formal que so. Úsalo en escritura: It was late; therefore,
      we left. En conversación, so es más natural.

## 1. Mapa de conectores

| Función | Conector | Ejemplo |
| :--- | :--- | :--- |
| Añadir | **and** | I like tea **and** coffee. |
| Contrastar | **but** | It's cheap, **but** small. |
| Contrastar | **although** | **Although** it's cheap, it's good. |
| Contrastar | **however** | It's cheap. **However**, it's small. |
| Causa | **because** | I'm tired **because** I worked late. |
| Resultado | **so** | I worked late, **so** I'm tired. |
| Resultado | **therefore** | It was late; **therefore**, we left. |

![Connectors](/blog/curso-a2/unit-59/a2-unit59-connectors.png)

---

## 2. *And*, *but*, *because*, *so*

| Conector | Idea | Ejemplo |
| :--- | :--- | :--- |
| **and** | suma | She studied hard **and** passed. |
| **but** | contraste simple | I like the city, **but** it's noisy. |
| **because** | causa (por qué) | We stayed in **because** it rained. |
| **so** | consecuencia | It rained, **so** we stayed in. |

> I was hungry, **so** I made a sandwich.  
> I made a sandwich **because** I was hungry.

## 3. *Although* y *however*

| Forma | Uso | Ejemplo |
| :--- | :--- | :--- |
| **Although** + clause | contraste (a menudo al inicio) | **Although** it was late, we went out. |
| …, **although** … | contraste en medio | We went out, **although** it was late. |
| **However**, … | contraste más formal / escrito | It was late. **However**, we went out. |

> **Although** the museum is small, it's interesting.  
> The museum is small. **However**, it's interesting.

No digas ~~Although… but…~~ en la misma frase.

## 4. *Therefore* (resultado más formal)

| Informal / natural | Más formal |
| :--- | :--- |
| It was expensive, **so** I didn't buy it. | It was expensive; **therefore**, I didn't buy it. |

En A2, prioriza **so** en conversación y **therefore** en escritura cuidada.

| Quieres… | Usa… | Ejemplo |
| :--- | :--- | :--- |

| Explicar por qué | because | because I'm tired |
| Dar resultado | so / therefore | so I left |

## 6. Lectura y diálogo

### Lectura — A short paragraph

I love my city **because** there are parks and museums. It's busy, **but** friendly. **Although** the centre is expensive, I enjoy living there. Last Saturday it rained, **so** we stayed at home. We watched a film **and** cooked dinner. The film was long; **however**, it was excellent.

<audio controls preload="none" src="/audio/blog/curso-a2/unit-59/reading-paragraph.mp3" title="🔊 Reading: A short paragraph"></audio>

### Diálogo — Weekend plans

**Eva:** Shall we go out?  
**Nico:** I'd like to, **but** I'm tired **because** I worked late.  
**Eva:** OK — **so** let's stay in **and** watch a series.  
**Nico:** Good idea. **Although** I'm tired, I don't want to sleep yet.  
**Eva:** Perfect.

## 7. Errores frecuentes

1. ~~Although it's cold, but sunny.~~ → **Although** it's cold, it's sunny. / It's cold, **but** sunny.  
2. ~~Because I was tired, so I slept.~~ → **Because** I was tired, I slept. / I was tired, **so** I slept.  
3. ~~I like coffee. And I like tea.~~ *(demasiado cortado a veces)* → **I like coffee and tea.**  
4. ~~However I agree~~ → **However, I agree.**  
5. ~~so that I tired~~ → **so I'm tired** / **because I'm tired**  
6. ~~therefore so…~~ → elige **uno**: *so* **o** *therefore*

3. because  
4. so  
5. although

b) result  
c) contrast (clause)

e) simple contrast

3 → a  
4 → b  
5 → c

1. I like pizza ___ pasta.  
2. The bag is nice, ___ expensive.  
3. She stayed home ___ she was ill.  
4. He was hungry, ___ he made a sandwich.  
5. ___ it was raining, we walked.

<details>
<summary>Soluciones</summary>

2. but  
3. because  
4. so  
5. Although  

</details>

### Ejercicio 3 — *because* o *so*

1. I took a taxi ___ I was late.  
2. I was late, ___ I took a taxi.  
3. We left early ___ the train was full.  
4. The train was full, ___ we left early.

<details>
<summary>Soluciones</summary>

1. because  
2. so  
3. because  
4. so  

</details>

### Ejercicio 4 — *but* / *although* / *however*

1. It's small, ___ comfortable.  
2. ___ it's small, it's comfortable.  
3. It's small. ___, it's comfortable.

<details>
<summary>Soluciones</summary>

1. but  
2. Although  
3. However  

</details>

### Ejercicio 5 — Corrige el error

1. Although I'm tired, but I will go.  
2. Because it rained, so we stayed.  
3. However I disagree.  
4. I was hungry so that I ate.  
5. Therefore, so we left.

<details>
<summary>Soluciones</summary>

1. Although I'm tired, I will go. / I'm tired, but I will go.  
2. Because it rained, we stayed. / It rained, so we stayed.  
3. However, I disagree.  
4. I was hungry, so I ate.  
5. Therefore, we left. / So we left.

</details>

5. Aunque era tarde, salimos.

### Checklist

- [ ] Uso *and / but / because / so*
