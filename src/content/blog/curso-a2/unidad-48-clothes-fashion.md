## 1. Vocabulario: ropa y estilo

| Palabra | Idea | Ejemplo |
| :--- | :--- | :--- |
| **outfit** | conjunto / look | I love your **outfit**. |
| **casual** | informal | Jeans are **casual**. |
| **formal** | formal / elegante | A suit is **formal**. |
| **pattern** | estampado | A striped **pattern**. |
| **material** | tela / material | This **material** is soft. |
| **size** | talla | What **size** are you? |
| **fit** | quedar (talla) | It **fits** perfectly. |
| **match** | combinar | Does this scarf **match**? |

Prendas útiles: **shirt**, **T-shirt**, **jumper / sweater**, **jacket**, **coat**, **dress**, **skirt**, **trousers / pants**, **jeans**, **shoes**, **trainers / sneakers**.

Accesorios: **bag**, **belt**, **scarf**, **hat**, **glasses**, **jewellery / jewelry**.

## 2. Verbos: *wear*, *put on*, *take off*

| Verbo | Idea | Ejemplo |
| :--- | :--- | :--- |
| **wear** | llevar puesto | I **wear** jeans at the weekend. |
| **put on** | ponerse | **Put on** your coat — it's cold. |
| **take off** | quitarse | **Take off** your shoes, please. |
| **try on** | probarse | Can I **try on** this jacket? |

> What are you **wearing** today?  
> She's **wearing** a blue dress.

## 3. *Too* vs *enough* (repaso)

| Forma | Idea | Ejemplo |
| :--- | :--- | :--- |
| **too** + adjective | demasiado | This shirt is **too small**. |
| adjective + **enough** | suficiente | This coat is **warm enough**. |
| **not** + adjective + **enough** | no suficiente | These shoes aren't **comfortable enough**. |
| **too much / too many** | demasiado (cantidad) | This bag costs **too much**. |

> These trousers are **too long**.  
> Is this jacket **smart enough** for work?

## 4. Describir un outfit

Orden útil:

1. Estilo general (*casual / formal*)  
2. Prendas principales  
3. Colores / pattern / material  
4. Accesorios  
5. Opinión (*It fits well. / It's comfortable.*)

> Today I'm wearing a **casual outfit**: a white **T-shirt**, blue **jeans** and black **trainers**. I've got a grey **scarf**. It's comfortable and not **too** warm.

## 6. Lectura y diálogo

### Lectura — Dress code tip

For the office, wear a **smart** or **formal outfit**: a shirt, dark trousers and clean shoes. Avoid **casual** clothes like old jeans or trainers. If it's cold, **put on** a jacket. Check that everything **fits** well — not **too tight** and not **too loose**. A simple bag and a belt are enough accessories.

<audio controls preload="none" src="/audio/blog/curso-a2/unit-48/reading-dress-code.mp3" title="🔊 Reading: Dress code tip"></audio>

### Diálogo — Choosing an outfit

**Sam:** What should I **wear** to the party?  
**Alex:** Something **smart casual**. Not too formal.  
**Sam:** Are these jeans OK?  
**Alex:** Yes — but that shirt is **too bright**. Try the blue one.  
**Sam:** Is this jacket **warm enough**?  
**Alex:** Perfect. **Put on** those black shoes and you're ready.

## 7. Errores frecuentes

1. ~~I put a jacket.~~ → **I put on** a jacket. / **I'm wearing** a jacket.  
2. ~~I wear on a hat.~~ → **I put on** a hat. / **I wear** a hat.  
3. ~~This is enough big.~~ → **This is big enough.**  
4. ~~Too much small~~ → **too small**  
5. ~~A clothes~~ → **clothes** (plural) / **a piece of clothing**  
6. ~~It fits to me.~~ → **It fits me.** / **It fits.**

2. formal  
3. put on  
4. take off  
5. outfit  

a) remove clothes  
b) smart / for work or events  
c) complete look  
d) relaxed style  
e) dress yourself in something

<details>
<summary>Soluciones</summary>

1 → d  
2 → b  
3 → e  
4 → a  
5 → c  

</details>

2. wears  
3. put on

</details>

### Ejercicio 4 — Corrige el error

1. I put a scarf.  
2. This shirt is enough big.  
3. These clothes is new.  
4. It fits to me well.  
5. Too much tight jeans.

<details>
<summary>Soluciones</summary>

1. I put on a scarf. / I'm wearing a scarf.  
2. This shirt is big enough.  
3. These clothes are new.  
4. It fits me well. / It fits well.  
5. These jeans are too tight.  

</details>
