## Lección 1 — Gramática

**Objetivo:** Shall we/Let's; Can I/Could you; I think/I agree; feelings; should/recycle; log in; work as; There is/are; because/so/although

### Ejercicios 1–5 — Completa

1. ___ we celebrate? → *Shall / Do / Am*

2. I ___ the course was useful. → *think / am think / thinking*

3. ___ you help me print this? → *Could / Can to / Do*

4. I felt ___ because I finished. → *excited / exciting / excite*

5. ___ it's late, I'm hungry. → *Although / Because / So*

<details>
<summary>Ver solución</summary>

1. **Shall** · 2. **think** · 3. **Could** · 4. **excited** · 5. **Although**

</details>


### Ejercicios 6–10 — Elige

6. *Shall we* (U51) in review: ____. → a) yes · b) only U41 · c) skip

7. *Could you help* (U52) = ____. → a) request · b) only opinion · c) only There is

8. *In my opinion* (U53) = ____. → a) opinión · b) offer · c) recycle only

9. *I felt excited* (U54) = ____. → a) feelings · b) shopping · c) weather only

10. Module 6 review covers ____. → a) U51–U59 · b) U41–U49 · c) U1–U10 only

<details>
<summary>Ver solución</summary>

6. **a) yes** · 7. **a) request** · 8. **a) opinión** · 9. **a) feelings** · 10. **a) U51–U59**

</details>


### Ejercicios 11–15 — Corrige

11. *Let's to meet in the square.*

12. *I am agree.*

13. *Could you to help me?*

14. *There are a café.*

15. *I felt exciting because I finished.*

<details>
<summary>Ver solución</summary>

11. Let's meet in the square.
12. I agree.
13. Could you help me?
14. There is a café.
15. I felt excited because I finished.

</details>

## Lección 2 — Vocabulario

**Objetivo:** repaso integrado Módulo 6: suggestions, offers, opinions, feelings, environment, tech, work, places, linking

### Ejercicios 1–5 — Empareja / elige

1. *celebrate* ≈ ____ → *celebrar · reciclar · estudiar*

2. *certificate* ≈ ____ → *certificado · contraseña · plaza*

3. *location* ≈ ____ → *ubicación · emoción · conector*

4. *useful* ≈ ____ → *útil · aburrido · caro*

5. *assistant* ≈ ____ → *asistente · turista · recepcionista only*

<details>
<summary>Ver solución</summary>

1. **celebrar** · 2. **certificado** · 3. **ubicación** · 4. **útil** · 5. **asistente**

</details>


### Ejercicios 6–10 — Completa

6. Meet in the main ___. → *square / squared / squaring*

7. Café located ___ the library. → *opposite / opposite to / oppositing*

8. Work ___ a student assistant. → *as / in / at*

9. Have to ___ in and send emails. → *log / logs / logging*

10. Try to ___ at home. → *recycle / recycles / recycling*

<details>
<summary>Ver solución</summary>

6. **square** · 7. **opposite** · 8. **as** · 9. **log** · 10. **recycle**

</details>


### Ejercicios 11–15 — Elige

11. Review mixes Module ____. → a) 6 · b) 5 only · c) 1 only

12. *That would be great* (U52) = ____. → a) aceptar · b) I don't think so · c) There are

13. *Send you the location* (U56) = ____. → a) tech · b) only feelings · c) only weather

14. Integrated text uses ____. → a) M6 structures · b) only did · c) only phrasals

15. After U60 continue with ____. → a) ingles-a2 / curso-a2 · b) U51 again · c) skip A2

<details>
<summary>Ver solución</summary>

11. **a) 6** · 12. **a) aceptar** · 13. **a) tech** · 14. **a) M6 structures** · 15. **a) ingles-a2 / curso-a2**

</details>

## Lección 3 — Reading: My A2 week

**Objetivo:** comprender un texto con el foco de la unidad.

### Texto y audio

<audio controls preload="none" src="/audio/blog/curso-a2/unit-60/reading-review.mp3" title="🔊 Reading: My A2 week"></audio>

> This week I felt excited because I finished Module 6. Shall we celebrate? Let's meet in the main square — there is a nice café located opposite the library. In my opinion, the course was useful, although some units were hard. I work as a student assistant, so I often have to log in and send emails. I also try to recycle at home. Could you help me print my certificate? That would be great!

### Ejercicios 1–5 — Comprensión

1. Felt ___ because finished Module 6. → a) excited · b) refund · c) foggy

2. Shall we ___? → a) celebrate · b) recycle only · c) checkout

3. Meet in main ___. → a) square · b) pharmacy · c) platform

4. There is a café ___ the library. → a) opposite · b) because · c) although

5. Course was ___ (opinion). → a) useful · b) sunny · c) cheaper

<details>
<summary>Ver solución</summary>

1. **a) excited** · 2. **a) celebrate** · 3. **a) square** · 4. **a) opposite** · 5. **a) useful**

</details>


### Ejercicios 6–10 — Detalles

6. Work ___ student assistant. → a) as · b) in job wrong · c) at university

7. Have to log in and ___ emails. → a) send · b) recycle · c) celebrate

8. Try to ___ at home. → a) recycle · b) pollute · c) waste more

9. *Although some units were hard* = ____. → a) although · b) so · c) and only

10. Matches Module 6 review: ____. → a) yes · b) no · c) only U31

<details>
<summary>Ver solución</summary>

6. **a) as** · 7. **a) send** · 8. **a) recycle** · 9. **a) although** · 10. **a) yes**

</details>


### Ejercicios 11–15 — Forma

11. *Could you help me print my certificate?* = ____. → a) request U52 · b) only opinion · c) only There is

12. *In my opinion, the course was useful* = ____. → a) U53 · b) U41 travel · c) only health

13. *There is a nice café* = ____. → a) U58 · b) U31 phrasal · c) only will

14. Review text mixes ____. → a) M6 topics · b) only Past · c) only comparatives

15. Review writing uses ____. → a) integrated M6 structures · b) only articles · c) only one unit

<details>
<summary>Ver solución</summary>

11. **a) request U52** · 12. **a) U53** · 13. **a) U58** · 14. **a) M6 topics** · 15. **a) integrated M6 structures**

</details>

**Objetivo:** escuchar el foco gramatical en contexto.

4. Ben offers to ___ a table. → a) book · b) download · c) pollute

5. ___ it's late, hungry — eat too. → a) Although · b) And only · c) Because result wrong
