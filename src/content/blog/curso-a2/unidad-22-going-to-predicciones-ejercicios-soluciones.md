## Lección 1 — Gramática

**Objetivo:** going to para predicciones con evidencia (*Look! It's going to…*).

### Ejercicios 1–5 — Completa

1. Look at the clouds! It ____ going to rain. → *is / are / am*
2. I think they ____ going to win. → *are / is / am*
3. I'm sure she ____ going to pass. → *is / are / am*
4. That cup ____ going to fall! → *is / are / am*
5. ____ it going to be sunny? → *Is / Are / Am*

<details>
<summary>Ver solución</summary>

1. **is** · 2. **are** · 3. **is** · 4. **is** · 5. **Is**

</details>


### Ejercicios 6–10 — Elige

6. U22 *going to* often needs ____. → a) evidence / clear signs · b) only Past Simple · c) only *must*
7. *Look!* often signals ____. → a) a prediction from evidence · b) a finished past · c) Present Perfect *yet*
8. *I think / I'm sure* + going to = ____. → a) opinion prediction · b) Past Continuous · c) obligation
9. Form stays ____. → a) am/is/are + going to + infinitive · b) will + -ing · c) have + PP
10. U21 plans vs U22 predictions: ____. → a) different uses, same form · b) different forms always · c) no link

<details>
<summary>Ver solución</summary>

6. **a) evidence / clear signs** · 7. **a) a prediction from evidence** · 8. **a) opinion prediction** · 9. **a) am/is/are + going to + infinitive** · 10. **a) different uses, same form**

</details>


### Ejercicios 11–15 — Corrige

11. *Look! It going to rain.*
12. *I think they is going to win.*
13. *I'm sure she are going to pass.*
14. *That cup are going to fall.*
15. *Are it going to be sunny?*

<details>
<summary>Ver solución</summary>

11. Look! It **is** going to rain.
12. I think they **are** going to win.
13. I'm sure she **is** going to pass.
14. That cup **is** going to fall.
15. **Is** it going to be sunny?

</details>

## Lección 2 — Vocabulario

**Objetivo:** clima y evidencia: clouds, sunny, warm, forecast, pass, win.

### Ejercicios 1–5 — Empareja / elige

1. *forecast* ≈ ____ → *weather prediction · a chair · a passport*
2. *clouds* ≈ ____ → *white/grey sky shapes · books · shoes*
3. *pass an exam* ≈ ____ → *succeed in a test · fail forever · cook*
4. *picnic* ≈ ____ → *meal outdoors · night class · airport*
5. *I'm sure* ≈ ____ → *I feel certain · I never know · yesterday*

<details>
<summary>Ver solución</summary>

1. **weather prediction** · 2. **white/grey sky shapes** · 3. **succeed in a test** · 4. **meal outdoors** · 5. **I feel certain**

</details>


### Ejercicios 6–10 — Completa

6. It is going to ____. → *rain / raining / rained*
7. They are going to ____. → *win / winning / won*
8. She is going to ____ her exam. → *pass / passing / passed*
9. We are going to ____ a great day. → *have / having / had*
10. The film is going to ____ good. → *be / being / been*

<details>
<summary>Ver solución</summary>

6. **rain** · 7. **win** · 8. **pass** · 9. **have** · 10. **be**

</details>


### Ejercicios 11–15 — Elige

11. Dark clouds often mean ____. → a) rain is likely · b) Past Perfect · c) *ago*
12. *I think* softens a ____. → a) prediction · b) Past Continuous · c) plural noun
13. Evidence predictions still use ____. → a) going to · b) only *did* · c) only *-est*
14. *Look at…!* is a useful ____. → a) signal · b) Past Simple marker · c) article error
15. Unit 22 is about ____. → a) predictions · b) only hotel bookings · c) only *could*

<details>
<summary>Ver solución</summary>

11. **a) rain is likely** · 12. **a) prediction** · 13. **a) going to** · 14. **a) signal** · 15. **a) predictions**

</details>

## Lección 3 — Reading: A weather day

**Objetivo:** comprender un texto con el foco de la unidad.

### Texto y audio

<audio controls preload="none" src="/audio/blog/curso-a2/unit-22/reading-predictions.mp3" title="🔊 Reading: A weather day"></audio>

> Tomorrow the weather is going to be sunny. I think it is going to be warm and nice. I'm sure we are going to have a good day at the beach. Look at the clouds! I think it is going to rain in the afternoon. Maybe we should take an umbrella. I'm sure the match is going to be exciting tonight. My team is going to win!

### Ejercicios 1–5 — Comprensión

1. Tomorrow the weather is going to be ____. → a) Sunny · b) Snowy forever · c) Dark only
2. Where might they have a good day? → a) At the beach · b) At school only · c) Underground
3. What might happen in the afternoon? → a) Rain · b) Snow forever · c) Nothing
4. What about the match tonight? → a) Going to be exciting · b) Cancelled · c) Already finished
5. What about the team? → a) Going to win · b) Going to lose for sure · c) Not mentioned

<details>
<summary>Ver solución</summary>

1. **a) Sunny** · 2. **a) At the beach** · 3. **a) Rain** · 4. **a) Going to be exciting** · 5. **a) Going to win**

</details>


### Ejercicios 6–10 — Detalles

6. The text practices ____. → a) going to predictions · b) only *for/since* · c) only comparatives
7. *Look at the clouds!* shows ____. → a) evidence · b) a finished past date · c) Present Perfect *yet*
8. *I think / I'm sure* appear: ____. → a) yes · b) never · c) only Unit 1
9. Form after *going to* is ____. → a) infinitive · b) PP only · c) adjective only
10. Matches unit 22: ____. → a) yes · b) no · c) only Module 6

<details>
<summary>Ver solución</summary>

6. **a) going to predictions** · 7. **a) evidence** · 8. **a) yes** · 9. **a) infinitive** · 10. **a) yes**

</details>


### Ejercicios 11–15 — Forma

11. *It is going to rain* needs ____. → a) is + going to + infinitive · b) did + rain · c) have + raining
12. Opinion phrases + going to are ____. → a) natural · b) wrong · c) only B2
13. Questions: ____. → a) Is it going to…? · b) Did it going to…? · c) Have it going?
14. Evidence words help you ____. → a) choose going to · b) avoid English · c) use only *ago*
15. Reading helps you ____. → a) notice prediction language · b) skip form · c) ignore clouds

<details>
<summary>Ver solución</summary>

11. **a) is + going to + infinitive** · 12. **a) natural** · 13. **a) Is it going to…?** · 14. **a) choose going to** · 15. **a) notice prediction language**

</details>

5. What about the film tonight? → a) Going to be good · b) Cancelled · c) Already seen

</details>


### Ejercicios 6–10 — Detalles

6. Listening checks ____. → a) prediction language · b) only spelling · c) only *into*

### Ejercicios 11–15 — Forma

12. Forecast + opinion phrases fit U22: ____. → a) true · b) false · c) irrelevant

## Lección 5 — Writing

**Objetivo:** producir frases con el foco de la unidad.

### Ejercicios 1–5 — Completa

1. Look! It ____ going to rain. → *is / are / am*
2. I think they are going to ____. → *win / winning / won*
3. I'm sure she ____ going to pass. → *is / are / am*
4. That cup is going to ____! → *fall / falling / fell*
5. ____ it going to be warm? → *Is / Are / Am*

<details>
<summary>Ver solución</summary>

1. **is** · 2. **win** · 3. **is** · 4. **fall** · 5. **Is**

</details>


### Ejercicios 6–8 — Ordena

6. It / is / going / to / rain.
7. I / think / they / are / going / to / win.
8. I'm / sure / she / is / going / to / pass.

<details>
<summary>Ver solución</summary>

6. It is going to rain.
7. I think they are going to win.
8. I'm sure she is going to pass.

</details>


### Ejercicios 9–15 — Escribe (modelos)

9. Una predicción con evidencia (*Look!…*).
10. Una predicción con *I think…*.
11. Una predicción con *I'm sure…*.
12. Una predicción de clima.
13. Una predicción sobre un examen o partido.
14. Una pregunta (*Is it going to…?*).
15. Párrafo (6–8 frases) con predicciones para mañana.

<details>
<summary>Ver solución</summary>
