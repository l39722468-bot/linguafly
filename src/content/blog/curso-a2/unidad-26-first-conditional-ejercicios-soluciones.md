## Lección 1 — Gramática

**Objetivo:** If + Present Simple, will + infinitivo (condiciones reales futuras).

### Ejercicios 1–5 — Completa

1. If it ____ (rain), I will stay at home. → *rains / will rain / rained*
2. If you study hard, you ____ (pass) the exam. → *will pass / pass / passed*
3. If she ____ (come) to visit, I will make coffee. → *comes / will come / come*
4. If the weather ____ (be) nice, I will go for a walk. → *is / will be / are*
5. If I ____ (not / pass), I will study harder. → *don't pass / won't pass / didn't pass*

<details>
<summary>Ver solución</summary>

1. **rains** · 2. **will pass** · 3. **comes** · 4. **is** · 5. **don't pass**

</details>


### Ejercicios 6–10 — Elige

6. After *If* use → ____. → a) Present Simple · b) will · c) Past Simple
7. Result clause uses → ____. → a) will + infinitive · b) Present only · c) going to always
8. *If it will rain* is → ____. → a) wrong · b) correct · c) Zero Conditional
9. First Conditional talks about → ____. → a) real future possibilities · b) always true facts · c) only past
10. Unit 26 trains → ____. → a) If + Present, will · b) only have to · c) only could

<details>
<summary>Ver solución</summary>

6. **a) Present Simple** · 7. **a) will + infinitive** · 8. **a) wrong** · 9. **a) real future possibilities** · 10. **a) If + Present, will**

</details>


### Ejercicios 11–15 — Corrige

11. *If it will rain, I will stay at home.*
12. *If she come, I will be happy.*
13. *If you study hard, you pass the exam.* *(future possible)*
14. *I will stay at home, if it rains.* *(comma)*
15. *If we will miss the bus, we will be late.*

<details>
<summary>Ver solución</summary>

11. If it **rains**, I will stay at home.
12. If she **comes**, I will be happy.
13. If you study hard, you **will pass** the exam.
14. I will stay at home if it rains. *(sin coma)*
15. If we **miss** the bus, we will be late.

</details>

## Lección 2 — Vocabulario

**Objetivo:** condition, consequence, rain, pass, celebrate, homework, help.

### Ejercicios 1–5 — Empareja / elige

1. *condition* ≈ ____ → *if-part of a sentence · a shoe · rain only*
2. *consequence* ≈ ____ → *result · yesterday · a ticket*
3. *stay at home* ≈ ____ → *not go out · fly · cook dinner*
4. *pass an exam* ≈ ____ → *succeed in a test · forget · sleep*
5. *study harder* ≈ ____ → *work more for next time · cancel · rain*

<details>
<summary>Ver solución</summary>

1. **if-part of a sentence** · 2. **result** · 3. **not go out** · 4. **succeed in a test** · 5. **work more for next time**

</details>


### Ejercicios 6–10 — Completa

6. If it rains, I will ____ at home. → *stay / staying / stayed*
7. If I pass, I will ____ with my friends. → *celebrate / celebrating / celebrated*
8. If you finish early, I will let you ____ out. → *go / going / went*
9. If you need help, I will ____. → *come / coming / came*
10. If the bus is late, I will be ____. → *late / lately / later*

<details>
<summary>Ver solución</summary>

6. **stay** · 7. **celebrate** · 8. **go** · 9. **come** · 10. **late**

</details>


### Ejercicios 11–15 — Elige

11. *If* at the start often needs a ____. → a) comma · b) question mark only · c) *ago*
12. Negative condition: *If I don't pass…* uses ____. → a) don't + base verb · b) won't in if-clause · c) didn't always
13. *I will stay at home if it rains* has ____. → a) no comma before if · b) comma always · c) Past Perfect
14. First vs Zero: tomorrow's rain is ____. → a) First · b) Zero · c) Past Simple
15. Unit 26 is about ____. → a) If + Present, will · b) only *have to* · c) only *could*

<details>
<summary>Ver solución</summary>

11. **a) comma** · 12. **a) don't + base verb** · 13. **a) no comma before if** · 14. **a) First** · 15. **a) If + Present, will**

</details>

## Lección 3 — Reading: Tomorrow's plans

**Objetivo:** comprender un texto con el foco de la unidad.

### Texto y audio

<audio controls preload="none" src="/audio/blog/curso-a2/unit-26/reading-first.mp3" title="🔊 Reading: Tomorrow's plans"></audio>

> If it rains tomorrow, I will stay at home. I will watch a film and relax. If the weather is nice, I will go for a walk in the park. If you come to visit me, I will make coffee for you. If I pass the exam, I will celebrate with my friends. If I don't pass, I will study harder next time.

### Ejercicios 1–5 — Comprensión

1. If it rains tomorrow, what will happen? → a) Stay at home · b) Go to the park · c) Celebrate
2. If the weather is nice, what will they do? → a) Go for a walk · b) Watch a film · c) Study harder
3. If you come to visit, what will they make? → a) Coffee · b) A present · c) Homework
4. If they pass the exam, what will they do? → a) Celebrate with friends · b) Stay at home · c) Be late
5. If they don't pass, what will they do? → a) Study harder next time · b) Go out tonight · c) Make coffee

<details>
<summary>Ver solución</summary>

1. **a) Stay at home** · 2. **a) Go for a walk** · 3. **a) Coffee** · 4. **a) Celebrate with friends** · 5. **a) Study harder next time**

</details>


### Ejercicios 6–10 — Detalles

6. The text practices ____. → a) First Conditional · b) only Zero · c) only *have to*
7. *If it rains tomorrow* is ____. → a) a future possibility · b) a scientific fact · c) past ability
8. Result clauses use ____. → a) will · b) only Present · c) *ago*
9. A negative condition appears: ____. → a) If I don't pass · b) If I will pass · c) If I passed
10. Matches unit 26: ____. → a) yes · b) no · c) only Module 6

<details>
<summary>Ver solución</summary>

6. **a) First Conditional** · 7. **a) a future possibility** · 8. **a) will** · 9. **a) If I don't pass** · 10. **a) yes**

</details>


### Ejercicios 11–15 — Forma

11. After *If* use ____. → a) Present Simple · b) will · c) Past Continuous
12. *If I pass, I will celebrate* is ____. → a) correct First · b) Zero · c) wrong
13. Clause order can change: ____. → a) true · b) false · c) forbidden
14. *If you come… I will make coffee* shows ____. → a) condition + result · b) only obligation · c) past ability
15. Reading helps you ____. → a) notice If/will patterns · b) skip grammar · c) avoid English

<details>
<summary>Ver solución</summary>

11. **a) Present Simple** · 12. **a) correct First** · 13. **a) true** · 14. **a) condition + result** · 15. **a) notice If/will patterns**

</details>

## Lección 5 — Writing

**Objetivo:** producir frases con el foco de la unidad.

### Ejercicios 1–5 — Completa

1. If it ____ tomorrow, I will stay at home. → *rains / will rain / rained*
2. If you study hard, you ____ pass. → *will / are / did*
3. If she ____ to visit, I will make coffee. → *comes / will come / come*
4. If I don't pass, I ____ study harder. → *will / am / do*
5. If you need help, I ____ come. → *will / am / do*

<details>
<summary>Ver solución</summary>

1. **rains** · 2. **will** · 3. **comes** · 4. **will** · 5. **will**

</details>


### Ejercicios 6–8 — Ordena

6. If / it / rains, / I / will / stay / at / home.
7. If / you / pass / the / exam, / I / will / buy / you / a / present.
8. I / will / make / coffee / if / you / come / to / visit / me.

<details>
<summary>Ver solución</summary>

6. If it rains, I will stay at home.
7. If you pass the exam, I will buy you a present.
8. I will make coffee if you come to visit me.

</details>


### Ejercicios 9–15 — Escribe (modelos)

9. Una condición con el tiempo (*If it rains…*).
10. Una condición de estudio (*If I pass…*).
11. Una negativa (*If I don't…*).
12. Resultado primero (*I will… if…*).
13. Un consejo (*If you need help…*).
14. Un plan del fin de semana con First Conditional.
15. Párrafo (6–8 frases) con varias condiciones futuras.

<details>
<summary>Ver solución</summary>

9. If it rains tomorrow, I will stay at home.
10. If I pass the exam, I will celebrate with my friends.
11. If I don't pass, I will study harder next time.
12. I will make coffee for you if you come to visit me.
13. If you need help, just call me and I will come.
14. If it rains on Saturday, we will stay at home and play games.
15. If it rains tomorrow, I will stay at home and watch a film. If the weather is nice, I will go for a walk. If I pass the exam, I will celebrate. If I don't pass, I will study harder next time!

</details>
