## Lección 1 — Gramática

**Objetivo:** send / download / upload; log in; turn on WiFi; password / link / app

### Ejercicios 1–5 — Completa

1. ___ in with your email. → *Log / Logs / Logging*

2. ___ the app. → *Download / Downloads / Downloading*

3. Turn ___ the WiFi. → *on / in / at*

4. ___ me an email. → *Send / Sends / Sending*

5. ___ your homework before Friday. → *Upload / Uploads / Uploading*

<details>
<summary>Ver solución</summary>

1. **Log** · 2. **Download** · 3. **on** · 4. **Send** · 5. **Upload**

</details>


### Ejercicios 6–10 — Elige

6. *Log in* (no *log in to with password only wrong)*): ____. → a) correcto · b) log on to always wrong · c) login to only

7. *Turn on WiFi* = ____. → a) encender WiFi · b) descargar · c) subir archivo

8. *Download the app* = ____. → a) bajar app · b) enviar email · c) recycle

9. *Check spam folder* = ____. → a) carpeta spam · b) password · c) museum

10. Unit 56 follows ____. → a) Environment U55 · b) Module 5 only · c) skip U57

<details>
<summary>Ver solución</summary>

6. **a) correcto** · 7. **a) encender WiFi** · 8. **a) bajar app** · 9. **a) carpeta spam** · 10. **a) Environment U55**

</details>


### Ejercicios 11–15 — Corrige

11. *I can't to log in.*

12. *Send me an screenshot.*

13. *Download the homework.* *(wrong context)*

14. *Turn the WiFi.*

15. *Upload an email.*

<details>
<summary>Ver solución</summary>

11. I can't log in.
12. Send me a screenshot.
13. Upload your homework. / Download the app.
14. Turn on the WiFi.
15. Send an email. / Upload your homework.

</details>

## Lección 2 — Vocabulario

**Objetivo:** email, download, upload, log in, WiFi, password, link, app, website, screenshot

### Ejercicios 1–5 — Empareja / elige

1. *log in* ≈ ____ → *iniciar sesión · descargar · subir*

2. *download* ≈ ____ → *descargar · enviar · encender*

3. *upload* ≈ ____ → *subir (archivo) · bajar · borrar*

4. *password* ≈ ____ → *contraseña · enlace · correo*

5. *link* ≈ ____ → *enlace · contraseña · aplicación*

<details>
<summary>Ver solución</summary>

1. **iniciar sesión** · 2. **descargar** · 3. **subir (archivo)** · 4. **contraseña** · 5. **enlace**

</details>


### Ejercicios 6–10 — Completa

6. Open the ___. → *website / web / webs*

7. Click the ___ in your email. → *link / links / linking*

8. Check your spam ___. → *folder / fold / folding*

9. Try another ___. → *password / pass / passwords*

10. Send me a ___. → *screenshot / screen / screens*

<details>
<summary>Ver solución</summary>

6. **website** · 7. **link** · 8. **folder** · 9. **password** · 10. **screenshot**

</details>


### Ejercicios 11–15 — Elige

11. *Log in* with email and ____. → a) password · b) pollution · c) receipt

12. *Upload homework* before ____. → a) Friday · b) sunny · c) gate

13. *Turn on WiFi* before ____. → a) log in · b) recycle · c) proud

14. Tech text uses ____. → a) log in / download / upload · b) only I think · c) only There is

15. Unit 56 next is ____. → a) Work U57 · b) Module 5 only · c) skip U57

<details>
<summary>Ver solución</summary>

11. **a) password** · 12. **a) Friday** · 13. **a) log in** · 14. **a) log in / download / upload** · 15. **a) Work U57**

</details>

## Lección 4 — Listening: Tech problem

**Objetivo:** escuchar el foco gramatical en contexto.

### Audio y guion

<audio controls preload="none" src="/audio/blog/curso-a2/unit-56/listening-tech.mp3" title="🔊 Listening: Tech problem"></audio>

> Sam: I can't log in.
> Alex: Did you turn on the WiFi?
> Sam: Yes. I also downloaded the app.
> Alex: Try another password. Or send me a screenshot.
> Sam: OK. Can you look up the help page?
> Alex: Sure — I'll send you the link.

### Ejercicios 1–5 — Comprensión

1. Sam can't ___. → a) log in · b) recycle · c) checkout

2. Alex asks about ___. → a) WiFi · b) pollution · c) stadium

3. Sam already ___ the app. → a) downloaded · b) uploaded homework · c) recycled

4. Alex says try another ___. → a) password · b) library · c) drama

5. Alex will send the ___. → a) link · b) receipt · c) gate

<details>
<summary>Ver solución</summary>

1. **a) log in** · 2. **a) WiFi** · 3. **a) downloaded** · 4. **a) password** · 5. **a) link**

</details>


### Ejercicios 6–10 — Detalles

6. Sam asks look up ___ page. → a) help · b) shopping · c) weather

7. *Send me a screenshot* = ____. → a) tech support · b) opinion · c) place

8. *Did you turn on the WiFi?* = ____. → a) troubleshooting · b) I agree · c) recycle

9. Dialogue uses ____. → a) tech communication · b) only feelings · c) only environment

10. Unit 56 practice: ____. → a) yes · b) no · c) only U31

<details>
<summary>Ver solución</summary>

6. **a) help** · 7. **a) tech support** · 8. **a) troubleshooting** · 9. **a) tech communication** · 10. **a) yes**

</details>


### Ejercicios 11–15 — Forma

11. *I can't log in* → a) log in · b) log in to wrong only · c) login noun only

12. *Downloaded the app* → a) download · b) upload · c) send email

13. *I'll send you the link* → a) send + link · b) upload password · c) recycle

14. Shadow and note ____. → a) tech verbs · b) only some · c) only Who

15. U56 next unit is ____. → a) Work U57 · b) Module 5 only · c) U55 skip

<details>
<summary>Ver solución</summary>

11. **a) log in** · 12. **a) download** · 13. **a) send + link** · 14. **a) tech verbs** · 15. **a) Work U57**

</details>
