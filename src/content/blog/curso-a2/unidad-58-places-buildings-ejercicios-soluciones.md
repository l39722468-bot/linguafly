## Lección 1 — Gramática

**Objetivo:** There is / There are; Is there…? / Are there…?; located in / opposite / near

### Ejercicios 1–5 — Completa

1. ___ is a museum in the centre. → *There / It / They*

2. ___ are two cafés. → *There / It / Has*

3. ___ there a library near here? → *Is / Are / Do*

4. The museum is ___ next to the square. → *located / locate / locating*

5. The hospital is ___ the station. → *near / nearly / nears*

<details>
<summary>Ver solución</summary>

1. **There** · 2. **There** · 3. **Is** · 4. **located** · 5. **near**

</details>


### Ejercicios 6–10 — Elige

6. *There is* + singular: ____. → a) correcto · b) There are a museum · c) It is there a museum

7. *Are there* + plural: ____. → a) correcto · b) Is there two cafés · c) There is two cafés

8. *Located in* = ____. → a) situado en · b) hay · c) cerca only

9. *Opposite* = ____. → a) enfrente de · b) dentro de · c) lejos always

10. Unit 58 follows ____. → a) Work U57 · b) Module 5 only · c) skip U59

<details>
<summary>Ver solución</summary>

6. **a) correcto** · 7. **a) correcto** · 8. **a) situado en** · 9. **a) enfrente de** · 10. **a) Work U57**

</details>


### Ejercicios 11–15 — Corrige

11. *There are a museum.*

12. *Is there any cafés?*

13. *The library is locate in Green Street.*

14. *There is two parks.*

15. *The stadium is the more big building.*

<details>
<summary>Ver solución</summary>

11. There is a museum.
12. Are there any cafés?
13. The library is located in Green Street.
14. There are two parks.
15. The stadium is the biggest building.

</details>

## Lección 2 — Vocabulario

**Objetivo:** square, museum, library, stadium, hospital, café, centre, opposite, near

### Ejercicios 1–5 — Empareja / elige

1. *square* ≈ ____ → *plaza · museo · hospital*

2. *museum* ≈ ____ → *museo · biblioteca · estadio*

3. *library* ≈ ____ → *biblioteca · cafetería · estación*

4. *stadium* ≈ ____ → *estadio · hospital · plaza*

5. *hospital* ≈ ____ → *hospital · museo · cafetería*

<details>
<summary>Ver solución</summary>

1. **plaza** · 2. **museo** · 3. **biblioteca** · 4. **estadio** · 5. **hospital**

</details>


### Ejercicios 6–10 — Completa

6. Main ___ in the centre. → *square / squared / squaring*

7. Two cafés ___ it. → *opposite / opposite to / oppositing*

8. Library is the ___ building. → *oldest / older / old*

9. Stadium in the ___. → *south / southernly / souths*

10. Hospital near the ___. → *station / stat / stating*

<details>
<summary>Ver solución</summary>

6. **square** · 7. **opposite** · 8. **oldest** · 9. **south** · 10. **station**

</details>


### Ejercicios 11–15 — Elige

11. Art museum next to ___. → a) square · b) receipt · c) drama

12. *Oldest building* = ____. → a) superlativo · b) comparativo only · c) will

13. Riverton guide uses ____. → a) There is/are · b) only I think · c) only recycle

14. *Easy to find* hospital near ___. → a) station · b) museum only · c) gate

15. Unit 58 next is ____. → a) Linking U59 · b) Module 5 only · c) skip U59

<details>
<summary>Ver solución</summary>

11. **a) square** · 12. **a) superlativo** · 13. **a) There is/are** · 14. **a) station** · 15. **a) Linking U59**

</details>

## Lección 4 — Listening: Asking for places

**Objetivo:** escuchar el foco gramatical en contexto.

### Audio y guion

<audio controls preload="none" src="/audio/blog/curso-a2/unit-58/listening-places.mp3" title="🔊 Listening: Asking for places"></audio>

> Tourist: Excuse me. Is there a library near here?
> Local: Yes. It's located in Green Street, opposite the museum.
> Tourist: And are there any good cafés?
> Local: There are three in the main square.
> Tourist: Perfect. Is the stadium far?
> Local: No — it's the biggest building in the south.

### Ejercicios 1–5 — Comprensión

1. Tourist asks about a ___. → a) library · b) stadium first · c) hospital only

2. Library in ___ Street. → a) Green · b) Red · c) Blue always

3. Library opposite the ___. → a) museum · b) station · c) receipt

4. ___ cafés in main square. → a) Three · b) One only · c) Zero

5. Stadium is the ___ building. → a) biggest · b) smallest always · c) oldest library

<details>
<summary>Ver solución</summary>

1. **a) library** · 2. **a) Green** · 3. **a) museum** · 4. **a) Three** · 5. **a) biggest**

</details>


### Ejercicios 6–10 — Detalles

6. Stadium in the ___. → a) south · b) centre always · c) gate

7. *Is the stadium far?* answer ____. → a) No · b) Yes always · c) Maybe only

8. *Are there any good cafés?* = ____. → a) Are there · b) Is there · c) There is

9. Dialogue uses ____. → a) places questions · b) only opinions · c) only environment

10. Unit 58 practice: ____. → a) yes · b) no · c) only U31

<details>
<summary>Ver solución</summary>

6. **a) south** · 7. **a) No** · 8. **a) Are there** · 9. **a) places questions** · 10. **a) yes**

</details>


### Ejercicios 11–15 — Forma

11. *Is there a library near here?* → a) Is there · b) Are there · c) There is

12. *It's located in Green Street* → a) located in · b) locate in · c) located at only wrong
