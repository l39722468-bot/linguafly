## Lección 1 — Gramática

**Objetivo:** If + Present Simple, Present Simple (hechos generales).

### Ejercicios 1–5 — Completa

1. If you heat water, it ____ (boil). → *boils / will boil / boiled*
2. If you freeze water, it ____ (turn) into ice. → *turns / will turn / turned*
3. If you mix red and blue, you ____ (get) purple. → *get / will get / got*
4. If you don't eat enough, you ____ (feel) hungry. → *feel / will feel / felt*
5. If you exercise regularly, you ____ (stay) healthy. → *stay / will stay / stayed*

<details>
<summary>Ver solución</summary>

1. **boils** · 2. **turns** · 3. **get** · 4. **feel** · 5. **stay**

</details>


### Ejercicios 6–10 — Elige

6. Zero Conditional uses ____. → a) Present + Present · b) If + will, will · c) Past + Past
7. *If you heat water, it will boil* for a general fact is ____. → a) wrong (use boils) · b) correct · c) First only
8. Zero talks about ____. → a) always true facts · b) tomorrow's plans only · c) past ability
9. After *If* in Zero still use ____. → a) Present Simple · b) will · c) *-ing* only
10. Unit 27 trains ____. → a) If + Present, Present · b) only *could* · c) only *have to*

<details>
<summary>Ver solución</summary>

6. **a) Present + Present** · 7. **a) wrong (use boils)** · 8. **a) always true facts** · 9. **a) Present Simple** · 10. **a) If + Present, Present**

</details>


### Ejercicios 11–15 — Corrige

11. *If you heat water, it will boil.* *(general fact)*
12. *If you will freeze water, it turns into ice.*
13. *If you don't sleep well, you will feel tired.* *(general routine)*
14. *If people don't eat, they will get hungry.* *(always)*
15. *If it rains tomorrow, I stay at home.* *(future possible — wrong form)*

<details>
<summary>Ver solución</summary>

11. If you heat water, it **boils**.
12. If you **freeze** water, it turns into ice.
13. If you don't sleep well, you **feel** tired.
14. If people don't eat, they **get** hungry.
15. If it rains tomorrow, I **will stay** at home. *(First, not Zero)*

</details>

## Lección 2 — Vocabulario

**Objetivo:** heat, freeze, boil, melt, mix, hungry, healthy, vocabulary.

### Ejercicios 1–5 — Empareja / elige

1. *boil* ≈ ____ → *reach 100°C and bubble · freeze · sleep*
2. *melt* ≈ ____ → *turn from solid to liquid · boil · mix colours*
3. *freeze* ≈ ____ → *turn to ice · feel hungry · read*
4. *general truth* ≈ ____ → *always true fact · tomorrow's plan · polite request*
5. *regularly* ≈ ____ → *often / in a routine · never · yesterday*

<details>
<summary>Ver solución</summary>

1. **reach 100°C and bubble** · 2. **turn from solid to liquid** · 3. **turn to ice** · 4. **always true fact** · 5. **often / in a routine**

</details>


### Ejercicios 6–10 — Completa

6. If you heat water, it ____. → *boils / will boil / boiled*
7. If you put ice in the sun, it ____. → *melts / will melt / melted*
8. If you don't water plants, they ____. → *die / will die / died*
9. If you read every day, your vocabulary ____. → *improves / will improve / improved*
10. If you drink water every day, you ____ better. → *feel / will feel / felt*

<details>
<summary>Ver solución</summary>

6. **boils** · 7. **melts** · 8. **die** · 9. **improves** · 10. **feel**

</details>


### Ejercicios 11–15 — Elige

11. Science facts use ____. → a) Zero Conditional · b) only will · c) only *could*
12. *If you don't water plants, they die* is ____. → a) Zero · b) First · c) Past Simple
13. Zero vs First: tomorrow's rain → ____. → a) First · b) Zero · c) neither
14. Both clauses in Zero are ____. → a) Present Simple · b) will + inf · c) Past Perfect
15. Unit 27 is about ____. → a) general truths · b) only promises · c) only obligations

<details>
<summary>Ver solución</summary>

11. **a) Zero Conditional** · 12. **a) Zero** · 13. **a) First** · 14. **a) Present Simple** · 15. **a) general truths**

</details>

### Ejercicios 1–5 — Comprensión

<summary>Ver solución</summary>

</details>


### Ejercicios 6–10 — Detalles

6. The text practices ____. → a) Zero Conditional · b) only First · c) only *have to*

8. *Exercise regularly* leads to ____. → a) stay healthy · b) boil · c) melt
9. Negative conditions use ____. → a) don't · b) won't in if-clause · c) didn't always
10. Matches unit 27: ____. → a) yes · b) no · c) only Module 6

<details>
<summary>Ver solución</summary>

6. **a) Zero Conditional** · 7. **a) Present Simple** · 8. **a) stay healthy** · 9. **a) don't** · 10. **a) yes**

</details>


### Ejercicios 11–15 — Forma

11. Zero = If + Present, ____. → a) Present · b) will · c) Past
12. *If you heat water, it boils* is ____. → a) correct Zero · b) First · c) wrong
13. General facts avoid ____. → a) will in the result · b) Present Simple · c) *if*
14. Ask: is it always true? → ____. → a) Zero · b) First · c) neither
15. Reading helps you ____. → a) notice Present + Present · b) skip form · c) avoid English

<details>
<summary>Ver solución</summary>

11. **a) Present** · 12. **a) correct Zero** · 13. **a) will in the result** · 14. **a) Zero** · 15. **a) notice Present + Present**

</details>

2. If you put ice in the sun, it ____. → *melts / will melt / melted*
3. If you don't water plants, they ____. → *die / will die / died*
4. If you exercise regularly, you ____ healthy. → *stay / will stay / stayed*
5. If you read every day, your vocabulary ____. → *improves / will improve / improved*

<details>
<summary>Ver solución</summary>

1. **boils** · 2. **melts** · 3. **die** · 4. **stay** · 5. **improves**

</details>


### Ejercicios 6–8 — Ordena

6. If / you / heat / water, / it / boils.
7. If / you / don't / eat / enough, / you / feel / hungry.
8. Water / boils / if / you / heat / it.

<details>
<summary>Ver solución</summary>

6. If you heat water, it boils.
7. If you don't eat enough, you feel hungry.
8. Water boils if you heat it.

</details>


### Ejercicios 9–15 — Escribe (modelos)

9. Un hecho científico con Zero Conditional.
10. Un hábito de salud (*If you exercise…*).
11. Una negativa (*If you don't…*).
12. Reordenar: resultado primero (*Water boils if…*).
13. Un hecho sobre estudio o lectura.
14. Contrasta una frase Zero y una First.
15. Párrafo (6–8 frases) con verdades generales.

<details>
<summary>Ver solución</summary>

</details>
