## Bloque 1 — Zero Conditional (hechos generales)

Estructura: **If + present simple, present simple**

### Ejercicio 1: Completa con la forma correcta del verbo

1. If you heat ice, it _______ (melt).
2. People get tired if they _______ (not sleep) enough.
3. If plants _______ (not get) water, they die.
4. If I drink coffee late, I _______ (not sleep) well.
5. If you press this button, the light _______ (turn on).

### Ejercicio 2: Completa las oraciones

6. If children are hungry, they _______.
7. Water freezes if _______.

### Ejercicio 3: Corrige el error

8. If you will mix red and blue, you get purple. → _______________

**Soluciones:**
1. melts
2. don't sleep
3. don't get
4. don't sleep
5. turns on
6. cry
7. the temperature goes below 0°C
8. If you mix red and blue, you get purple.

---

## Bloque 2 — First Conditional (futuro probable)

Estructura: **If + present simple, will + infinitivo**

### Ejercicio 4: Completa con la forma correcta del verbo

1. If it _______ (rain), we will stay home.
2. I will call you if I _______ (finish) early.
3. If she studies, she _______ (pass) the exam.
4. If we _______ (not leave) now, we will be late.

### Ejercicio 5: Completa las oraciones

5. If they offer me the job, _______.
6. If you don't practice, _______.

### Ejercicio 6: Corrige y escribe

7. If he will come, we will start the meeting. → _______________
8. Escribe una oración en First Conditional sobre tu semana.

**Soluciones:**
1. rains
2. finish
3. will pass
4. don't leave
5. I will accept it
6. you will not improve
7. If he comes, we will start the meeting.
8. Respuesta abierta (ej.: *If I finish work early, I will go to the gym.*)

## Resumen rápido

| Tipo | Estructura | Uso |
|------|-----------|-----|
| Zero | if + present simple → present simple | Hechos y reglas generales |
| First | if + present simple → will + inf. | Futuro probable |
