## Ejercicios

### Ejercicio 1 — Pasado → presente

1. If he ___ (catch) the bus, he would be here now.
2. If we ___ (book) the hotel, we would have a room.
3. If I ___ (check) the forecast, I would have the right clothes now.
4. If they ___ (leave) earlier, they would be at the gate already.
5. If she ___ (bring) her passport, she wouldn't be at the embassy now.

<details>
<summary>Ver solución</summary>

1. **had caught** · 2. **had booked** · 3. **had checked** · 4. **had left** · 5. **had brought**
</details>

### Ejercicio 2 — Presente → pasado

1. If I ___ (be) taller, I would have joined the team.
2. If she ___ (be) more organised, she would have caught the flight.
3. If he ___ (not be) so nervous, he would have spoken up.
4. If we ___ (have) more money, we would have booked business class.
5. If they ___ (like) adventure, they would have gone hiking.

<details>
<summary>Ver solución</summary>

1. **were** · 2. **were** · 3. **weren't** · 4. **had** · 5. **liked**
</details>

### Ejercicio 3 — Corrige el error

1. *If he caught the bus, he would be here now.*
2. *If we had booked the hotel, we would have had a room.*
3. *If she was organised, she would have caught it.*
4. *If he had booked, he isn't waiting.*
5. *If I am taller, I would have joined.*

<details>
<summary>Ver solución</summary>

1. If he **had caught** the bus, he would be here now.
2. If we had booked the hotel, we **would have** a room.
3. If she **were** organised, she would have caught it.
4. If he had booked, he **wouldn't be** waiting.
5. If I **were** taller, I would have joined.
</details>

### Ejercicio 4 — Elige la opción correcta

1. If I had checked the forecast, I ___ a raincoat. → *pack / would pack / would have packed*
2. If she ___ more organised, she would have caught the flight. → *is / were / had been*
3. We ___ at the beach now if the ferry hadn't been cancelled. → *are / would be / will be*
4. Mixed: past → present uses ___ in the if-clause. → *past perfect / past simple / will*
5. If he were braver, he ___ asked for help yesterday. → *will / would / would have*

<details>
<summary>Ver solución</summary>

1. **would have packed** · 2. **were** · 3. **would be** · 4. **past perfect** · 5. **would have**
</details>

### Ejercicio 8 — Traduce

1. Si hubiéramos salido antes, no estaríamos atrapados ahora.
2. Si fuera más alto, habría entrado en el equipo.
3. Si hubiéramos reservado, tendríamos una habitación ahora.
4. Si comprobara el pronóstico, empacaría mejor.
5. Si él hubiera aprobado, empezaría la próxima semana.

<details>
<summary>Ver solución</summary>

1. If we had left earlier, we wouldn't be stuck now.
2. If I were taller, I would have joined the team.
3. If we had booked, we would have a room now.
4. If I checked the forecast, I would pack better. *(2.º condicional, no mixed)*
5. If he had passed, he would start next week.
</details>

### Ejercicio 9 — Mixed vs. 2.º / 3.er condicional puro

Clasifica cada frase: **mixed**, **2.º condicional** o **3.er condicional**.

1. If I had more time, I would travel more.
2. If he had caught the bus, he would be here now.
3. If I had studied, I would have passed the exam.
4. If she were taller, she would have joined the team last year.
5. If we had booked earlier, we would be relaxing on the beach now.

<details>
<summary>Ver solución</summary>

1. **2.º condicional** (presente hipotético → presente hipotético) · 2. **mixed** (pasado → presente) · 3. **3.er condicional** (pasado → pasado) · 4. **mixed** (presente → pasado) · 5. **mixed** (pasado → presente)
</details>

## Tip del profesor

Para identificar qué tipo de mixed conditional necesitas, dibuja mentalmente una línea de tiempo con dos puntos: el momento de la **causa** y el momento del **resultado**. Si la causa está antes en el tiempo que el resultado, y el resultado es "ahora" o "pronto", usa **had + participio → would + infinitivo**. Si la causa es un rasgo estable que sigue siendo cierto, pero el resultado ya ocurrió en el pasado, usa **past simple/were → would have + participio**. Esta línea de tiempo mental es más fiable que memorizar reglas sueltas.

| Tipo | If-clause | Resultado | Ejemplo |
| :--- | :--- | :--- | :--- |

| Pasado → futuro | past perfect | would + infinitivo | If he had passed, he would start next week. |

## Lección 1 — Gramática

**Objetivo:** if + past perfect → would + base (now); if + past simple → would have + pp

### Ejercicios 1–5 — Completa

5. If he had booked online, he ___ waiting in the queue. → *isn't / wouldn't be / won't be*

<details>
<summary>Ver solución</summary>

</details>
