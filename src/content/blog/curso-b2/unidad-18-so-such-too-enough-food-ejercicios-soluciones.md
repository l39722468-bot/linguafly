## Lección 1 — Gramática

**Objetivo:** so / such / too / enough contrasts

### Ejercicios 1–5 — Completa

1. The cake was ___ delicious that we couldn't stop. → *so / such / too*
2. It was ___ a great class that we signed up again. → *such / so / too*
3. The soup was ___ hot to eat. → *too / so / enough*
4. We don't have ___ time to finish. → *enough / too / such*
5. He is experienced ___ to run a kitchen. → *enough / too / so*

<details>
<summary>Ver solución</summary>

1. **so** · 2. **such** · 3. **too** · 4. **enough** · 5. **enough**

</details>

### Ejercicios 6–10 — Elige / completa

1. So + ___ (+ that). → *adjective/adverb / noun only*
2. Such (+ a) + ___. → *noun / adjective alone*
3. Too + adj + ___. → *to-infinitive / that only*
4. Enough goes ___ a noun. → *before / after*
5. Enough goes ___ an adjective. → *after / before*

<details>
<summary>Ver solución</summary>

1. **adjective/adverb** · 2. **noun** · 3. **to-infinitive** · 4. **before** · 5. **after**

</details>

### Ejercicios 11–15 — Corrige

1. *It was so a great class.*
2. *The cake was such delicious.*
3. *The soup was too hot that we waited.* (use to)
4. *We have time enough?* (noun)
5. *He is enough experienced.*

<details>
<summary>Ver solución</summary>

1. It was **such** a great class.
2. The cake was **so** delicious.
3. The soup was too hot **to** eat / we waited because…
4. We have **enough time**.
5. He is experienced **enough**.

</details>

## Lección 5 — Writing

**Objetivo:** producir frases con el foco de la unidad.

1. Escribe so, such, too y enough (2 cada uno).
2. Completa: The cake was ___ delicious that…
3. Completa: It was ___ a great class that…
4. Completa: The soup was ___ hot to eat.
5. Completa: We don't have ___ time.
6. Explica so vs such en 1 frase.
7. Corrige: *It was so a great class.*
8. Corrige: *He is enough experienced.*
9. Párrafo cooking con so/such/too/enough.
10. Traduce: Había tantos ingredientes que…
11. Traduce: No estoy lo bastante hábil para…
12. Diálogo en una clase de cocina.
13. Matching: too/enough → significado.
14. Autochequeo posición de enough.
15. Enlace teoría U18.

<details>
<summary>Ver solución</summary>

1. Open — two of each.
2. **so**
3. **such**
4. **too**
5. **enough**
6. So + adj; such (+ a) + noun.
7. It was **such** a great class.
8. He is experienced **enough**.
9. Open paragraph.
10. There were **so many** ingredients that…
11. I'm not skilled **enough** to…
12. Open dialogue.
13. too = excess; enough = sufficiency.
14. enough + N; adj + enough.
15. [Guía U18](/blog/curso-b2/unidad-18-so-such-too-enough-food)

</details>
