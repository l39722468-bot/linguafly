## Lección 1 — Gramática

**Objetivo:** the… the…; much/far/slightly + comparative; by far + superlative

### Ejercicios 1–5 — Completa

1. ___ more you read, ___ better you write. → *The / the · More / more · The / more*
2. This is ___ the best novel. → *by far / far / more*
3. This edition is ___ more expensive. → *much / more / the most*
4. The new version is ___ better. → *slightly / by far / the*
5. She reads ___ faster than last year. → *far / by far / the*

<details>
<summary>Ver solución</summary>

1. **The / the** · 2. **by far** · 3. **much** · 4. **slightly** · 5. **far**

</details>

### Ejercicios 6–10 — Elige / completa

1. The… the… needs two ___. → *comparatives / superlatives*
2. By far usually modifies a ___. → *superlative / noun only*
3. Much / far / a lot intensify a ___. → *comparative / article*
4. Slightly / a bit = ___ difference. → *small / huge*
5. The longer we waited, the ___ excited we became. → *more / most / much*

<details>
<summary>Ver solución</summary>

1. **comparatives** · 2. **superlative** · 3. **comparative** · 4. **small** · 5. **more**

</details>

### Ejercicios 11–15 — Corrige

1. *More you read, better you write.*
2. *This is far the best novel.*
3. *It is more much expensive.*
4. *She is by far faster than me.* (comparative)
5. *The harder you work, better the draft.*

<details>
<summary>Ver solución</summary>

1. **The** more you read, **the** better you write.
2. This is **by far** the best novel.
3. It is **much more** expensive.
4. She is **far / much** faster than me.
5. The harder you work, **the** better the draft.

</details>

## Lección 3 — Reading: Sam's book club

**Objetivo:** comprender un texto con el foco de la unidad.

### Texto y audio

<audio controls preload="none" src="/audio/blog/curso-b2/unit-19/reading-workbook.mp3" title="🔊 Reading: Sam's book club"></audio>

> Sam runs a book club. The more members read, the better they write reviews. This is by far the best novel the club has ever chosen. The hardback edition is much more expensive than the paperback. The longer they waited for the sequel, the more excited they became. She reads far faster than she did last year. The new translation is slightly better than the old one.

### Ejercicios 1–5 — Comprensión

1. Who runs a book club? → *Sam / Mia / Nora*
2. The more… the better they ___ → *write / cook*
3. By far the ___ novel → *best / better*
4. Hardback ___ more expensive → *much / by far*
5. Than the ___ → *paperback / harness*

<details>
<summary>Ver solución</summary>

1. **Sam** · 2. **write** · 3. **best** · 4. **much** · 5. **paperback**

</details>

### Ejercicios 6–10 — Detalles

6. The longer… the ___ excited → *more / most*
7. Reads ___ faster → *far / by far*
8. Translation is ___ better → *slightly / by far*
9. Two comparatives in the…the…? → *True / False*
10. Club chose a novel? → *True / False*

<details>
<summary>Ver solución</summary>

6. **more** · 7. **far** · 8. **slightly** · 9. **True** · 10. **True**

</details>

### Ejercicios 11–15 — Forma

## Lección 5 — Writing

**Objetivo:** producir frases con el foco de la unidad.

1. Escribe the…the…, by far, much/far + comp. y slightly + comp.
2. Completa: ___ more you read, ___ better you write.
3. Completa: This is ___ the best novel.
4. Completa: This edition is ___ more expensive.
5. Completa: The translation is ___ better.
6. Explica by far vs far.
7. Corrige: *More you read, better you write.*
8. Corrige: *This is far the best book.*
9. Párrafo literature con comparativos avanzados.
10. Traduce: Cuanto más lees, mejor escribes.
11. Traduce: Es, con diferencia, la mejor novela.
12. Diálogo en un club de lectura.
13. Matching: intensifier → uso.
14. Autochequeo: dos comparativos en the…the…
15. Enlace teoría U19.

<details>
<summary>Ver solución</summary>

1. Open — one of each pattern.
2. **The / the**
3. **by far**
4. **much**
5. **slightly**
6. By far + superlative; far/much + comparative.
7. **The** more you read, **the** better you write.
8. This is **by far** the best book.
9. Open paragraph.
10. The more you read, the better you write.
11. It is **by far** the best novel.
12. Open dialogue.
13. much/far→comp.; by far→superl.; slightly→small gap.
14. Self-check parallel comparatives.
15. [Guía U19](/blog/curso-b2/unidad-19-advanced-comparatives-literature)

</details>
