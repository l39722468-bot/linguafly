## Qué aprenderás en la Unidad 41 (A1)

Al terminar esta unidad serás capaz de:

- Usar ***must + verbo base*** para obligaciones en el aeropuerto.
- Usar ***should + verbo base*** para consejos y recomendaciones.
- Nombrar ***passport, ticket, check-in, boarding pass, gate, boarding***.
- Seguir el flujo: facturación → tarjeta de embarque → puerta → embarque.
- Entender y producir instrucciones simples de aeropuerto.

## 1. Must vs should

| Modal | Significado | Ejemplo |
| :--- | :--- | :--- |
| **must** | obligación (debes) | You **must** show your passport. |
| **should** | consejo (deberías) | You **should** arrive early. |

![Must vs should A1](/blog/curso-a1/unit-41/a1-unit41-must-should.png)

```
must / should + base verb
→ must show · should go · must have · should arrive
(NO: must to show / should going)
```

### Tip

**Must** = regla o necesidad fuerte (*tienes que*).  
**Should** = buena idea (*conviene*). En el aeropuerto: *must show passport*; *should go to the gate early*.

### Contraste con can (U31) y Can I…? (U38)

| Forma | Uso | Ejemplo |
| :--- | :--- | :--- |
| **can** | habilidad | I **can** swim. |
| **Can I…?** | permiso | **Can I** use the bathroom? |
| **must** | obligación | You **must** show your passport. |
| **should** | consejo | You **should** arrive early. |

6. ¿Cuántas maletas? → **One**.

## 7. Errores típicos de hispanohablantes

| ❌ Incorrecto | ✅ Correcto | Explicación |
| :--- | :--- | :--- |
| *You must **to** show* | *You must **show*** | sin *to* |
| *You should **going*** | *You should **go*** | verbo base |
| *You must show **the** passport* (siempre) | *You must show **your** passport* | posesivo habitual |
| *Go to the gate **number the** ten* | *Go to gate **number ten*** | *gate number + número* |
| *I must **can** show* | *I must show* | un modal por frase en A1 |
| Confundir *must* y *should* | *must* = obligación; *should* = consejo | significado distinto |

## 9. Mini-diálogos para memorizar

> **A:** Where is check-in?  
> **B:** Over there. You must show your passport.  
> **A:** What gate?  
> **B:** Gate ten. You should go early.

> **A:** Do I need my ticket?  
> **B:** Yes — you must have your ticket ready.  
> **A:** And then?  
> **B:** You get your boarding pass and go to the gate.

> **A:** Should I go to the gate now?  
> **B:** Yes. Boarding starts in ten minutes.  
> **A:** I have my boarding pass.  
> **B:** Perfect. Have a good flight!

Cambia solo el número de puerta o la ciudad: fijas ***must / should + base verb***.
