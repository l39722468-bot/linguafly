## Qué aprenderás en la Unidad 16 (A1)

Al terminar esta unidad serás capaz de:

- Pedir con ***Can I have…, please?***
- Pedir con ***I'd like…*** (*I would like*).
- Responder a ***Would you like something to drink/eat?***
- Usar vocabulario de **café**, **snacks** y **servicio**.
- Preguntar el **precio** y pedir **la cuenta**.

## 1. Vocabulario: bebidas, snacks y servicio

### Bebidas

| Inglés | Español | Ejemplo |
| :--- | :--- | :--- |
| **coffee** | café | Can I have a coffee, please? |
| **tea** | té | I'd like a tea, please. |
| **(orange) juice** | zumo (de naranja) | I'd like an orange juice. |
| **water** | agua | Can I have a water, please? |
| **milk** | leche | Would you like milk? |

### Snacks / comida

| Inglés | Español | Ejemplo |
| :--- | :--- | :--- |
| **croissant** | croissant | I'd like a croissant. |
| **sandwich** | bocadillo | Can I have a sandwich? |
| **cake** | tarta / pastel | Would you like some cake? |
| **cookie** | galleta | I'd like a cookie. |
| **toast** | tostada | Can I have toast, please? |

### Servicio y precios

| Inglés | Español | Ejemplo |
| :--- | :--- | :--- |
| **counter** | mostrador | I'm at the counter. |
| **table / chair** | mesa / silla | A table for two. |
| **bill** | cuenta | Can I have the bill, please? |
| **How much is it?** | ¿Cuánto es / cuesta? | How much is the coffee? |
| **Anything else?** | ¿Algo más? | No, that's all, thanks. |
| **please / thanks** | por favor / gracias | A tea, please. Thanks! |

### Tips de uso

- En A1 suele decirse *a coffee / a tea* (una taza), aunque en casa digas *coffee* sin artículo.  
- *orange juice* → **an** orange juice (empieza por vocal).  
- *the bill* = la cuenta (con *the*).  
- Añade **please** al pedir: suena educado y natural.

## 2. *Can I have…?*

Fórmula de pedido educado:

```
Can I have + a/an + cosa, please?
```

| Pedido | Significado |
| :--- | :--- |
| **Can I have** a coffee, please? | ¿Me pone un café, por favor? |
| **Can I have** a tea, please? | ¿Me pone un té, por favor? |
| **Can I have** a sandwich, please? | ¿Me pone un bocadillo, por favor? |
| **Can I have** the bill, please? | ¿La cuenta, por favor? |

Es más educado que *Give me a coffee* o *I want a coffee*.

## 3. *I'd like…* / *I would like…*

```
I'd like + a/an + cosa, please.
```

*I'd* = *I would*. Misma idea: “Me gustaría…”.

| Pedido | Significado |
| :--- | :--- |
| **I'd like** a tea, please. | Me gustaría un té. |
| **I'd like** a croissant, please. | Me gustaría un croissant. |
| **I'd like** an orange juice. | Me gustaría un zumo de naranja. |
| **I would like** a sandwich, please. | Forma completa (más formal). |

### *Can I have* vs *I'd like*

| | Uso típico |
| :--- | :--- |
| **Can I have…?** | Pedido directo y educado en el mostrador |
| **I'd like…** | Pedido suave; también responde a *Would you like…?* |

Ambas son correctas en un café. Practica las dos.

## 4. *Would you like…?* (ofertas del camarero)

El personal pregunta:

```
Would you like + something to drink / eat?
Would you like + a/an + cosa?
```

| Oferta | Respuesta típica |
| :--- | :--- |
| Would you like something to drink? | Yes, I'd like a coffee. / No, thanks. |
| Would you like something to eat? | Yes, a croissant please. |
| Would you like milk? | Yes, please. / No, thank you. |
| Anything else? | No, that's all, thanks. |

| **How much is the coffee?** | ¿Cuánto cuesta el café? |

## 6. Diálogo modelo completo

> **Waiter:** Hi! What can I get you?  
> **Sara:** Can I have a coffee, please?  
> **Waiter:** Would you like something to eat?  
> **Sara:** Yes, I'd like a croissant, please.  
> **Waiter:** Anything else?  
> **Sara:** No, that's all, thanks. How much is it?  
> **Waiter:** Three euros twenty.  
> **Sara:** Can I have the bill, please?  
> **Waiter:** Sure. Here you are.  
> **Sara:** Thank you!

Otro diálogo breve:

> **Tom:** I'd like a tea and a sandwich, please.  
> **Server:** Would you like milk in your tea?  
> **Tom:** Yes, please.  
> **Server:** OK. That's four euros.  
> **Tom:** Thanks!

## 7. Errores típicos de hispanohablantes

| ❌ Incorrecto | ✅ Correcto | Explicación |
| :--- | :--- | :--- |
| *Give me a coffee* | *Can I have a coffee, please?* | Más educado |
| *I want a tea* (seco) | *I'd like a tea, please* | Suave y natural |
| *Can I have coffee?* (sin *a*) | *Can I have **a** coffee?* | En café: *a coffee* = una taza |
| *I'd like a orange juice* | *I'd like **an** orange juice* | Vocal → *an* |
| *Can I have bill?* | *Can I have **the** bill?* | *the bill* |
| *How many is the coffee?* | *How **much** is the coffee?* | Precio → *much* |
| *I like a coffee* (pedido) | *I'd like a coffee* | Pedido = *would like*, no *like* |

---

## 8. Pronunciación útil

| Forma | Tip A1 |
| :--- | :--- |
| **Can I have** | *Can* a menudo se debilita; practica claro: *Can I have…?* |
| **I'd like** | *I'd* = *aid* corto + *like*. |
| **Would you like** | En habla rápida: *wood-ya like*. Primero di las tres palabras. |
| **please** | Al final del pedido: *…, please?* |
| **bill** | Suena *bil*. |

Escucha los audios y repite dos veces cada pedido. Grábate pidiendo café + croissant.

### Mapa de cortesía (de menos a más educado)

| Menos educado | Mejor en A1 |
| :--- | :--- |
| Give me a coffee. | Can I have a coffee, please? |
| I want a tea. | I'd like a tea, please. |
| Do you want juice? | Would you like some juice? |

No hace falta sonar “demasiado formal” en un café: con *please*, *Can I have* e *I'd like* ya entras bien en casi cualquier sitio en inglés.

---

## 8b. Mini-diálogos para memorizar

> **A:** Can I have a coffee, please?  
> **B:** Sure. Would you like milk?  
> **A:** Yes, please.  
> **B:** Anything else?  
> **A:** No, that's all. How much is it?  
> **B:** Two euros fifty.

> **A:** Would you like something to drink?  
> **B:** Yes, I'd like an orange juice.  
> **A:** Would you like something to eat?  
> **B:** I'd like a sandwich, please.

> **A:** Can I have the bill, please?  
> **B:** Of course. One moment.

Cambia solo la bebida o el snack: así fijas la estructura sin aprender diálogos de memoria largos.

---

## 8c. Plantillas para copiar

1. Can I have a \_\_\_\_, please?  
2. I'd like a \_\_\_\_ and a \_\_\_\_, please.  
3. Would you like something to drink? — Yes, I'd like \_\_\_\_.  
4. How much is the \_\_\_\_?  
5. Can I have the bill, please?

Rellena con tu pedido habitual (café con leche, té, zumo…). Si lo dices en voz alta cada mañana, se queda.

### Más ejemplos en contexto

> At the counter: *Hi! Can I have a coffee and a cookie, please?*  
> With a friend: *I'd like a tea. And you?* — *I'd like an orange juice.*  
> The waiter asks: *Would you like something to eat?* — *Yes, a sandwich please.*  
> Paying: *How much is it?* — *Four euros.* — *Can I have the bill, please?*

Practica también **pedidos dobles**: bebida + snack. Es lo más realista en una cafetería (*a coffee and a croissant*).

3. \_\_\_\_ the bill, please?

### Ejercicio 4 — Corrige el error

1. *Give me a coffee.*  
2. *I want tea.* (hazlo educado)  
3. *I'd like a orange juice.*  
4. *Can I have bill?*  
5. *How many is the coffee?*

4. Can I have **the** bill?

### Ejercicio 6 — Escribe tu pedido

## 10. Plan de práctica (15 minutos)

1. **3 min** — Repite: *Can I have a coffee / tea / water, please?*  
2. **3 min** — Repite: *I'd like a croissant / sandwich / juice.*  
3. **4 min** — Escucha los audios y actúa el diálogo modelo.  
4. **5 min** — Escribe tu pedido habitual + *How much* + *the bill*.

### Checklist

- [ ] Sé pedir con *Can I have…, please?*  
- [ ] Sé pedir con *I'd like…*  
- [ ] Respondo a *Would you like…?*  
- [ ] Uso *a/an* y *the bill* correctamente  
- [ ] Pregunto *How much is it?*
