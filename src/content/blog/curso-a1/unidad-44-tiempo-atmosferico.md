En la [Unidad 43](/blog/curso-a1/unidad-43-verbos-viaje-horarios) hablaste de horarios de viaje. En la **Unidad 44 del curso A1** (*The Weather*) describes el **tiempo atmosférico**: ***It is sunny***, ***It is raining***, ***hot / cold***.

Repasas *It is…* del verbo *to be* y conectas con viajes del Módulo 5. Incluye **audios**, **esquemas** y **ejercicios**.

## Qué aprenderás en la Unidad 44 (A1)

Al terminar esta unidad serás capaz de:

- Usar ***It is + adjetivo***: *sunny, rainy, cloudy, snowy, hot, cold*.
- Usar ***It is raining / It is snowing*** para la acción ahora.
- Preguntar: ***What is the weather like today?***
- Contrastar ***today (is)*** y ***yesterday (was)***.
- Decir qué tiempo prefieres (*I prefer sunny weather*).

---

## 1. It is + adjetivo de tiempo

| Forma | Ejemplo |
| :--- | :--- |
| It **is sunny** | It is sunny today. |
| It **is rainy** | It is rainy this morning. |
| It **is cloudy** | It is cloudy. |
| It **is snowy** | It is snowy in winter. |
| It **is hot** | It is hot in summer. |
| It **is cold** | It is cold today. |

![It is + weather A1](/blog/curso-a1/unit-44/a1-unit44-it-is-weather.png)

```
It is + weather adjective
→ sunny · rainy · cloudy · snowy · hot · cold

It is + -ing (now)
→ It is raining · It is snowing
```

### Tip

Sujeto fijo: ***It***. No digas *The weather is sunny* al principio (también existe, pero en A1 priorizamos *It is sunny*).

### Adjetivo vs -ing

| Adjetivo | Acción ahora |
| :--- | :--- |
| It is **rainy**. | It is **raining**. |
| It is **snowy**. | It is **snowing**. |
| It is **sunny**. | — (no *It is sunning*) |

## 4. Today vs yesterday

![Today vs yesterday A1](/blog/curso-a1/unit-44/a1-unit44-today-yesterday.png)

| Tiempo | Forma | Ejemplo |
| :--- | :--- | :--- |
| Hoy | It **is**… | Today it is sunny and hot. |
| Ayer | It **was**… | Yesterday it was cloudy and rainy. |
| Acción ayer | It **was raining** | It was raining in the afternoon. |

### Tip

*Is* = ahora / hoy. *Was* = ayer. Misma estructura: *It + is/was + adjetivo* o *It + is/was + raining/snowing*.

## 8. Errores típicos de hispanohablantes

| ❌ Incorrecto | ✅ Correcto | Explicación |
| :--- | :--- | :--- |
| *It **are** sunny* | *It **is** sunny* | sujeto *It* |
| *It is **sun*** | *It is **sunny*** | adjetivo |
| *It is **rain*** | *It is **rainy*** / *It is **raining*** | adjetivo o *-ing* |
| *The day is sunny* (menos A1) | *It is sunny* | fórmula estándar |
| *Yesterday it **is** rainy* | *Yesterday it **was** rainy* | pasado |
| *What weather is today?* | *What **is the weather like** today?* | pregunta fija |

Cambia solo el adjetivo: fijas ***It is… / It was…***.

1. Today it \_\_\_\_ sunny.  
2. Yesterday it \_\_\_\_ rainy.  
3. It \_\_\_\_ raining now.  
4. Yesterday it \_\_\_\_ raining in the afternoon.  
5. In summer it \_\_\_\_ hot.

<details>
<summary>Ver solución</summary>

1. **is**  
2. **was**  
3. **is**  
4. **was**  
5. **is**
</details>

<details>

2. **cloudy**  
3. **rainy**  
4. **cold**  
5. **hot**
</details>
