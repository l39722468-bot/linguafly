En la [Unidad 21](/blog/curso-a1/unidad-21-habitaciones-casa) nombraste las habitaciones. En la **Unidad 22 del curso A1** (*Furniture & Household Items*) las **llenas de muebles** y dices **de quién son** con ***mine, yours, his, hers***.

Esta guía cubre el **vocabulario de furniture**, la diferencia ***my / mine***, la pregunta ***Whose…?*** y frases con *There is… in the…*. Incluye **audios**, **esquemas** y **ejercicios** (más de 2000 palabras). Conecta con los posesivos de la [Unidad 6](/blog/curso-a1/unidad-6-familia-posesivos-genitivo) (*my, your, his, her*) y da el paso a los **pronombres** (*mine, yours…*).

## Qué aprenderás en la Unidad 22 (A1)

Al terminar esta unidad serás capaz de:

- Nombrar **muebles** básicos (*bed, sofa, table, fridge…*).
- Relacionar muebles con **habitaciones**.
- Usar ***mine / yours / his / hers / ours*** sin nombre detrás.
- Distinguir ***my sofa*** vs ***It's mine***.
- Preguntar ***Whose is this?*** / ***Is this yours?***.

## 2. *My* vs *mine* (y el resto)

| Determinante (+ nombre) | Pronombre (solo) |
| :--- | :--- |
| **my** sofa | **mine** |
| **your** chair | **yours** |
| **his** bed | **his** |
| **her** bag | **hers** |
| **our** table | **ours** |
| **their** keys | **theirs** *(intro)* |

**Regla clave:**

- Con nombre → *my / your / her…*  
- Sin nombre → *mine / yours / hers…*

> This is **my** sofa. → This sofa is **mine**.  
> That is **your** chair. → That chair is **yours**.  
> This is **her** bag. → This bag is **hers**.  
> The bed is **his**.  
> That table is **ours**.

### Parejas que más confunden

| ❌ | ✅ |
| :--- | :--- |
| *This is my.* | This is **mine**. / This is **my** sofa. |
| *This is mine sofa.* | This is **my** sofa. / This sofa is **mine**. |
| *This bag is her.* | This bag is **hers**. |
| *Is this pen your?* | Is this pen **yours**? |

*His* no cambia: *his bed* / *The bed is his.*

## 3. *Whose…?* e *Is this yours?*

```
Whose + (noun) + is this/that?
Is this + noun + yours/mine/his/hers?
```

| Pregunta | Respuesta |
| :--- | :--- |
| **Whose** is this? | It's **mine**. / It's **hers**. |
| **Whose sofa** is this? | It's **mine**. |
| **Is this pen yours?** | Yes, it's **mine**. / No, it's **his**. |
| Whose keys are these? | They're **ours**. |

## 4. Muebles + habitaciones (juntar U21 + U22)

> There is a **bed** and a **wardrobe** in the **bedroom**.  
> There is a **sofa** in the **living room**.  
> The **fridge** is in the **kitchen**.  
> There is a **table** and four **chairs** in the dining room.  
> I sit on the **sofa**. I sleep in the **bed**.

### Texto modelo

> In my bedroom there is a bed, a wardrobe and a lamp. The bed is mine. The desk is also mine.  
> In the living room there is a sofa and a table. The sofa is ours.  
> In the kitchen there is a fridge. Whose fridge is it? It's ours!

---

## 5. Diálogo modelo

> **Ana:** Whose sofa is this?  
> **Luis:** It's mine. And that chair is yours.  
> **Ana:** Nice! Is this bag yours?  
> **Luis:** No, it's hers — Sara's bag.  
> **Ana:** And the bed upstairs?  
> **Luis:** The bed is his. Tom sleeps there.  
> **Ana:** Cool. In my flat there is a sofa in the living room and a fridge in the kitchen.  
> **Luis:** Same here. That table is ours.

## 6. Errores típicos de hispanohablantes

| ❌ Incorrecto | ✅ Correcto | Explicación |
| :--- | :--- | :--- |
| *This is my* | *This is **mine*** | Falta nombre o usa pronombre |
| *This is mine sofa* | *This is **my** sofa* | Con nombre → *my* |
| *This bag is her* | *This bag is **hers*** | Pronombre = *hers* |
| *Is this pen your?* | *Is this pen **yours**?* | Pregunta con *yours* |
| *Whose is this sofa is?* | *Whose sofa is this?* | Orden fijo |
| *I sit in the sofa* | *I sit **on** the sofa* | *on* para sofá/silla |
| *The fridge is on the kitchen* | *The fridge is **in** the kitchen* | *in* la habitación |

## 7. Pronunciación útil

| Forma | Tip A1 |
| :--- | :--- |
| **mine / yours** | *yours* suena *yorz*. |
| **hers** | Con *-s* final: *herz*. |
| **whose** | Como *huuz* (/huːz/), no como *who is* escrito raro. |
| **wardrobe** | *WOR-drobe*. |
| **fridge** | Una sílaba: *frij*. |

Escucha los audios de posesivos y repite el par: *This is my sofa* → *This sofa is mine.*

## 7b. Mini-diálogos para memorizar

> **A:** Is this chair yours?  
> **B:** Yes, it's mine.  
> **A:** And that bag?  
> **B:** It's hers.

> **A:** Whose bed is this?  
> **B:** It's his.  
> **A:** Whose table is that?  
> **B:** It's ours.

> **A:** Where is the fridge?  
> **B:** It's in the kitchen. There is a table too.

Cambia solo el mueble: fijas *mine/yours/his/hers* sin diálogos largos.

## 7c. Plantillas para copiar

1. This is my \_\_\_\_. → This \_\_\_\_ is mine.  
2. That chair is \_\_\_\_. (yours / his / hers)  
3. Whose \_\_\_\_ is this? — It's \_\_\_\_.  
4. There is a \_\_\_\_ in the \_\_\_\_.  
5. Is this \_\_\_\_ yours? — Yes, it's mine.

### Más frases para memorizar

> This sofa is mine.  
> That chair is yours.  
> The bed is his.  
> This bag is hers.  
> That table is ours.  
> Is this pen yours? — Yes, it's mine.  
> Whose is this? — It's hers.  
> There is a bed and a wardrobe in the bedroom.  
> The fridge is in the kitchen.  
> I sit on the sofa.

Lee la lista dos veces. Señala objetos reales en tu casa y di *This … is mine*. Si estudias con alguien, intercambiad *Is this yours?*

### Conexión con Unidad 6

| U6 (determinante) | U22 (pronombre) |
| :--- | :--- |
| This is **my** book. | This book is **mine**. |
| Is this **your** pen? | Is this pen **yours**? |
| **His** name is Tom. | The bag is **his**. |
| **Her** bag is red. | The bag is **hers**. |

No sustituyas una por otra al azar: mira si hay **nombre** después o no.

### Rutina de 2 minutos

1. Nombra 8 muebles.  
2. Di 4 frases *There is a … in the …*.  
3. Di 4 frases *This … is mine/yours/his/hers*.  
4. Pregunta en voz alta: *Whose is this?*

Si lo haces cada día junto a tu escritorio, *mine/yours* deja de mezclarse con *my/your*.

### Mini-juego en casa (muy efectivo)

Señala cinco objetos y di en voz alta la pareja completa:

> This is my lamp. → This lamp is mine.  
> This is my chair. → This chair is mine.  
> This is our table. → This table is ours.

Luego inventa tres frases con *his* y *hers* (hermanos, compañeros, vecinos imaginarios). Ese contraste *my/mine* + *his/hers* es el núcleo gramatical de la unidad.

### Tour de muebles (modelo para imitar)

> Welcome to my flat. In the hall there is a lamp. In the living room there is a sofa and a shelf. The sofa is ours. In the bedroom there is a bed, a wardrobe and a desk. The bed is mine. The desk is mine too. In the kitchen there is a fridge and a table. Whose chair is this? It's yours!

Cambia los posesivos y los muebles a tu realidad. Es un speaking de un minuto perfecto para esta unidad.

### Checklist mental antes del speaking

- ¿Usé *mine/yours/hers* **sin** nombre detrás?  
- ¿Usé *my/your/her* **con** nombre (*my sofa*)?  
- ¿Pregunté con *Whose…?* al menos una vez?  
- ¿Coloqué al menos tres muebles con *There is… in the…*?  
- ¿Evité *This is my* y *This is mine sofa*?

Si marcas sí en todos, tu descripción de casa + posesivos ya está lista para la Unidad 22.



### Un último tip

Cuando dudes entre *my* y *mine*, pregunta: ¿viene un nombre justo después? Si sí → *my*. Si no → *mine*. La misma prueba vale para *your/yours* y *her/hers*. Practícala con diez objetos de tu habitación y el error desaparece en pocos días.
También puedes grabarte haciendo el tour de muebles y escucharlo al día siguiente: si oyes *This is my* solo, corrígelo en el momento a *This is mine* o *This is my sofa*.


## 9. Plan de práctica (15 minutos)

1. **3 min** — Repite los 9 muebles con audio.  
2. **4 min** — Transforma: *This is my X* → *This X is mine* (6 objetos).  
3. **4 min** — Preguntas *Whose…?* / *Is this yours?*  
4. **4 min** — Escribe tu párrafo de muebles + posesivos.

### Checklist

- [ ] Sé bed, sofa, table, chair, fridge, wardrobe…  
- [ ] Distingo *my* / *mine* y *your* / *yours*  
- [ ] Uso *his* y *hers* correctamente  
- [ ] Pregunto *Whose is this?*  
- [ ] Coloco muebles con *There is… in the…*

## 10. Consejos para practicar

1. **Etiqueta** 5 objetos en casa: *mine* en un post-it (juego mental).  
2. **Haz fotos** de habitaciones y descríbelas en inglés.  
3. **Combina** con U21: habitación + mueble + adjetivo (*The bedroom is cozy. The bed is mine.*).  
4. Prepárate para la [Unidad 23](/curso-a1/unit-23): más *There is / There are*.
