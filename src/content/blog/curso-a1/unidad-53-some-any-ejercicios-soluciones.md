## Lección 1 — Gramática: some y any

**Objetivo:** *some* en afirmativas; *any* en negativas y preguntas.

### Ejercicios 1–5 — Completa

1. I have ____ milk in the fridge. → *some / any / many*  
2. There isn't ____ bread left. → *any / some / many*  
3. Do you have ____ eggs? → *any / some / much*  
4. We need ____ water and ____ apples. → *some, some / any, any / any, some*  
5. She doesn't have ____ rice. → *any / some / many*

<details>
<summary>Ver solución</summary>

1. **some** — afirmativa.  
2. **any** — negativa.  
3. **any** — pregunta.  
4. **some, some** — dos afirmativas.  
5. **any**

</details>

### Ejercicios 6–10 — Elige

6. We use *some* in ____. → a) affirmative sentences · b) negative only · c) questions only  
7. We use *any* in ____. → a) negatives and questions · b) affirmative only · c) never in questions  
8. Correct: ____. → a) I have some milk · b) I have any milk · c) I don't have some milk  
9. Correct: ____. → a) Do you have any eggs? · b) Have you some eggs? · c) You have any eggs?  
10. *There isn't any* = ____. → a) negative + any · b) affirmative · c) question

<details>
<summary>Ver solución</summary>

6. **a) affirmative sentences**  
7. **a) negatives and questions**  
8. **a) I have some milk**  
9. **a) Do you have any eggs?**  
10. **a) negative + any**

</details>

### Ejercicios 11–13 — Ordena

11. I have / some / milk / in / the fridge.  
12. Do you have / any / bread?  
13. There isn't / any / rice / left.

<details>
<summary>Ver solución</summary>

11. I have some milk in the fridge.  
12. Do you have any bread?  
13. There isn't any rice left.

</details>

### Ejercicios 14–15 — Verdadero o falso

14. *Some* in affirmatives; *any* in negatives and questions. → True / False  
15. We can use *some* in questions when we offer (*Would you like some?*). → True / False

<details>
<summary>Ver solución</summary>

14. **True**  
15. **True**

</details>

## Lección 2 — Vocabulario: contenedores

**Objetivo:** *bottle, box, bag, can* + *a … of …*.

### Ejercicios 1–5 — Elige el significado

1. *Bottle* = ____. → a) a container for liquid (water, milk) · b) a box · c) a bag  
2. *Box* = ____. → a) a cardboard or plastic container · b) a bottle · c) a can  
3. *Bag* = ____. → a) a container you can carry (paper, plastic) · b) a bottle · c) a box  
4. *Can* = ____. → a) a metal container (cola, beans) · b) a bottle · c) a bag  
5. *A bottle of water* = ____. → a) one bottle containing water · b) many bottles · c) a box

<details>
<summary>Ver solución</summary>

1. **a) a container for liquid (water, milk)**  
2. **a) a cardboard or plastic container**  
3. **a) a container you can carry (paper, plastic)**  
4. **a) a metal container (cola, beans)**  
5. **a) one bottle containing water**

</details>

### Ejercicios 6–7 — Empareja

6. Empareja: bottle / box / bag / can / some → water, milk · cereal, eggs · shopping, potatoes · cola, beans · affirmative  
7. Empareja: a bottle of / a box of / a bag of / a can of / any → milk · cereal · apples · cola · negative, question

<details>
<summary>Ver solución</summary>

6. **bottle → water, milk** · **box → cereal, eggs** · **bag → shopping, potatoes** · **can → cola, beans** · **some → affirmative**  
7. **a bottle of → milk** · **a box of → cereal** · **a bag of → apples** · **a can of → cola** · **any → negative, question**

</details>

### Ejercicios 8–13 — Completa / elige

8. I need a ____ of water. → *bottle / box / can*  
9. There is a ____ of cereal on the table. → *box / bottle / bag*  
10. Buy a ____ of cola. → *can / bottle / box*  
11. *A bag of* ____. → a) potatoes, oranges · b) milk · c) cola  
12. We say ____ for containers. → a) a bottle of, a box of, a can of · b) bottle water · c) can cola  
13. *Some* and *any* go before ____. → a) uncountable or plural nouns · b) only singular · c) only plural

<details>
<summary>Ver solución</summary>

8. **bottle**  
9. **box**  
10. **can**  
11. **a) potatoes, oranges**  
12. **a) a bottle of, a box of, a can of**  
13. **a) uncountable or plural nouns**

</details>

### Ejercicios 14–15 — Verdadero o falso

14. A can is usually metal for drinks or food. → True / False  
15. We say *some water* and *any eggs* with *some/any*. → True / False

<details>
<summary>Ver solución</summary>

14. **True**  
15. **True**

</details>

## Lección 3 — Reading: In the fridge

**Objetivo:** leer sobre comida en casa con *some/any* y contenedores.

### Texto

<audio controls preload="none" src="/audio/blog/curso-a1/unit-53/reading-some-any.mp3" title="🔊 Reading: In the fridge"></audio>

> I open the fridge. There is some milk and some water in bottles. There isn't any bread left. In the cupboard I have some rice in a box and some cans of beans. Do we have any fruit? Yes, there are some apples in the bag. I need to buy some bread and some eggs if they have any.

### Ejercicios 1–5 — Elige la respuesta correcta

1. Where is the writer at the start? → a) Opening the fridge · b) In the shop · c) In the cupboard  
2. Is there any milk? → a) Yes, some · b) No · c) The text doesn't say  
3. Is there any bread left? → a) No · b) Yes · c) Some  
4. Where is the rice? → a) In a box in the cupboard · b) In the fridge · c) In a bag  
5. What is in cans? → a) Beans · b) Milk · c) Rice

<details>
<summary>Ver solución</summary>

1. **a) Opening the fridge**  
2. **a) Yes, some**  
3. **a) No**  
4. **a) In a box in the cupboard**  
5. **a) Beans**

</details>

### Ejercicios 6–10 — Comprensión

6. Do they have any fruit? → a) Yes, some apples · b) No · c) Only rice  
7. Where are the apples? → a) In the bag · b) In the fridge · c) In the box  
8. What does he/she need to buy? → a) Some bread and eggs · b) Milk and water · c) Rice and beans  
9. Which word means *ninguno/nada* in negatives? → a) Any · b) Some · c) Many  
10. *Bottle* means ____. → a) a container for milk, water · b) a box · c) a bag

<details>
<summary>Ver solución</summary>

6. **a) Yes, some apples**  
7. **a) In the bag**  
8. **a) Some bread and eggs**  
9. **a) Any**  
10. **a) a container for milk, water**

</details>

### Ejercicios 11–15 — Detalles

11. The text is about ____. → a) what is in the fridge/cupboard, some/any · b) a cooking recipe · c) a restaurant  
12. *Some* in affirmatives means ____. → a) algo/algunos · b) nada · c) only in questions  
13. *Cupboard* means ____. → a) a place for food storage · b) a fridge · c) a bag  
14. *Left* means ____. → a) remaining · b) left side · c) bought  
15. The main topic is ____. → a) food at home, some/any, containers · b) a shopping list only · c) a recipe

<details>
<summary>Ver solución</summary>

11. **a) what is in the fridge/cupboard, some/any**  
12. **a) algo/algunos**  
13. **a) a place for food storage**  
14. **a) remaining**  
15. **a) food at home, some/any, containers**

</details>

## Lección 4 — Listening: Do you have any bread?

**Objetivo:** escuchar un diálogo con *some/any* y contenedores.

### Audio y guion

<audio controls preload="none" src="/audio/blog/curso-a1/unit-53/listening-some-any.mp3" title="🔊 Listening: Do you have any bread?"></audio>

> **A:** Do you have any bread?  
> **B:** No, I don't have any.  
> **A:** I have some in the bag. Do you need a bottle of water or some milk?  
> **B:** Some milk, please.  
> **A:** There are some cans of cola in the fridge. Do you want any?  
> **B:** No, thanks. I need to buy some eggs and a box of cereal.

### Ejercicios 1–5 — Comprensión

1. Does B have any bread? → a) No · b) Yes · c) Some  
2. Where does A have some bread? → a) In the bag · b) In the fridge · c) In a box  
3. What does B want — water or milk? → a) Some milk · b) Water · c) Both  
4. Where are the cans of cola? → a) In the fridge · b) In the bag · c) On the table  
5. Does B want any cola? → a) No · b) Yes · c) Maybe

<details>
<summary>Ver solución</summary>

1. **a) No**  
2. **a) In the bag**  
3. **a) Some milk**  
4. **a) In the fridge**  
5. **a) No**

</details>

### Ejercicios 6–10 — Detalles

6. What does B need to buy? → a) Some eggs and a box of cereal · b) Bread and milk · c) Cola  
7. *A bottle of water* means ____. → a) one bottle with water · b) many bottles · c) a box  
8. The dialogue is about ____. → a) offering/asking for food, some/any · b) cooking · c) shopping at the supermarket only  
9. *Do you have any…?* uses ____. → a) any in a question · b) some in a question · c) many  
10. *I have some* uses ____. → a) some in an affirmative · b) any in an affirmative · c) any in a negative

<details>
<summary>Ver solución</summary>

6. **a) Some eggs and a box of cereal**  
7. **a) one bottle with water**  
8. **a) offering/asking for food, some/any**  
9. **a) any in a question**  
10. **a) some in an affirmative**

</details>

### Ejercicios 11–15 — Forma

11. *I don't have any* = ____. → a) negative + any · b) affirmative · c) question  
12. *Box of cereal* means ____. → a) one box containing cereal · b) many boxes · c) a bottle  
13. *No, thanks* means ____. → a) a polite refusal · b) yes please · c) a question  
14. *Some cans* = ____. → a) plural, countable · b) uncountable · c) singular  
15. The main idea is ____. → a) asking/offering food with some/any and containers · b) cooking · c) at a restaurant

<details>
<summary>Ver solución</summary>

11. **a) negative + any**  
12. **a) one box containing cereal**  
13. **a) a polite refusal**  
14. **a) plural, countable**  
15. **a) asking/offering food with some/any and containers**

</details>

## Lección 5 — Writing: Some / any

**Objetivo:** escribir con *some/any* y contenedores.

### Ejercicios 1–5 — Completa

1. I have ____ milk in the fridge. → *some / any / many*  
2. There isn't ____ bread left. → *any / some / many*  
3. Do you have ____ eggs? → *any / some / much*  
4. We need ____ water and ____ apples. → *some, some / any, any / any, some*  
5. She doesn't have ____ rice. → *any / some / many*

<details>
<summary>Ver solución</summary>

1. **some**  
2. **any**  
3. **any**  
4. **some, some**  
5. **any**

</details>

### Ejercicios 6–8 — Ordena

6. I have / some / milk / in / the fridge.  
7. Do you have / any / bread?  
8. There are / some / cans / of / cola.

<details>
<summary>Ver solución</summary>

6. I have some milk in the fridge.  
7. Do you have any bread?  
8. There are some cans of cola.

</details>

### Ejercicios 9–15 — Escribe (modelos)

9. Tengo algo de leche en la nevera.  
10. Pregunta: ¿Tienes pan? (*Do you have any bread?*).  
11. Dos frases: no hay arroz; necesito una botella de agua.  
12. Pregunta *Do you have any eggs?* y respuesta *Yes, I have some.*  
13. Párrafo corto (3–4 frases): nevera/despensa con *some/any* y contenedores.  
14. Lista de compra con *some* y *a bottle of / a box of*.  
15. Diferencia *some* (afirmativa) y *any* (negativa) en 2 frases.

<details>
<summary>Ver solución (ejemplos)</summary>

9. I have some milk in the fridge.  
10. Do you have any bread?  
11. There isn't any rice left. I need a bottle of water.  
12. Do you have any eggs? Yes, I have some.  
13. I have some milk and water in bottles. There is some rice in a box. There aren't any cans of cola.  
14. I need some bread and some eggs. I need a bottle of water and a box of cereal.  
15. I have some milk. I don't have any bread.

</details>
