## Lección 1 — Gramática: need to / don't need to

**Objetivo:** *need to* + verbo base; *don't / doesn't need to*.

### Ejercicios 1–5 — Completa

1. I ____ pack my suitcase tonight. → *need to / need / needs to*  
2. You ____ take your passport. → *need to / don't need to / need*  
3. She ____ bring so many clothes. → *doesn't need to / need to / don't need to*  
4. We ____ take toiletries – toothbrush, soap. → *need to / needs to / to need*  
5. They ____ pack heavy bags for one week. → *don't need to / need to / doesn't need to*

<details>
<summary>Ver solución</summary>

1. **need to** — *need to* + verbo base.  
2. **need to**  
3. **doesn't need to** — he/she/it → *doesn't need to*.  
4. **need to**  
5. **don't need to** — they → *don't need to*.

</details>

### Ejercicios 6–10 — Elige

6. *Need to* = ____. → a) necessity, have to · b) past · c) only advice  
7. After *need to* we use ____. → a) base verb (*pack, take*) · b) *to* + verb again · c) *-ing* only  
8. *Don't need to* = ____. → a) no necessity · b) obligation · c) past  
9. He/She ____ pack. → a) needs to · b) need to · c) don't need to  
10. *Essential items* = ____. → a) things you need · b) optional things · c) heavy things only

<details>
<summary>Ver solución</summary>

6. **a) necessity, have to**  
7. **a) base verb (*pack, take*)**  
8. **a) no necessity**  
9. **a) needs to**  
10. **a) things you need**

</details>

### Ejercicios 11–13 — Ordena

11. I / need to / pack / my / suitcase / tonight.  
12. You / don't need to / take / so many / clothes.  
13. We / need to / take / toiletries.

<details>
<summary>Ver solución</summary>

11. I need to pack my suitcase tonight.  
12. You don't need to take so many clothes.  
13. We need to take toiletries.

</details>

### Ejercicios 14–15 — Verdadero o falso

14. *Need to* is followed by a base verb (*pack*, *take*). → True / False  
15. *Don't need to* means it is not necessary. → True / False

<details>
<summary>Ver solución</summary>

14. **True**  
15. **True**

</details>

## Lección 2 — Vocabulario: equipaje y maleta

**Objetivo:** *suitcase, pack, clothes, toiletries, essential items, passport*.

### Ejercicios 1–5 — Elige el significado

1. *Suitcase* = ____. → a) a bag for travel; you pack clothes · b) a passport · c) a toothbrush  
2. *Toiletries* = ____. → a) soap, toothbrush, shampoo, etc. · b) clothes · c) a suitcase  
3. *Essential items* = ____. → a) things you need for the trip · b) optional things · c) heavy things only  
4. *Pack* = ____. → a) put things in a suitcase · b) open the suitcase · c) buy a suitcase  
5. *Toothbrush* = ____. → a) you use it to brush your teeth · b) soap · c) a suitcase

<details>
<summary>Ver solución</summary>

1. **a) a bag for travel; you pack clothes**  
2. **a) soap, toothbrush, shampoo, etc.**  
3. **a) things you need for the trip**  
4. **a) put things in a suitcase**  
5. **a) you use it to brush your teeth**

</details>

### Ejercicios 6–7 — Empareja

6. Empareja: suitcase / toiletries / clothes / essential / pack → pack clothes · soap and toothbrush · shirt and trousers · necessary · put in bag  
7. Empareja: passport / shampoo / towel / underwear / toothpaste → need for travel · toiletries · dry yourself · clothes · with toothbrush

<details>
<summary>Ver solución</summary>

6. **suitcase → pack clothes** · **toiletries → soap and toothbrush** · **clothes → shirt and trousers** · **essential → necessary** · **pack → put in bag**  
7. **passport → need for travel** · **shampoo → toiletries** · **towel → dry yourself** · **underwear → clothes** · **toothpaste → with toothbrush**

</details>

### Ejercicios 8–13 — Completa / elige

8. I need to ____ my suitcase before the trip. → *pack / packing / to pack*  
9. Don't forget ____ – toothbrush, soap, shampoo. → *toiletries / clothes / suitcase*  
10. Take ____ clothes – shirt, trousers, underwear. → *essential / suitcase / toiletries*  
11. *Soap* = ____. → a) for washing · b) for teeth · c) for hair only  
12. *Shampoo* = ____. → a) for washing hair · b) for the body only · c) for teeth  
13. What do you need to pack for a short trip? → a) Clothes, toiletries, passport · b) Only clothes · c) Nothing

<details>
<summary>Ver solución</summary>

8. **pack**  
9. **toiletries**  
10. **essential**  
11. **a) for washing**  
12. **a) for washing hair**  
13. **a) Clothes, toiletries, passport**

</details>

### Ejercicios 14–15 — Verdadero o falso

14. Toiletries include toothbrush, soap and shampoo. → True / False  
15. You need to pack your suitcase before a trip. → True / False

<details>
<summary>Ver solución</summary>

14. **True**  
15. **True**

</details>

## Lección 3 — Reading: Pack tonight

**Objetivo:** leer sobre hacer la maleta antes de un vuelo.

### Texto

<audio controls preload="none" src="/audio/blog/curso-a1/unit-49/reading-packing.mp3" title="🔊 Reading: Pack tonight"></audio>

> I need to pack my suitcase tonight. My flight is tomorrow. I need to take clothes – shirts, trousers, underwear. I need to take toiletries too – toothbrush, soap, shampoo. I don't need to take so many things – only essential items. My suitcase is small. Passport and ticket are in my bag.

### Ejercicios 1–5 — Elige la respuesta correcta

1. When does he/she need to pack? → a) Tonight · b) Tomorrow · c) Next week  
2. When is the flight? → a) Tomorrow · b) Tonight · c) Today  
3. What clothes does he/she need to take? → a) Shirts, trousers, underwear · b) Only shirts · c) Only toiletries  
4. What toiletries does he/she need? → a) Toothbrush, soap, shampoo · b) Only toothbrush · c) Only soap  
5. Does he/she need to take so many things? → a) No, only essential items · b) Yes · c) The text does not say

<details>
<summary>Ver solución</summary>

1. **a) Tonight**  
2. **a) Tomorrow**  
3. **a) Shirts, trousers, underwear**  
4. **a) Toothbrush, soap, shampoo**  
5. **a) No, only essential items**

</details>

### Ejercicios 6–10 — Comprensión

6. How is the suitcase? → a) Small · b) Big · c) Heavy  
7. Where are passport and ticket? → a) In my bag · b) In the suitcase · c) At home  
8. *Need to* means ____. → a) necessity · b) past · c) only advice  
9. *Essential items* means ____. → a) things you need · b) optional things · c) heavy things only  
10. *Toiletries* means ____. → a) toothbrush, soap, shampoo, etc. · b) clothes · c) a suitcase

<details>
<summary>Ver solución</summary>

6. **a) Small**  
7. **a) In my bag**  
8. **a) necessity**  
9. **a) things you need**  
10. **a) toothbrush, soap, shampoo, etc.**

</details>

### Ejercicios 11–15 — Detalles

11. The text is about ____. → a) packing a suitcase for a trip · b) the airport · c) a hotel  
12. *Don't need to* means ____. → a) no necessity · b) obligation · c) past  
13. *Pack* means ____. → a) put things in a suitcase · b) open a suitcase · c) buy a suitcase  
14. *Underwear* means ____. → a) clothes under outer clothes · b) a shirt · c) trousers only  
15. The main topic is ____. → a) what to pack: clothes, toiletries, essential items · b) the flight only · c) a hotel

<details>
<summary>Ver solución</summary>

11. **a) packing a suitcase for a trip**  
12. **a) no necessity**  
13. **a) put things in a suitcase**  
14. **a) clothes under outer clothes**  
15. **a) what to pack: clothes, toiletries, essential items**

</details>

## Lección 4 — Listening: Do you need to pack?

**Objetivo:** escuchar un diálogo sobre hacer la maleta.

### Audio y guion

<audio controls preload="none" src="/audio/blog/curso-a1/unit-49/listening-packing.mp3" title="🔊 Listening: Do you need to pack?"></audio>

> **A:** Do you need to pack today?  
> **B:** Yes. I need to pack my suitcase. I need to take clothes and toiletries.  
> **A:** Do you need to take so many shirts?  
> **B:** No. I don't need to take so many. Only essential items.  
> **A:** Don't forget your passport and toothbrush.  
> **B:** I won't. They are in my bag.

### Ejercicios 1–5 — Comprensión

1. Does B need to pack today? → a) Yes · b) No · c) The dialogue does not say  
2. What does B need to take? → a) Clothes and toiletries · b) Only clothes · c) Only toiletries  
3. Does B need to take so many shirts? → a) No, only essential items · b) Yes · c) The dialogue does not say  
4. What does A say not to forget? → a) Passport and toothbrush · b) Suitcase only · c) Clothes only  
5. Where are passport and toothbrush? → a) In B's bag · b) In the suitcase · c) At home

<details>
<summary>Ver solución</summary>

1. **a) Yes**  
2. **a) Clothes and toiletries**  
3. **a) No, only essential items**  
4. **a) Passport and toothbrush**  
5. **a) In B's bag**

</details>

### Ejercicios 6–10 — Detalles

6. *Don't need to* means ____. → a) no necessity · b) obligation · c) past  
7. *Essential items* means ____. → a) things you need · b) optional things · c) heavy things only  
8. The dialogue is about ____. → a) packing for a trip · b) the airport · c) a hotel  
9. *Toiletries* means ____. → a) toothbrush, soap, shampoo, etc. · b) clothes · c) a suitcase  
10. *Pack* means ____. → a) put things in a suitcase · b) open a suitcase · c) buy a suitcase

<details>
<summary>Ver solución</summary>

6. **a) no necessity**  
7. **a) things you need**  
8. **a) packing for a trip**  
9. **a) toothbrush, soap, shampoo, etc.**  
10. **a) put things in a suitcase**

</details>

### Ejercicios 11–15 — Forma

11. *I won't* (forget) means ____. → a) I will not forget · b) I forgot · c) I forget  
12. *Need to* means ____. → a) necessity · b) past · c) only advice  
13. *Don't forget* means ____. → a) remember to take · b) forget · c) past  
14. *Suitcase* means ____. → a) a bag for travel · b) a passport · c) a toothbrush  
15. What tense is used for *need to / don't need to*? → a) Present (necessity) · b) Past · c) Future only

<details>
<summary>Ver solución</summary>

11. **a) I will not forget**  
12. **a) necessity**  
13. **a) remember to take**  
14. **a) a bag for travel**  
15. **a) Present (necessity)**

</details>

## Lección 5 — Writing: My suitcase

**Objetivo:** escribir sobre hacer la maleta con *need to / don't need to*.

### Ejercicios 1–5 — Completa

1. I ____ pack my suitcase tonight. → *need to / need / needs to*  
2. You ____ take your passport. → *need to / don't need to / needs to*  
3. She ____ bring so many clothes. → *doesn't need to / need to / don't need to*  
4. Don't forget ____ – toothbrush, soap. → *toiletries / clothes / suitcase*  
5. We ____ take only essential items. → *need to / don't need to / needs to*

<details>
<summary>Ver solución</summary>

1. **need to**  
2. **need to**  
3. **doesn't need to**  
4. **toiletries**  
5. **need to**

</details>

### Ejercicios 6–8 — Ordena

6. I / need to / pack / my / suitcase / tonight.  
7. You / don't need to / take / so many / clothes.  
8. We / need to / take / toiletries.

<details>
<summary>Ver solución</summary>

6. I need to pack my suitcase tonight.  
7. You don't need to take so many clothes.  
8. We need to take toiletries.

</details>

### Ejercicios 9–15 — Escribe (modelos)

9. Escribe qué necesitas hacer esta noche (*need to pack*).  
10. Escribe qué necesitas llevar (*clothes, toiletries*).  
11. Dos frases: algo que necesitas y algo que no necesitas.  
12. Lista corta de objetos esenciales (3–4 palabras).  
13. Párrafo corto (3–4 frases): qué necesitas y qué no.  
14. 2–3 frases *need to / don't need to* para un viaje de una semana.  
15. Qué no debes olvidar (*Don't forget…*).

<details>
<summary>Ver solución (ejemplos)</summary>

9. I need to pack my suitcase tonight.  
10. I need to take clothes and toiletries.  
11. I need to take my passport. I don't need to take so many shirts.  
12. Essential items: passport, toothbrush, clothes, soap.  
13. I need to pack my suitcase. I need to take clothes and toiletries. I don't need to take so many things. Only essential items.  
14. I need to take shirts, trousers, toothbrush. I don't need to take ten shirts.  
15. Don't forget your passport and toothbrush.

</details>
