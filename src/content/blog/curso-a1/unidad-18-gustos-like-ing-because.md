En la [Unidad 17](/blog/curso-a1/unidad-17-comidas-breakfast-lunch-dinner) dijiste qué comida te gusta. En la **Unidad 18 del curso A1** (*Likes & Dislikes*) pasas a las **actividades**: *I like reading*, *She doesn't like cooking*, y das **razones** con *Why? Because…*.

Esta guía cubre ***like / don't like + -ing***, la pregunta ***Why?***, la respuesta ***Because…***, y vocabulario de **hobbies, música y películas**. Incluye **audios**, **esquemas** y **ejercicios** (más de 2000 palabras). Es el paso natural después de hablar de comida y de *Do you like…?*.

## Qué aprenderás en la Unidad 18 (A1)

Al terminar esta unidad serás capaz de:

- Formar ***like / don't like / likes / doesn't like + -ing***.
- Hablar de **hobbies** (*reading, swimming, dancing…*).
- Preguntar ***Why?*** y responder ***Because…***.
- Nombrar **tipos de música** y **películas**.
- Preguntar *What kind of music / films do you like?*

### Tips

- *listen **to** music* (hace falta *to*).  
- *play football* (deporte) vs *play **the** guitar* (instrumento).  
- *films* (BrE) ≈ *movies* (AmE); en el curso usamos *films*.

## 2. *Like + -ing*

```
sujeto + like(s) / don't like / doesn't like + verbo-ing
```

| Afirmativa | Negativa |
| :--- | :--- |
| I **like reading**. | I **don't like** running. |
| She **likes watching** films. | She **doesn't like** cooking. |
| We **like swimming**. | They **don't like** dancing. |
| He **likes playing** football. | He **doesn't like** cooking. |

**Regla:** tras *like* → forma **-ing**, no infinitivo bare (*read*).  
En A1 priorizamos *like + -ing* para actividades. (Más adelante verás también *like to…*.)

### Cómo se forma la *-ing* (A1)

| Regla | Ejemplo |
| :--- | :--- |
| + **-ing** | read → reading, watch → watching |
| *-e* final → quita *e* + *-ing* | dance → dancing, like → liking |
| CVC corto → dobla consonante (común) | swim → swimming, run → running |

No hace falta memorizar todas las excepciones aún: imita las formas del vocabulario de la unidad.

### *Like* + nombre (U17) vs *like* + *-ing* (U18)

| U17 | U18 |
| :--- | :--- |
| I like **cheese**. | I like **reading**. |
| She loves **pasta**. | She likes **watching** films. |
| Do you like **milk**? | Do you like **swimming**? |

## 4. *Why?* y *Because…*

```
Why do you like it? / Why don't you like it?
Because + razón.
```

| Pregunta | Respuesta |
| :--- | :--- |
| Why do you like reading? | **Because** it's relaxing. |
| Why do you like swimming? | **Because** it's fun. |
| Why don't you like running? | **Because** it's hard. |
| Why does she like comedy films? | **Because** they're funny. |

También puedes unir en una sola frase:

> I like swimming **because** it's fun.  
> I don't like cooking **because** it's hard.  
> She likes reading **because** it's relaxing.

### Mini-mapa de razones

| Actividad | Because… |
| :--- | :--- |
| reading | it's relaxing / interesting |
| swimming / dancing | it's fun |
| comedy films | they're funny |
| horror films | they're scary (I don't like…) |
| cooking | it's interesting / hard |
| running | it's hard / boring (para algunos) |

## 5. Más ejemplos en contexto

> I **like reading** books in the evening. Why? **Because** it's relaxing.  
> My sister **likes watching** films. She loves comedy films **because** they're funny.  
> We **like listening to** music. I like pop and rock.  
> Tom **doesn't like cooking**. Why? **Because** it's hard. He likes eating, though!  
> Do you like **playing** football? — Yes, I do. **Because** it's fun.

### Diálogo modelo

> **Ana:** What do you like doing at the weekend?  
> **Luis:** I like reading and listening to music. And you?  
> **Ana:** I like watching films.  
> **Luis:** Why do you like it?  
> **Ana:** Because it's relaxing. Do you like comedy films?  
> **Luis:** Yes, I do. They're funny. I don't like horror films because they're scary.  
> **Ana:** What kind of music do you like?  
> **Luis:** I like pop and rock.  
> **Ana:** Nice! I like dancing too. Why? Because it's fun!

## 6. Errores típicos de hispanohablantes

| ❌ Incorrecto | ✅ Correcto | Explicación |
| :--- | :--- | :--- |
| *I like read* | *I like **reading*** | *like* + *-ing* |
| *She like watching films* | *She **likes** watching films* | 3.ª persona *-s* |
| *I like listen music* | *I like **listening to** music* | *-ing* + *to* |
| *Why you like it?* | *Why **do** you like it?* | Auxiliar *do* |
| *Because fun* | *Because **it's** fun* | Hace falta *it's / they're* |
| *I like play football* | *I like **playing** football* | *-ing* |
| *He don't like cooking* | *He **doesn't** like cooking* | he → *doesn't* |

## 7. Pronunciación útil

| Forma | Tip A1 |
| :--- | :--- |
| **-ing** | Termina en /ɪŋ/. No digas solo *-in* al practicar despacio. |
| **because** | A menudo *bi-KOZ* / *bɪˈkɒz*. |
| **why** | Empieza con /w/. |
| **watching / cooking** | *ch* / *ck* claras. |
| **films** | *filmz*. |

Escucha los audios y repite pares: *I like reading* → *Why?* → *Because it's relaxing.*

### Ortografía rápida de *-ing* (para no dudar)

Escribe y di estas cinco formas hasta que salgan solas: *reading, watching, listening, swimming, dancing*. Si una actividad nueva no la conoces, parte del infinitivo (*cook → cooking*, *play → playing*) y comprueba en el diccionario solo si suena raro.

Recuerda: tras *don't like / doesn't like* también va *-ing*: *I don't like running* (no *I don't like run*).

---

## 7b. Mini-diálogos para memorizar

> **A:** Do you like reading?  
> **B:** Yes, I do.  
> **A:** Why do you like it?  
> **B:** Because it's relaxing.

> **A:** Does she like cooking?  
> **B:** No, she doesn't.  
> **A:** Why?  
> **B:** Because it's hard.

> **A:** What kind of music do you like?  
> **B:** I like jazz. I like listening to music because it's fun.

Cambia solo el hobby y el adjetivo: fijas la estructura sin diálogos eternos.

## 7c. Plantillas para copiar

1. I like \_\_\_\_ing.  
2. I don't like \_\_\_\_ing because it's \_\_\_\_.  
3. She likes \_\_\_\_ing. Why? Because it's \_\_\_\_.  
4. Do you like \_\_\_\_ing? — Yes, I do. / No, I don't.  
5. What kind of music / films do you like? — I like \_\_\_\_.

### Más frases para memorizar

> I like reading because it's relaxing.  
> I like swimming because it's fun.  
> She likes watching films. She loves comedy films.  
> They don't like dancing.  
> He doesn't like cooking because it's hard.  
> What kind of music do you like? — I like pop and rock.  
> Do you like comedy films? — Yes, I do. They're funny.

Lee la lista dos veces en voz alta. Luego tapa el inglés y traduce desde el español. Si puedes, grábate y comprueba la *-ing* y *Because it's…*.

### Mapa U14–U18 (gustos)

| Unidad | Aporte |
| :--- | :--- |
| U14–15 | *Do/Does … like…?* + respuestas cortas |
| U17 | *like* + comida; *love/hate* |
| U18 | *like* + *-ing*; *Why? Because…*; hobbies/música/cine |

### Frases extra para practicar en voz alta

> I like playing football because it's fun.  
> She likes listening to classical music because it's relaxing.  
> They don't like watching horror films because they're scary.  
> Why do you like dancing? — Because it's fun.  
> Why doesn't he like cooking? — Because it's hard.  
> What kind of films do you like? — I like action and comedy.

Haz el “triple salto” con un hobby: afirmativa → negativa → pregunta con *Why?*. Ejemplo: *I like swimming.* → *I don't like swimming.* → *Why do you like swimming? Because it's fun.*

Otra rutina de dos minutos: elige tres hobbies reales tuyos y escribe para cada uno *I like …ing because…*. Luego cambia uno a negativa (*I don't like …ing because…*). Así practicas forma y significado a la vez, no solo la lista de verbos.

## 9. Plan de práctica (15 minutos)

1. **3 min** — Repite: *I like …ing / I don't like …ing.*  
2. **4 min** — Haz 5 pares *Why? — Because…* en voz alta.  
3. **4 min** — Escucha los audios y actúa el diálogo.  
4. **4 min** — Escribe tu lista de hobbies + géneros favoritos.

### Checklist

- [ ] Uso *like + -ing* (no *like read*)  
- [ ] Formo *She likes / He doesn't like*  
- [ ] Pregunto *Why?* y respondo *Because…*
