## Qué aprenderás en la Unidad 48 (A1)

Al terminar esta unidad serás capaz de:

- Usar ***the + -est*** (*the oldest, the biggest, the tallest*).
- Usar ***the most + adjective*** (*the most famous, the most beautiful*).
- Nombrar ***museum, monument, statue, guided tour, square***.
- Describir un día de sightseeing.
- Combinar pasado (U47) + superlativos: *We visited the most famous museum*.

---

## 1. Superlativos básicos

| Tipo | Forma | Ejemplo |
| :--- | :--- | :--- |
| Corto | **the + -est** | the **oldest**, the **biggest**, the **tallest** |
| Largo | **the most + adj.** | the **most famous**, the **most beautiful** |

![Superlatives A1](/blog/curso-a1/unit-48/a1-unit48-superlatives.png)

```
short:  the + adjective + -est  → the oldest / the biggest
long:   the most + adjective    → the most famous / the most beautiful
```

### Tip

El superlativo compara **uno con todos**: *This is the oldest building in town* = el más antiguo del pueblo.

### Tabla rápida

| :--- | :--- |
| old | the oldest |
| big | the biggest |
| tall | the tallest |
| famous | the most famous |
| beautiful | the most beautiful |
| interesting | the most interesting |

## 8. Errores típicos de hispanohablantes

| ❌ Incorrecto | ✅ Correcto | Explicación |
| :--- | :--- | :--- |
| *the **more** famous* | *the **most** famous* | superlativo |
| ***most** famous museum* | ***the** most famous museum* | falta *the* |
| *the **older** church* (aquí) | *the **oldest** church* | superlativo, no comparativo |
| *the most **old*** | *the **oldest*** | corto → *-est* |
| *the famousest* | *the **most** famous* | largo → *the most* |
| *biggest museum* (sin the) | ***the** biggest museum* | casi siempre *the* |

## 10. Mini-diálogos para memorizar

> **A:** What did you visit?  
> **B:** The most famous museum.

> **B:** Yes, it is.

> **A:** Did you do a guided tour?

> **B:** Yes — a tall statue in the square.

> **A:** Was it interesting?  
> **B:** Yes, very. We took photos.

Cambia solo el lugar: fijas ***the most / the -est***.

### Rutina de 2 minutos

1. Di 3 superlativos cortos (*oldest, biggest, tallest*).  
2. Di 3 con *the most* (*famous, beautiful, interesting*).  
3. Une con *museum / monument / statue*.  
4. Pregunta *Did you do a guided tour?*

### Combinar U47 + U48

| Unidad | Aporta | Ejemplo |
| :--- | :--- | :--- |
| U47 | pasado | We **visited**… / We **did** sightseeing. |
| **U48** | superlativo | …**the most famous** museum. |

4. We saw \_\_\_\_ tall statue in the square. (the tallest)  
5. This is \_\_\_\_ beautiful building. (the most)

## 12. Plan de práctica (15 minutos)

1. **3 min** — Di 5 superlativos (*oldest, biggest, most famous…*).  
2. **3 min** — Une cada uno a *museum / monument / statue*.  
3. **4 min** — Reescribe el reading con tu ciudad.  
4. **5 min** — Mini-entrevista *What did you visit?* / *Was it interesting?*

### Checklist

- [ ] Uso *the + -est* con adjetivos cortos  
- [ ] Uso *the most* con adjetivos largos  
- [ ] Conozco museum / monument / statue / guided tour  
- [ ] Combino con pasado (*visited / did*)  
- [ ] Describo un día de sightseeing

1. **Guía turística de 1 minuto:** presenta tu ciudad con 3 superlativos.
