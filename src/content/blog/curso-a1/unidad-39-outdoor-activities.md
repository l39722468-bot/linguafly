## Qué aprenderás en la Unidad 39 (A1)

Al terminar esta unidad serás capaz de:

- Usar ***am / is / are + going + activity*** para planes.
- Hablar de ***camping, hiking, cycling, fishing***.
- Usar marcadores: ***tomorrow, on Saturday, next week, next weekend***.
- Preguntar: ***What are you doing next weekend?***
- Describir planes familiares outdoor.

## 1. Present Continuous para planes futuros

| Forma | Ejemplo |
| :--- | :--- |
| I **'m going** + activity | I'm going camping next week. |
| She / He **is going** + activity | She is going hiking on Saturday. |
| We / They **are going** + activity | We are going cycling tomorrow. |

![Present Continuous planes A1](/blog/curso-a1/unit-39/a1-unit39-present-continuous-plans.png)

```
am / is / are + going + camping / hiking / cycling / fishing
+ tomorrow / on Saturday / next week / next weekend
```

### Tip

No es “ahora mismo”: es un **plan ya decidido**. La clave está en el tiempo futuro (*next week*, *tomorrow*…).

Con un marcador claro, el oyente entiende que hablas del futuro aunque la forma sea Present Continuous. Sin marcador (*I'm going camping*), a veces suena a “ahora / en camino”; por eso en A1 conviene añadir **cuándo**.

### Marcadores de tiempo útiles

| Marcador | Ejemplo |
| :--- | :--- |
| tomorrow | We're going cycling **tomorrow**. |
| on Saturday / on Sunday | She's going hiking **on Saturday**. |
| next week | I'm going camping **next week**. |
| next weekend | We're going to the mountains **next weekend**. |
| in July | They're going camping **in July**. |

Memoriza 4 marcadores y reutilízalos con las 4 actividades outdoor.

## 7. Errores típicos de hispanohablantes

| ❌ Incorrecto | ✅ Correcto | Explicación |
| :--- | :--- | :--- |
| *I going camping* | *I**'m** going camping* | Falta *am* |
| *She going hiking* | *She **is** going hiking* | Falta *is* |
| *We go camping next week* (plan fijo A1) | *We **are going** camping next week* | PC para planes |
| *I'm go camping* | *I'm **going** camping* | *-ing* |
| *next week I camping* | *I'm going camping **next week*** | Orden + *going* |

### Rutina de 2 minutos

1. Di 4 frases *I'm going…* con actividades distintas.  
2. Di 3 con *he/she is going…*.  
3. Pregunta *What are you doing next weekend?* y responde.  
4. Añade *tent / backpack / mountains*.

Si lo unes a U33: *I'm often going hiking at weekends* (más natural: *I often go hiking* para hábitos; *I'm going hiking on Saturday* para un plan concreto).

### Combinar U29 + U32 + U39

| Unidad | Aporta | Ejemplo |
| :--- | :--- | :--- |
| U29 | am/is/are + -ing | form |
| U32 | go + -ing activities | go cycling |
| **U39** | plans | I'm **going** cycling **tomorrow** |

### Mini-historia para reescribir

> I'm going camping next week with my family. My brother is going hiking on Saturday. My sister is going cycling on Sunday. My dad is going fishing tomorrow. Next weekend we are going to the mountains.

Cambia días y actividades; mantén *am/is/are going*.

### Tour guiado (modelo)

> I'm going camping next week with my family. We love outdoor activities. My brother is going hiking on Saturday and my sister is going cycling on Sunday. My dad is going fishing tomorrow. We have a tent and backpacks. Next weekend we are all going to the mountains.

Grábate leyéndolo. Luego improvisa con **tus** planes.

## 10. Ejercicios prácticos (con soluciones)

### Ejercicio 1 — Completa *am / is / are*

1. I \_\_\_\_ going camping next week.  
2. She \_\_\_\_ going hiking on Saturday.  
3. We \_\_\_\_ going cycling tomorrow.  
4. He \_\_\_\_ going fishing next weekend.  
5. They \_\_\_\_ going camping in July.

<details>
<summary>Ver solución</summary>

1. **am** / **'m**  
2. **is**  
3. **are**  
4. **is** / **'s**  
5. **are**
</details>

## 11. Plan de práctica (15 minutos)

1. **3 min** — Di las 4 actividades con *I'm going…*.  
2. **3 min** — Cambia sujeto (*he/she/we*).  
3. **4 min** — Reescribe el reading.  
4. **5 min** — Mini-entrevista *What are you doing…?*

- [ ] Uso marcadores de futuro  
- [ ] Conozco hiking / camping / cycling / fishing  
- [ ] Pregunto planes con Present Continuous  
- [ ] Distingo hábito (I go…) vs plan (I'm going…)
