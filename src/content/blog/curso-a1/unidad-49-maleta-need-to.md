## Qué aprenderás en la Unidad 49 (A1)

Al terminar esta unidad serás capaz de:

- Usar ***need to + verbo base*** para necesidades.
- Usar ***don't need to / doesn't need to*** cuando algo no es necesario.
- Nombrar ***suitcase, clothes, toiletries, essential items***.
- Hacer una **lista de maleta** en inglés.
- Recordar *passport* y *toothbrush* antes del viaje.

---

## 1. Need to / don't need to

| Forma | Uso | Ejemplo |
| :--- | :--- | :--- |
| **need to** | necesario | I **need to** pack my suitcase. |
| **don't need to** | no necesario (I/you/we/they) | I **don't need to** take so many clothes. |
| **doesn't need to** | no necesario (he/she/it) | She **doesn't need to** bring so many clothes. |

![Need to A1](/blog/curso-a1/unit-49/a1-unit49-need-to.png)

```
need to + base verb
→ need to pack · need to take · need to bring

don't need to / doesn't need to + base verb
→ don't need to take so many things
```

### Tip

Después de ***need to*** va el **verbo base** (*pack*, *take*), no *to pack* doble ni *-ing*: ~~need to packing~~.

### Contraste con must (U41)

| Forma | Idea | Ejemplo |
| :--- | :--- | :--- |
| **must** | obligación fuerte | You **must** show your passport. |
| **need to** | necesidad práctica | I **need to** pack tonight. |
| **don't need to** | no hace falta | You **don't need to** take heavy bags. |

## 8. Errores típicos de hispanohablantes

| ❌ Incorrecto | ✅ Correcto | Explicación |
| :--- | :--- | :--- |
| *I need pack* | *I need **to** pack* | falta *to* |
| *I need to **packing*** | *I need to **pack*** | verbo base |
| *She **don't** need to…* | *She **doesn't** need to…* | 3.ª persona |
| *I **no** need to take…* | *I **don't** need to take…* | auxiliar |
| *need to **to** take* | *need to take* | un solo *to* |
| *toiletry* (lista) | *toiletries* | suele usarse en plural |
