## Qué aprenderás en la Unidad 25 (A1)

Al terminar esta unidad serás capaz de:

- Elegir ***a / an / the*** al hablar de lugares del barrio.
- Usar ***some*** (afirmativa) y ***any*** (negativa / pregunta).
- Nombrar y usar: ***park, supermarket, cinema, library, pharmacy***.
- Describir tu *neighbourhood* con *There is/are* + preposiciones.
- Hablar de hábitos: *I go to the park…*, *I buy some food…*.

## 2. *A / an* — primera mención

| Forma | Cuándo | Ejemplo |
| :--- | :--- | :--- |
| **a** | sonido de **consonante** | There is **a** supermarket near my house. |
| **an** | sonido de **vocal** | There is **an** apple on the table. |

```
There is + a/an + singular (primera mención / no específico)
```

> There is **a** park near my house.  
> There is **a** supermarket in the street.  
> There is **a** cinema opposite the park.  
> There is **a** library next to the school.  
> There is **an** apple on the table.

### Importante

No miras la letra escrita sola: miras el **sonido**. *An hour* (suena con vocal), *a university* (suena /juː/).

## 3. *The* — específico o conocido

***The*** = el/la/los/las **que conocemos** o que son únicos en el contexto.

> I go to **the** park every day.  
> I want to go to **the** cinema.  
> We watch films at **the** cinema.  
> I need some milk from **the** supermarket.  
> I go to **the** library to borrow books.

### Patrón típico del barrio

1. **Presentas** con *a/an*: *There is a park near my house.*  
2. **Luego** usas *the*: *I go to the park every weekend.*

También: *go to the cinema / the supermarket / the library* = el lugar “de siempre” o el tipo de actividad.

## 4. *Some* y *any* (intro A1)

| Palabra | Uso A1 | Ejemplo |
| :--- | :--- | :--- |
| **some** | afirmativa | There are **some** shops in my street. |
| **any** | negativa | There aren’t **any** pharmacies here. |
| **any** | pregunta | Are there **any** cafes near here? |

```
afirmativa → some
negativa / pregunta → any
```

![Esquema some any A1](/blog/curso-a1/unit-25/a1-unit25-some-any.png)

> There are **some** shops in my street.  
> I buy **some** food at the supermarket.  
> I need **some** milk from the supermarket.  
> Are there **any** cafes near here?  
> Do you have **any** bread?  
> There aren’t **any** pharmacies here.  
> There aren’t **any** cafes in this street.

### Tip

*Some/any* van con **plurales** e **incontables** (*milk, bread, food*). Con singular contable sueles usar *a/an*: *There isn’t a pharmacy* (no *any pharmacy* en el modelo A1 del curso; también verás *There isn’t any milk*).

Más adelante (U52–54) profundizarás cuantificadores; aquí basta la regla **afirmativa = some / neg-preg = any**.

## 5. Combinar: *There is/are* + artículos + barrio

| Idea | Ejemplo |
| :--- | :--- |
| Presentar singular | There is **a** park near my house. |
| Presentar plural | There are **some** shops in my street. |
| Negativa singular | There **isn’t a** pharmacy in my street. |
| Negativa plural | There **aren’t any** cafes in this street. |
| Pregunta | Are there **any** cafes near here? |
| Lugar conocido | I go to **the** park every weekend. |

> My neighbourhood is quiet and nice.  
> There is a park near my house. I go there every weekend.  
> There is a supermarket in the street. I buy some food there.  
> There is a cinema opposite the park. We sometimes watch films.  
> There is a library next to the school.  
> There isn’t a pharmacy in my street, but there is one in the next street.

### Diálogo modelo

> **Ana:** Is your neighbourhood nice?  
> **Luis:** Yes. It’s quiet. There is a park near my house.  
> **Ana:** Are there any shops?  
> **Luis:** Yes. There are some shops in my street. And there is a supermarket.  
> **Ana:** Is there a pharmacy?  
> **Luis:** There isn’t a pharmacy in my street, but there is one in the next street.  
> **Ana:** And the cinema?  
> **Luis:** It’s opposite the park. We sometimes go to the cinema at the weekend.

## 6. Preposiciones + artículos (repaso U24)

Sigue usando *next to, between, in front of, opposite, near* con *a/the*:

> There is a pharmacy **next to** the supermarket.  
> There is a cinema **opposite** the park.  
> There is a library **next to** the school.  
> There is a park **near** my house.  
> There is a supermarket **in** the street.

*Near* = cerca de (ya lo usas mucho en esta unidad).

## 7. Errores típicos de hispanohablantes

| ❌ Incorrecto | ✅ Correcto | Explicación |
| :--- | :--- | :--- |
| *There is supermarket* | *There is **a** supermarket* | Falta artículo |
| *I go to park* | *I go to **the** park* | Lugar conocido / actividad |
| *There are any shops* (afirm.) | *There are **some** shops* | Afirmativa → some |
| *Are there some cafes?* (A1) | *Are there **any** cafes?* | Pregunta → any (regla A1) |
| *There aren’t some pharmacies* | *There aren’t **any** pharmacies* | Negativa → any |
| *There is an supermarket* | *There is **a** supermarket* | /s/ = consonante |
| *I buy the food* (cantidad indefinida) | *I buy **some** food* | Cantidad no exacta |

## 8. Pronunciación útil

| Forma | Tip A1 |
| :--- | :--- |
| **a / an / the** | *the* antes de vocal suele sonar *thi*; antes de consonante *thə*. |
| **some / any** | *sam* (débil) · *E-ni*. |
| **neighbourhood** | UK *nei-bə-hud*; US *neighborhood*. |
| **pharmacy** | *FAR-mə-si*. |
| **supermarket** | acento en *SU-* · *super-market*. |
| **cinema** | *SI-nə-mə*. |

Practica el cambio: *There is **a** park* → *I go to **the** park*.

## 8b. Mini-diálogos para memorizar

> **A:** Is there a park near your house?  
> **B:** Yes, there is. I go to the park every weekend.  
> **A:** Are there any shops?  
> **B:** Yes. There are some shops in my street.

> **A:** Do you have any bread?  
> **B:** No, I don’t. I need some milk from the supermarket too.  
> **A:** Is there a pharmacy here?  
> **B:** There isn’t a pharmacy in this street.

> **A:** Where is the cinema?  
> **B:** It’s opposite the park.  
> **A:** Let’s go to the cinema!  
> **B:** Good idea.

Cambia solo los lugares: fijas *a/the* y *some/any*.

Lee la lista dos veces. Luego describe **tu** barrio con 8 frases (mínimo: 2 *a/an*, 2 *the*, 1 *some*, 1 *any*).

### Rutina de 2 minutos

1. Di 3 frases *There is a…*.  
2. Di 2 frases *There are some…*.  
3. Di 1 negativa con *any* y 1 pregunta con *any*.  
4. Di 2 hábitos con *the*: *I go to the…*.

Si miras un mapa real de tu calle, eliges *a/the* con más naturalidad.

### Tour guiado (modelo)

> My neighbourhood is quiet and nice. There is a park near my house. I go there every weekend. There is a supermarket in the street. I buy some food there. There is a cinema opposite the park. We sometimes watch films. There is a library next to the school. There isn’t a pharmacy in my street, but there is one in the next street. There are some shops near the park.

Grábate leyéndolo y luego improvísalo sin mirar. Ese es el speaking típico de esta unidad.

### Frases extra para practicar en voz alta

> Excuse me. Are there any cafes near here?  
> Yes. There are some cafes next to the cinema.  
> Where is the library?  
> It’s next to the school.  
> I need some milk from the supermarket.  
> Do you have any bread?  
> There aren’t any pharmacies in this street.  
> Let’s go to the park!

Personaliza con tu ciudad. Cuanto más concreto, mejor decides entre *a* y *the*.

### Checklist mental

- Primera mención singular → *a/an*  
- Conocido / específico / “el de siempre” → *the*  
- Afirmativa (cantidad) → *some*  
- Negativa / pregunta → *any*  
- Singular negativo de lugar → *There isn’t a…*  
- Plural negativo → *There aren’t any…*

### Mapa rápido U4 → U25

| Unidad | Enfoque |
| :--- | :--- |
| U4 | *a/an*, plurales, *this/that* |
| U11 | Lugares + *There is/are* intro |
| U23–24 | Existencia + preposiciones |
| **U25** | Barrio + *the/a/an* + *some/any* |
| U26 | Direcciones (imperativos) |

### Repaso exprés 21–25

Antes de U26, recuerda también:

- Habitaciones (U21) y muebles / *mine/yours* (U22).  
- *There is/are* + *in/on/under/behind* (U23).  
- *next to / between / in front of / opposite* (U24).  
- Descripción de barrio con artículos y *some/any* (U25).

4. **5 min** — Escribe y lee tu descripción de barrio.
