## Qué aprenderás en la Unidad 46 (A1)

Al terminar esta unidad serás capaz de:

- Pedir con ***Can I have…?*** / ***Can I get…?***
- Preguntar existencia con ***Is there…?***
- Usar vocabulario: ***reception, key, single/double room, room service***
- Hacer **check-in** básico en recepción.
- Entender y producir un diálogo corto de hotel.

---

## 1. Can I have…? / Is there…?

| Forma | Uso | Ejemplo |
| :--- | :--- | :--- |
| **Can I have…?** | pedir algo | Can I have a key? |
| **Can I get…?** | pedir / conseguir | Can I get room service? |
| **Is there…?** | ¿hay…? | Is there Wi-Fi? |
| **I would like…** | me gustaría | I would like a single room. |

![Hotel requests A1](/blog/curso-a1/unit-46/a1-unit46-hotel-requests.png)

```
Can I + base verb (+ object)
→ Can I have a key?
→ Can I get room service?

Is there + noun…?
→ Is there Wi-Fi?
→ Is there a double room available?
```

### Tip

Después de ***Can I*** va el **verbo base** (*have*, *get*), no *to have* ni *having*.  
***Is there*** pregunta si algo existe en el hotel.

2. ¿Adónde va? → **Reception (to check in)**.

5. ¿Qué quiere esta noche? → **Room service**.  
6. ¿Qué tipo de habitación? → **Single room**.

## 8. Errores típicos de hispanohablantes

| ❌ Incorrecto | ✅ Correcto | Explicación |
| :--- | :--- | :--- |
| *Can I **to** have a key?* | *Can I **have** a key?* | verbo base |
| *Can I **having** room service?* | *Can I **have** room service?* | verbo base |
| *Are there Wi-Fi?* | *Is there Wi-Fi?* | *Wi-Fi* como singular aquí |
| *Have I a key?* | *Can I have a key?* | petición cortés |
| *I want key* | *Can I have a key?* / *I would like a key* | más natural |
| *single for two people* | *double room* | single = 1 persona |

## 13. Consejos para practicar

1. **Simula recepción:** una persona es recepcionista; la otra el huésped.  
2. **Lista de necesidades:** Wi-Fi, room service, restaurant, double room → convierte cada una en *Is there…?* o *Can I have…?*.  
3. **Combina** U16: misma forma *Can I have…* en café y hotel.  
4. Prepárate para la [Unidad 47](/curso-a1/unit-47): *Holidays & Vacation* (*was/were*, pasado regular).  
5. Practica en el [cuaderno de ejercicios de la Unidad 46](/blog/curso-a1/unidad-46-hotel-can-i-have-ejercicios-soluciones) y en la [Unidad 46 del curso A1](/curso-a1/unit-46).
