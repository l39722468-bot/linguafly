## Parte II — Ejercicios

### Ejercicio 1 — Identifica el tipo de condicional

Indica si cada frase es zero, first, second, third o mixto.

1. If emissions rise, temperatures rise.
2. If we cut emissions now, temperatures will stabilise.
3. If we phased out coal now, the transition would be steep.
4. If we had acted a decade ago, emissions would now be lower.
5. If we were truly committed, we would have set a target years ago.

<details><summary>Ver solución</summary>

1. **zero** (hecho general). 2. **first** (real posible). 3. **second** (hipotético presente). 4. **mixed** (pasado irreal → presente). 5. **mixed** (presente irreal → pasado).

</details>

### Ejercicio 2 — Mixed conditionals

Completa con los tiempos adecuados.

1. If we ___ (act) earlier, emissions ___ (be) lower today.
2. If we ___ (be) truly committed, we ___ (set) a net-zero target years ago.
3. Had the policy been bolder, the trajectory ___ (change) by now.

<details><summary>Ver solución</summary>

1. *If we **had acted** earlier, emissions **would be** lower today.* (pasado irreal → presente).
2. *If we **were** truly committed, we **would have set** a net-zero target years ago.* (presente irreal → pasado).
3. *Had the policy been bolder, the trajectory **would have changed** by now.* (o *would now be different*: mixto invertido).

</details>

### Ejercicio 3 — Inversión condicional (Had / Were / Should)

Reescribe omitiendo *if*.

1. If we had acted sooner, the window would not have narrowed.
2. If it were not for the delays, we might already have peaked.
3. If we were to phase out coal now, the transition would be steep.
4. If temperatures rise beyond 1.5°C, the consequences will be severe.

<details><summary>Ver solución</summary>

1. *Had we acted sooner, the window would not have narrowed.*
2. *Were it not for the delays, we might already have peaked.*
3. *Were we to phase out coal now, the transition would be steep.*
4. *Should temperatures rise beyond 1.5°C, the consequences will be severe.* (o *would be* en registro hipotético).

</details>

### Ejercicio 4 — Alternativas a if

Reescribe con *unless / provided that / as long as / supposing / assuming*.

1. If emissions do not fall, targets will be missed.
2. Decarbonisation is feasible, but only if investment scales up.
3. Imagine the ice sheets collapsed; how would coastlines respond?
4. We take the models as correct, so the window is narrow.

<details><summary>Ver solución</summary>

1. *Unless emissions fall, targets will be missed.*
2. *Decarbonisation is feasible provided that / as long as investment scales up.*
3. *Supposing the ice sheets collapsed, how would coastlines respond?*
4. *Assuming the models are correct, the window is narrow.*

</details>

### Ejercicio 5 — Hedging léxico

Reescribe con *tend to / appear to / seem to / be likely to*.

1. Renewables are cheaper once deployed at scale. (tend)
2. The data confirms the feedback loop. (appear)
3. Tipping points are closer than models predicted. (seem)
4. A tipping point will be triggered. (likely)

<details><summary>Ver solución</summary>

1. *Renewables tend to be cheaper once deployed at scale.*
2. *The data appears to confirm the feedback loop.*
3. *Tipping points seem to be closer than models predicted.*
4. *A tipping point is likely to be triggered.*

El hedging presenta la afirmación como tendencia o inferencia, no como hecho probado.

</details>

### Ejercicio 6 — Hedging clausal

Reescribe con *it could be argued / arguably / the data suggests / to some extent*.

1. Adaptation is now unavoidable.
2. The window for 1.5°C has closed.
3. Mitigation and adaptation are complementary.
4. The feedback loop is accelerating.

<details><summary>Ver solución</summary>

1. *It could be argued that adaptation is now unavoidable.*
2. *Arguably, the window for 1.5°C has already closed.*
3. *To some extent, mitigation and adaptation are now complementary.*
4. *The data suggests that the feedback loop is accelerating.*

</details>

### Ejercicio 7 — Corrige los errores

1. If we will act now, temperatures will stabilise.
2. If we would have acted, emissions would be lower.
3. Had we would act, the window would not have narrowed.
4. The data suggest to confirm the loop.
5. Renewables are tending to be cheaper.

<details><summary>Ver solución</summary>

1. *If we act now, temperatures will stabilise.*
2. *If we had acted, emissions would be lower.*
3. *Had we acted, the window would not have narrowed.*
4. *The data appears to confirm the loop.* (o *The data suggest that the loop is accelerating.*)
5. *Renewables tend to be cheaper.*

</details>

### Ejercicio 8 — Transformación (CAE-style)

Reescribe manteniendo el sentido con la palabra dada.

1. We did not act, so the window narrowed. (HAD)
2. Perhaps the loop is accelerating. (APPEARS)
3. Without the delays, we might have peaked. (WERE)
4. Adaptation is unavoidable, in my view. (COULD)

<details><summary>Ver solución</summary>

1. *Had we acted, the window would not have narrowed.*
2. *The loop appears to be accelerating.*
3. *Were it not for the delays, we might have peaked.*
4. *It could be argued that adaptation is unavoidable.*

</details>

### Ejercicio 9 — Vocabulario climático

Define en una palabra o frase breve.

1. Reducir las causas del cambio climático. (___)
2. Ajustarse a los efectos ya inevitables. (___)
3. Punto en que un cambio se vuelve autónomo e irreversible. (___)
4. Emisiones netas cero. (___)
5. Ciencia que vincula un evento concreto con el cambio climático. (___)

<details><summary>Ver solución</summary>

1. **mitigation**; 2. **adaptation**; 3. **tipping point**; 4. **net zero**; 5. **attribution (science)**.

</details>

### Ejercicio 10 — Colocaciones

Completa con el verbo adecuado (*peak / narrow / accelerate / scale up / phase out / build*).

1. Emissions need to ___ and then fall.
2. The window for 1.5°C is ___.
3. The feedback loop is ___ warming.
4. Decarbonisation must ___ dramatically.
5. Coastal cities need to ___ resilience.
6. We must ___ coal by 2030.

<details><summary>Ver solución</summary>

1. **peak**; 2. **narrowing**; 3. **accelerating**; 4. **scale up**; 5. **build**; 6. **phase out**.

</details>

### Ejercicio 11 — Combina inversión + hedging

Escribe una frase que combine una inversión con *Had* y un hedging con *arguably* sobre el clima.

<details><summary>Ver solución</summary>

Modelo: *Had we heeded the early warnings, the window would arguably still be open; as it stands, the data suggests it is rapidly narrowing.*

</details>

### Ejercicio 12 — Reading

Lee y responde.

> *Had we acted a decade ago, emissions would now be markedly lower; arguably, the window for 1.5°C has already closed. Were it not for the delay, the data suggests we might already have peaked.*

1. ¿Qué tipo de condicional es *Had we acted... would now be*?
2. ¿Qué función cumple *arguably*?
3. ¿Qué expresa *Were it not for*?

<details><summary>Ver solución</summary>

1. Un **mixto invertido**: pasado irreal (*had acted*) + presente (*would now be*), con omisión de *if*.
2. Modula la certeza: presenta el cierre de la ventana como opinión razonable, no como hecho probado.
3. "De no ser por"; introduce una condición negativa cuya ausencia habría cambiado el resultado.

</details>

### Ejercicio 13 — Listening (paráfrasis)

Oíste: *"If the models are right, we probably have very little time left."* Reescribe con inversión y hedging formal.

<details><summary>Ver solución</summary>

Modelo: *Assuming the models are correct, the data suggests the window is exceedingly narrow.* / *Were the models accurate, it could be argued that little time remains.*

</details>

### Ejercicio 14 — Writing

Escribe un párrafo (70–90 palabras) argumentando sobre una política climática, usando al menos: un mixto invertido con *Had*, un *provided that* y un hedging con *the data suggests*.

<details><summary>Ver solución</summary>

Modelo: *Had investment scaled up a decade ago, decarbonisation would now be further along. Provided that policy is sustained, the data suggests emissions could still peak within this decade. Arguably, however, adaptation can no longer be deferred: were it not for belated action, resilience would already be faltering in the most exposed regions.* (50 palabras; añade un ejemplo concreto para alcanzar el rango.)

Criterios: mixto invertido correcto, *provided that* como condición suficiente, hedging con *the data suggests* y *arguably*, coherencia argumentativa.

</details>

### Ejercicio 15 — Speaking (monólogo)

En 2 minutos, argumenta: *"Is mitigation still enough, or must adaptation take equal priority?"* Usa un condicional mixto, una inversión y un hedging.

<details><summary>Ver solución</summary>

Modelo: *Had we mitigated aggressively, adaptation would be less urgent; as it stands, the data suggests it is no longer optional. Were it not for the delay, arguably we could focus on mitigation alone. Provided that both are funded, resilience and decarbonisation can proceed in parallel.*

</details>

### Ejercicio 16 — Distinción de grados

Reescribe la misma idea en los cuatro grados (zero, first, second, third). Idea: actuar / estabilizar temperaturas.

<details><summary>Ver solución</summary>

- **zero:** *If emissions fall, temperatures stabilise.*
- **first:** *If we cut emissions now, temperatures will stabilise.*
- **second:** *If we phased out coal now, temperatures would stabilise sooner.*
- **third:** *If we had acted a decade ago, temperatures would have stabilised by now.*

El grado cambia la realidad de la condición: ley, posibilidad, hipótesis, irrealidad. Practicar la misma idea en los cuatro grados es el mejor entrenamiento para sentir cómo cada uno reubica la afirmación en el espectro de lo real a lo irreal, una destreza esencial al escribir sobre escenarios climáticos.

</details>

### Ejercicio 17 — Reordenar y combinar

Reordena y puntúa las siguientes proposiciones para formar un párrafo coherente que combine inversión, mixto y hedging.

- a) the trajectory would now be flatter
- b) had the warning been heeded
- c) arguably, the window for 1.5°C is closing
- d) the data suggests we might already have peaked
- e) were it not for the delay

<details><summary>Ver solución</summary>

Modelo: *Were it not for the delay (e), the data suggests we might already have peaked (d). Arguably, the window for 1.5°C is closing (c); had the warning been heeded (b), the trajectory would now be flatter (a).*

Rúbrica: inversión con *were it not for*, hedging con *the data suggests* y *arguably*, mixto invertido con *had ... would now be*. La puntuación separa las cláusulas con punto y coma, no con coma simple.

</details>

### Ejercicio 18 — Consolidación

Identifica cada recurso del texto y su función.

> *Were it not for the delay, the data suggests we might already have peaked. Arguably, the window for 1.5°C is closing; had it been heeded, the trajectory would now be flatter. Provided that investment scales up, however, decarbonisation remains feasible.*

<details><summary>Ver solución</summary>

- *Were it not for* → inversión condicional (condición negativa, omisión de *if*).
- *the data suggests ... might* → hedging (inferencia probabilística).
- *Arguably* → hedging clausal (postura razonable).
- *had it been heeded ... would now be* → mixto invertido (pasado irreal → presente).
- *Provided that* → condición suficiente (alternativa formal a *if*).

</details>

### Ejercicio 19 — Reescribe el párrafo con condicionales y hedging

Eleva el registro del párrafo neutro con un mixto invertido y al menos dos hedging.

> *We did not invest enough, so emissions are still high. I think the window is closing. If we invest now, decarbonisation can still work, but time is short.*

<details><summary>Ver solución</summary>

Modelo: *Had investment scaled up earlier, emissions would now be markedly lower; arguably, the window for 1.5°C is already closing. The data suggests, however, that provided investment scales up now, decarbonisation remains feasible — though the margin, conceivably, is thin.*

Rúbrica: mixto invertido con *had*, hedging con *arguably / the data suggests / conceivably*, *provided* como condición suficiente.

</details>

## Resumen de la unidad

- Los **condicionales** se gradúan en cuatro niveles (zero, first, second, third); los **mixtos** combinan tiempos cuando condición y resultado operan en momentos distintos (pasado irreal → presente, o presente irreal → pasado).
- La **inversión condicional** omite *if* y adelanta el auxiliar: *Had we acted... / Were it not for... / Were we to... / Should temperatures rise...*.
- **Alternativas a if**: *unless, provided (that), as long as, suppose, assuming*.
- El **hedging** modula la certeza: léxico (*tend to, appear to, seem to, be likely to*) y clausal (*arguably, it could be argued, the data suggests, to some extent*).
- El **vocabulario climático** (*emissions, mitigation, adaptation, tipping point, feedback loop, attribution, resilience, decarbonisation, net zero*) y sus colocaciones (*peak, narrow, accelerate, scale up, phase out, build resilience*) permiten argumentar con la precisión y la prudencia que exige la ciencia del clima.
